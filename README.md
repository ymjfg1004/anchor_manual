# Anchor 매뉴얼·제품소개서

앵커 ERP 사용설명서와 제품소개서를 순서대로 제작하는 작업 저장소입니다.

## 작업 순서

1. `사용설명서_Pharos_매뉴얼.pdf`의 구성과 설명 방식을 참고해 `사용설명서_anchor_매뉴얼`을 제작합니다.
2. 앵커 사용설명서를 완성한 뒤 `PHAROS_ERP_제품소개서_33P_v3.html`을 참고해 앵커 제품소개서를 제작합니다.
3. 각 단계는 사용자와 확인하며 차근차근 진행합니다.

## 참고 원칙

- 생산관리는 사용자가 제공한 Notion 매뉴얼 정리본을 기준으로 하며, 본문·문구·내용 순서를 임의로 정리하거나 변경하지 않습니다.
- 문구에 이상이 있으면 사용자에게 먼저 한 번 확인하고, 답변을 받은 뒤 해당 문구를 처리합니다.
- 매뉴얼 화면은 실제 앵커 서비스에서 캡처합니다. 실제 기능, 레이아웃, UI 디자인의 최종 기준은 서비스입니다.
- Figma의 `component`, `파로스/스텔라`, `앵커` 페이지를 모두 참고하되, 화면에 반영할 디자인 변경 범위는 초록 + black 콘셉트의 색상입니다.
- 화면의 기능, 요소 배치, 크기, 구조를 유지하고 색상만 변경할 예정입니다.
- 로그인 정보와 인증 자료는 저장소에 기록하지 않습니다.

참고자료와 접근 상태는 [참고자료 목록](references/README.md)에 기록합니다.

이 저장소에서 작업할 때는 [제작 규칙](AGENTS.md)을 따릅니다.
