1. 외주거래처

1.1. 외주거래처 정보

외주를 맡길 거래처(외주처)를 등록·관리하는 화면입니다. [기초정보]-[일반거래처]에 등록된 거래처 중 외주를 의뢰할 거래처를 선택해 외주거래처로 불러와 등록합니다. 여기서 등록한 외주거래처는 이후 [외주생산지시]·[사외외주 실적입력]·[외주송장입력] 등 외주 업무 전반의 기준 거래처가 됩니다.

💡 외주거래처는 [기초정보]-[일반거래처]에 이미 등록된 거래처 중에서 선택해 불러옵니다. 일반거래처에 없는 거래처는 등록 팝업의 [신규등록]으로 거래처를 먼저 만든 뒤 선택합니다.

⚠️ 외주거래처로 등록하려면 외주유형(사내·사외)과 소속 공장/창고를 반드시 지정해야 합니다.

① 검색 영역

  • 외주유형: [전체]·[사내]·[사외] 중 선택해 외주유형으로 거래처를 필터링합니다.
  • 공장: 드롭다운에서 공장을 선택해 해당 공장 소속 외주거래처만 조회합니다.
  • 작업장: 돋보기 버튼으로 작업장을 선택해 조회 조건에 추가합니다.
  • 우측 검색바: 검색 기준을 고르고 검색어를 입력한 뒤 [조회]를 누르면 목록이 조회되고, [초기화]는 검색 조건을 비웁니다. [상세검색]을 누르면 위의 외주유형·공장·작업장 필터 영역이 펼쳐집니다.

② 기능 버튼

  • 등록: [외주거래처 등록] 팝업을 열어 일반거래처 중에서 외주거래처를 선택·등록합니다.
  • 삭제: 목록에서 선택한 외주거래처를 삭제합니다. (행을 선택해야 활성화됩니다.)
  • 다운로드: 현재 조회된 외주거래처 목록을 엑셀 파일로 내려받습니다.
  • 툴바 우측의 전체 N개 / 선택 N개 표시로 조회·선택 건수를 확인할 수 있습니다.

③ 거래처 목록

  • 컬럼: 거래처코드 · 거래처명 · 사업자번호 · 대표자명 · 외주유형 · 소속작업장 · 소속공장 · 담당자명 · 연락처 · 이메일 · 구분
  • 외주유형: 셀의 드롭다운에서 사내·사외를 지정합니다.
  • 소속작업장 · 소속공장: 돋보기 버튼으로 작업장·공장을 지정합니다. 작업장 화면에서 해당 거래처를 외주처로 지정하면 소속작업장·소속공장이 자동으로 연동됩니다.
  • 담당자명: 돋보기로 담당자를 지정하고 연락처·이메일을 입력합니다.
  • 구분: 토글로 사용 여부를 켜고 끕니다.
  • 등록된 외주거래처가 없으면 그리드에는 데이터가 표시되지 않습니다.

외주거래처 등록 (등록 팝업)

[등록] 버튼을 누르면 열리는 팝업입니다. 일반거래처 목록에서 외주처로 사용할 거래처를 선택해 외주유형·공장을 지정한 뒤 등록합니다. 진행 순서: ① 거래처 선택 → ② 외주유형·공장/창고 지정 → ③ [등록].

① 거래처 목록

  • [기초정보]-[일반거래처]에 등록된 거래처가 등록 최신순으로 표시됩니다. 컬럼: 거래처코드 · 거래처명 · 사업자번호 · 거래처구분 · 업태 · 종목.
  • 상단 검색창에 거래처코드·거래처명·사업자번호를 입력하고 [조회]하면 해당 거래처를 찾을 수 있으며, [초기화]로 검색 조건을 비웁니다.
  • 체크박스로 외주처로 등록할 거래처를 선택하면 아래 [선택된 거래처] 영역에 추가됩니다. 이미 외주거래처로 등록된 거래처는 선택할 수 없습니다.
  • 신규등록: 일반거래처에 없는 거래처는 거래처 등록 팝업으로 새로 만든 뒤 선택합니다.

② 선택된 거래처

  • 위에서 선택한 거래처가 쌓이는 영역입니다. 컬럼: 거래처코드 · 거래처명 · 사업자번호 · 외주유형 · 공장/창고 (외주유형과 공장/창고는 필수 입력 항목입니다.)
  • 외주유형: 사내·사외 중 선택합니다. (필수)
  • 공장/창고: 해당 외주거래처가 소속될 공장/창고를 지정합니다. (필수)
  • 잘못 담은 거래처는 선택 후 [삭제]로 목록에서 제거합니다. 선택 전에는 ‘등록할 거래처를 선택해주세요.’ 안내가 표시됩니다.
  • 외주거래처는 최대 300개까지 등록할 수 있습니다.

③ 등록

  • [등록]은 [선택된 거래처]에 항목이 있을 때 활성화되며, 필수값(외주유형·공장/창고)을 채운 뒤 누르면 외주거래처로 등록됩니다.
  • [취소]를 누르면 ‘내용이 저장되지 않습니다. 취소하시겠습니까?’ 확인 후 닫힙니다.

🔒 외주거래처로 등록되었거나 작업장에 외주처로 지정된 거래처는 [기초정보]-[일반거래처]에서 바로 삭제할 수 없습니다. 외주거래처(또는 작업장)에서 먼저 해제한 뒤 삭제해야 합니다.

2. 외주발주

2.1. 외주생산지시

외주(사외·사내)에 위탁할 생산 작업을 지시·관리하는 화면입니다. 생산관리에서 생성된 생산지시서 중 작업장이 외주로 지정된 작업만 발췌하여, 외주거래처별로 외주생산지시를 발행합니다. 발행된 외주생산지시는 이후 사급자재 출고요청·외주 실적입력·검수·외주정산의 기준이 됩니다.

💡 외주생산지시는 직접 입력하지 않고, [등록] 시 열리는 [생산지시서 선택] 팝업에서 외주 대상 생산지시서를 선택해 구성합니다. 즉 생산지시서의 외주 작업만 발췌해 외주생산지시로 발행하는 개념입니다.

🔢 외주생산지시번호(예: OPI2026060004)는 발행 시 시스템이 자동 부여하며, 원천이 된 생산지시서번호(원천생산지시서번호, 예: PIR2026050017)와 연결됩니다.

📌 하나의 외주생산지시는 단일 라우팅에서 같은 외주거래처(작업장)에 연결된 외주 작업을 기준으로 묶여 발행됩니다.

① 검색 영역

  • 외주생산지시서 발행일자: 조회할 발행일자 범위를 지정합니다. [상세검색]으로 추가 조건을 펼치고, [조회]로 목록을 불러오며, [초기화]로 검색 조건을 비웁니다.

② 기능 버튼

  • 마감: 실적 집계가 끝난 외주생산지시를 마감 처리합니다.
  • 등록: [생산지시서 선택] 팝업을 열어 외주 대상 생산지시서를 선택하고 외주생산지시를 발행합니다.
  • 수정: 기본 정보에서 대상 건을 선택한 뒤 작업장·수량 등을 변경합니다.
  • 삭제: 선택한 외주생산지시를 삭제합니다.
  • 결재상신: 선택한 외주생산지시를 전자결재로 상신합니다.
  • 다운로드: 조회된 기본정보·상세정보를 엑셀 파일로 내려받습니다.

③ 기본 정보 (외주생산지시 헤더)

  • 외주생산지시 목록(마스터)입니다. 컬럼: 외주생산지시번호 · 외주거래처 · 외주생산지시서 발행일자 · 산출품목 · 원천생산지시서번호 · 작성자 · 부서 · 상태 · 문서번호 · 결재상태
  • 상태: 외주생산지시의 진행 상태(예: 작성중, 배포)를 표시합니다. 배포 상태가 되면 해당 지시가 사급자재 요청 대상으로 넘어갑니다.
  • 결재상태: 전자결재 진행 상태를 표시합니다. 행을 선택하면 아래 [외주 생산지시 상세정보]가 해당 지시의 내용으로 표시됩니다.

④ 외주 생산지시 상세정보 (디테일)

  • 선택한 외주생산지시의 공정·작업·자재 상세입니다. 컬럼: 라우팅 · 공정 · 작업 · 작업장 · 산출품목 · 생산지시수량 · 시작일자 · 납기일자 · BOM 정보(사급자재·규격·단위·사급자재 수량) · 원천 생산지시서 정보(생산지시서번호·품목)
  • 공정·작업·생산지시수량·시작일자·납기일자는 원천 생산지시서(생산계획)에서 가져옵니다. 외주생산지시서 발행일자도 원천 생산지시서의 발행일자와 동일하게 자동 설정됩니다.

📅 외주생산지시서 발행일자 (2026-06 설정 추가) — 원천 생산지시서의 발행일자와 동일하게 자동 설정됩니다. (예: 원천 PIR2026050021의 발행일자 = 해당 외주생산지시 발행일자)

  • BOM 정보: 해당 공정·작업에 매핑된 사급자재(외주처에 제공할 자재)와 규격·단위·수량입니다.

외주생산지시 등록 (생산지시서 선택 팝업)

[등록]을 누르면 열리는 팝업입니다. 외주거래처·공장 등 조건으로 외주 대상 생산지시서를 조회해 선택하면, 그 생산지시서의 외주 작업으로 외주생산지시가 구성됩니다. 진행 순서: ① 외주거래처·공장·생산계획일자 등 조건 입력 → ② [조회] → ③ 생산지시서 선택 → ④ [확인].

① 검색조건

  • 외주거래처: 돋보기 버튼으로 외주거래처를 선택합니다. (필수)
  • 공장: 드롭다운에서 공장을 선택합니다. (필수, 공장 목록은 외주거래처를 먼저 선택해야 채워집니다.)
  • 생산계획일자 · 생산지시번호 · 품목 · 라우팅 · 작업장: 조회 범위를 좁히는 추가 조건입니다. 조건 입력 후 [조회], [초기화]로 조건을 비웁니다.
  • 외주거래처·공장을 지정하지 않고 조회하면 ‘외주 거래처, 공장을 입력해 주세요.’ 안내가 표시됩니다.

② 작성자 · 부서 (필수)

  • 외주생산지시의 작성자와 부서입니다. 로그인 사용자 기준으로 자동 표시되며, 필요 시 변경할 수 있습니다.

③ 생산지시서 목록

  • 조회된 생산지시서(외주 작업 포함분)가 표시됩니다. 컬럼: 거래처 · 외주유형 · 생산지시번호 · 발행일자 · 공장 · 품목 · 규격 · 단위 · 라우팅 · 공정 · 선택 · 작업 · 작업장 · 외주생산품 · 생산지시수량 · 누적지시수량 · 지시수량
  • [선택] 체크박스로 외주생산지시를 생성할 작업(업체)을 선택합니다. (해당 거래처의 외주 작업이 모두 외주생산지시로 발행된 기간에는 ‘조회된 데이터가 없습니다.’가 표시됩니다.)

④ 확인 / 취소

  • 확인: 선택한 생산지시서로 외주생산지시를 발행합니다.
  • 취소: 입력을 취소하고 팝업을 닫습니다. 입력 내용이 있으면 ‘내용이 저장되지 않습니다. 취소하시겠습니까?’ 확인 후 닫힙니다.

3.2. 사외외주 실적입력

개요

사외외주 실적입력은 외부 외주처(협력사)에 가공을 맡긴 외주생산지시에 대해, 외주처가 납품한 입고 실적수량을 입력하는 외주입고 화면입니다. 사외외주는 사급자재를 외주처에 출고해 가공·완성한 뒤 당사가 입고검수(합격품만 입고, 불량은 반품·폐기)하는 점이, 검수 없이 작업 완료로 다음 공정이 연결되는 사내외주(3.1)와 다릅니다.

💡 잔여수량 = 외주생산지시수량 − (기존 실적입고수량 + 이번 실적입고수량). 외주비 = 외주단가 × 입고수량(표준 대비 차이는 외주가공비차이로 인식).

화면 진입

좌측 사이드바 [외주관리] ▸ [외주입고] ▸ [사외외주 실적입력]. 상단 외주생산지시서 발행일자 기간(예: 2026-05-01 ~ 2026-05-31)을 선택해 [조회]합니다.

화면 구성

화면은 상단 ‘외주실적 기본정보’(마스터)와 하단 ‘외주실적 상세품목정보’(디테일)의 마스터-디테일로 구성됩니다. 마스터에서 외주실적을 선택하면 하단에 그 실적의 입고 품목이 표시됩니다.

  • 외주실적 기본정보(마스터) — 외주실적번호 · 외주거래처 · 공장 · 입고일자 · 외주생산지시번호 · 작성자 · 부서 · 상태 · 비고(전자결재 사용 시 결재문서번호·결재상태 포함). 상태는 작성중 → 입고(검수대기) → 검수완료 → 검수완료/반품요청 → 검수완료/반품완료로 진행됩니다.
  • 버튼 — [등록]·[수정]·[삭제]로 실적을 관리하고, [입고반영]·[입고취소]로 입고 처리/취소, [마감]으로 마감, [다운로드]로 내려받습니다.

  • 외주실적 상세품목정보(디테일) — 외주제작품목 · 규격 · 단위 · 공정 · 작업 · 작업장 · 입고창고 · 완료/납품 기한 · 외주생산지시수량 · 실적입고수량 · 잔여수량. (예: 실크프린트 완료품, 외주생산지시수량 3,333 = 실적입고수량 3,333 → 잔여수량 0.)

실적 입력 절차

  • 등록 — [등록]을 누르면 ‘외주실적입력’ 팝업이 열립니다. 발행일자·외주거래처·부서·사원으로 외주생산지시서를 조회하고, 사외외주 유형의 지시서를 선택합니다.
  • 입고 입력 — 입고일자를 입력하고, 품목별로 실적입고수량을 입력합니다. 잔여수량 = 외주생산지시수량 − (기존 실적입고수량 + 입력 수량)으로 자동 계산되며, [확인]으로 저장합니다.
  • 검증 — 실적입고수량이 잔여수량을 초과해 잔여수량이 음수가 될 수 없고, 실적입고수량은 최소 1개 이상이어야 합니다.
  • 입고반영 — 저장한 실적을 [입고반영]하면 상태가 입고(검수대기)가 됩니다. 잘못 반영했으면 [입고취소]합니다. 입고된 수량은 취소할 수 없으며, 외주생산지시 수량 변경도 입고수량 이상으로만 가능합니다.

회계처리 (전표)

사외외주 입고·정산 시 다음 분개가 생성됩니다(분개 상세·정산은 외주송장입력·외주마감에서 처리되며, 생산마감 전에 완료하는 것이 원칙입니다).

  • 외주 입고(GR) — (차) 재공품(WIP) / (대) 사급자재. 외주처에 사급한 자재가 가공품으로 들어와 재공에 반영됩니다.

연계

  • 외주생산지시(2.1)에서 발행한 지시를 선택해 실적을 입력하며, 입고 후 외주 검수 및 반품(3.3)에서 양품/불량(반품·폐기)을 처리하고, 외주송장입력(4.1)에서 외주비를 정산합니다. 사내외주(3.1)는 검수 없이 작업 완료로 다음 공정에 연결됩니다.

3. 외주입고

3.3. 외주 검수 및 반품

개요

외주 검수 및 반품은 사외외주로 입고된 외주제작품을 검수해 양품·불량·폐기 수량을 구분하고, 불량분을 반품(재작업)하거나 폐기 처리하는 화면입니다. 사외외주(3.2)로 입고된 건만 검수 대상이며(사내외주는 검수 없음), 합격(양품)분은 실재고로 확정되고 불량분은 반품/폐기됩니다.

💡 양품수량 = 입고수량 − 불량수량. 불량수량은 다시 반품수량 + 폐기수량으로 처리합니다. 반품+폐기 수량 합은 입고수량을 넘을 수 없고, 검수일자는 외주입고일자보다 앞설 수 없습니다.

화면 진입

좌측 사이드바 [외주관리] ▸ [외주입고] ▸ [외주 검수 및 반품]. 상단 외주입고일자 기간(예: 2026-05-01 ~ 2026-05-31)과 입고상태를 선택해 [조회]합니다.

화면 구성

화면은 상단 외주입고 검수 목록(마스터)과 하단 ‘상세품목정보’(디테일)의 마스터-디테일로 구성됩니다. 마스터에서 입고건을 선택하면 하단에 그 입고의 품목별 검수 결과가 표시됩니다.

  • 마스터(외주입고 검수 목록) — 외주실적번호 · 외주입고일자 · 입고번호 · 외주거래처코드 · 외주거래처명 · 공장 · 상태 · 검수일자 · 외주생산지시서번호 · 비고. 상태는 입고(검수대기) → 검수완료 → 검수완료/반품요청 → 검수완료/반품완료로 진행됩니다.
  • 버튼 — [검수완료]·[검수취소]로 검수를 확정/취소하고, [출력]·[다운로드]로 내보냅니다.

  • 디테일(상세품목정보) — 번호 · 품목코드 · 품목명 · 품목유형 · 규격 · 단위 · 입고수량 · 양품수량 · 불량수량 · 폐기수량 · 반품요청수량 · 반품수량 · 입고공장 · 입고창고 · 비고 · 최종작업자 · 작업일시. [검수입력]으로 검수 결과를 입력하고, [반품출고요청]으로 불량분 반품을 요청합니다.

검수 · 반품 처리 절차

  • 검수입력 — [검수입력]을 누르면 검수 결과 입력 팝업이 열립니다. 품목별로 불량수량·폐기수량을 불량코드(예: NG01 치수, NG02 외관, NG03 조립, NG04 용접, NG05 도장, NG06 기타)별로 입력하면 양품수량(= 입고수량 − 불량수량)이 자동 계산됩니다. 입고수량은 실적 데이터로 고정되어 수정할 수 없습니다.

  • 검수완료 — [검수완료]로 검수를 확정합니다. 확정하면 양품수량이 확정되고 양품·불량 수량에 대한 전표가 생성됩니다. [검수취소]로 취소할 수 있으나, 이미 반품처리된 건이나 전표가 승인·마감된 상태면 검수취소할 수 없습니다.
  • 반품출고요청 — 검수완료 상태이고 불량수량이 있는 품목에만 [반품출고요청]이 활성화됩니다. 반품일자(입고일자 이후)와 반품수량(≤ 미반품수량 = 불량수량 − 반품요청완료수량)을 입력해 재작업을 위한 반품 출고를 요청합니다. 반품요청수량과 반품완료수량이 같아지면 상태가 검수완료/반품완료가 됩니다.
  • 폐기 — 폐기수량은 비정상공손손실로 즉시 인식되며, 재고 입출고조정(외주검수폐기, 표준단가)으로 재고에서 차감됩니다.

회계처리 (전표)

사외외주(유상사급) 검수·반품·폐기·정산 시 다음 분개가 생성됩니다(검수자산대기·외주검수대기·사급자재출고는 결산 시 잔액 0이 되는 임시 가계정). 분개 상세·정산은 외주송장입력·외주마감에서 처리됩니다.

  • 임시 입고(검수 전) — (차) 검수자산대기 / (대) 외주검수대기.
  • 합격품(양품) — (차) 외주검수대기 / (대) 검수자산대기 → (차) 외주제작품 재고 / (대) 사급자재출고. 외주제작품 금액 = 합격수량 × 표준단가.
  • 반품 — (차) 외주검수대기 / (대) 검수자산대기. 재작업·재납품을 위해 사급자재출고 임시계정이 남습니다(폐기손실은 인식하지 않음).
  • 폐기 — (차) 외주검수대기 / (대) 검수자산대기, 그리고 (차) 재고자산폐기손실 / (대) 사급자재출고. 폐기분만 폐기손실(비정상공손손실)을 추가 인식합니다.
  • 외주비 정산 — (차) 외주가공비 / (대) 외상매입금. 표준원가형은 (차) 표준외주가공비 · (차) 외주가공비차이 / (대) 외상매입금. 이후 정산 시 (차) 재공품 / (대) 외주제작품 재고 · (대) 외주가공비로 대체됩니다.

연계

  • 사외외주 실적입력(3.2)에서 입고한 건이 본 화면의 검수 대상이며, 검수완료 후 외주송장입력(4.1)·외주마감에서 외주비를 정산해 제조원가로 반영됩니다. 사내외주(3.1)는 검수 없이 작업 완료로 다음 공정에 연결됩니다.

3.4. 외주 지시대비 실적현황

ℹ️ 위탁 생산지시수량 대비 실적입고수량 · 잔여수량으로 지시 대비 입고 진행을 확인합니다. 하나의 외주생산지시번호에 여러 건의 실적이 나뉘어 입력될 수 있으며, 외주생산지시번호별 소계와 맨 아래 전체 합계가 표시됩니다.

② 다운로드

③ 조회 결과

  • 외주생산지시번호별 입고 실적 내역입니다. 컬럼: 외주생산지시번호 · 외주거래처 · 품목 · 규격 · 단위 · 공정 · 작업 · 작업장 · 입고공장 · 입고창고 · 위탁 생산지시수량 · 실적번호 · 실적입고수량 · 잔여수량
  • 실적번호는 실적 입력 시 채번되는 번호로, 하나의 외주생산지시번호에 여러 실적번호가 대응(1:N)할 수 있습니다. 각 외주생산지시번호 아래에 소계(실적입고수량·잔여수량 합)가 표시됩니다.
  • 잔여수량은 위탁 생산지시수량에서 실적입고수량을 뺀 값으로, 아직 입고되지 않은 수량을 나타냅니다.

④ 합계

  • 조회된 전체 소계의 합계(위탁 생산지시수량·실적입고수량·잔여수량)를 그리드 하단에 고정 표시합니다.

4.1. 외주송장입력

외주 거래처로부터 받은 송장(IR)을 입력해 외주 대금 정산의 기초를 만드는 화면입니다. 외주 입고 실적(GR)을 참조해 송장을 입력하고, GR/IR 매칭·송장확정을 거쳐 전표로 처리합니다.

💡 송장 입력 방식은 두 가지입니다. ① 일반송장 - 외주실적(GR)으로 입력: 외주 입고 실적(GR)이 있는 정식 방식으로, GR을 참조해 송장을 입력합니다. ② 선송장 - 외주생산지시서로 입력: 송장(IR)이 입고(GR)보다 먼저 도착한 경우, 외주생산지시서를 참조해 먼저 입력합니다.

ℹ️ GR/IR 매칭상태로 입고수량과 송장수량의 일치 여부를 확인합니다. [송장확정] 시 전표가 생성되며, [송장취소]로 되돌릴 수 있습니다.

📝 아래 목록은 실제 입력된 송장(5월)이며 일부 식별정보(거래처코드·담당자명)는 가상 표기로 바꿨습니다. 등록 팝업 캡처는 입력 화면 구성을 보여주는 예시(가상 데이터) 입니다.

① 검색 영역

  • 송장일자: 조회할 송장일자 범위를 지정합니다. 상세검색으로 조건을 추가하고, [조회]로 목록을 불러오며 [초기화]로 검색 조건을 비웁니다.

② 기능 버튼

  • 일반송장-외주실적(GR)으로 입력: 외주 입고 실적(GR)을 참조해 송장을 입력하는 팝업을 엽니다.
  • 선송장-외주생산지시서로 입력: 외주생산지시서를 참조해 송장을 먼저 입력하는 팝업을 엽니다.

미도착송장 처리 (월말 미착 결산)

외주는 구매와 달리 대금을 비교할 발주(PO) 기준이 없어, 외주 거래처가 보낸 송장이 도착하는 대로 이 화면에서 반영합니다. 다만 외주 실적(입고·합격)은 확정됐는데 월말까지 송장이 도착하지 않은 경우, 발생주의에 따라 결산 시점에 그 금액을 미도착송장(추정부채)으로 인식합니다.

  • 추정 인식(월말 결산): 미수취 송장분을 표준금액으로 추정해 부채로 계상합니다. 분개는 (차) 외주가공비 / (대) 미지급금-외주가공비 이며, 사내외주·사외외주 동일합니다.
  • 자동 해소(익월 1일): 전월 추정분개를 자동 역분개해 되돌립니다. 이후 실제 송장이 도착하면 이 화면에서 정식으로 송장을 입력·확정합니다.

📒 미도착송장은 "송장이 아직 오지 않은 입고분"을 월말에만 임시로 부채로 잡았다가 익월 초에 되돌리는 결산 추정 처리입니다. 추정은 표준금액 기준이라, 실제 송장 금액과 차이가 있으면 정식 송장 처리 시 정산됩니다.

5.1. 외주 GR/IR 불일치 조회

외주생산지시·외주실적(GR)·외주송장(IR)을 라인 단위로 매칭해, 수량이 일치하지 않는 항목을 모아 보는 보고서입니다. 매칭상태와 수량차이로 부분청구·과다청구 건을 추적해 송장확정·정산을 점검합니다.

💡 외주는 비교할 발주(PO)가 없어 단가차이(구매가격차이) 개념이 없으며, 입고(GR) 수량 대비 송장(IR) 수량의 수량차이를 중심으로 매칭합니다. (구매 송장의 단가차이·세액차이 항목 없음)

ℹ️ GR/IR 매칭상태: 일치(수량차이 0) · 부분청구(송장수량 < 입고 양품수량, 잔량 남음) · 과다청구(송장수량 > 입고 양품수량). 화면은 라인 단위 [상세현황]과 매칭상태·거래처별 [요약현황] 두 탭으로 구성됩니다.

📝 아래 캡처의 데이터는 매칭상태 종류(일치·부분청구·과다청구)를 보여주기 위한 예시이며, 가독성을 위해 주요 컬럼만 표시했습니다(전체 컬럼은 아래 목록 참조).

① 탭

  • 상세현황: 외주생산지시/GR/IR 매칭 라인 1건이 한 행. 요약현황: 매칭상태·거래처로 집계.

② 검색 영역

  • 매칭상태 필터·검색어·상세검색으로 조건을 좁혀 [조회]하고 [초기화]로 비웁니다.

③ 출력 · 다운로드

  • 조회 결과를 출력하거나 엑셀로 내려받습니다.

④ 조회 결과 (상세현황)

  • 전체 컬럼(좌→우): 기준정보(거래처코드 · 거래처명 · 품목코드 · 품목명 · 품목유형 · 규격 · 단위) · 외주생산지시(외주생산지시 항목 · 지시일자 · 지시수량) · 외주실적입고(GR)(GR 항목 · 입고일자 · 입고수량 · 양품수량 · 불량수량) · 송장(IR)(IR 항목 · 송장일자 · 송장수량 · 송장단가 · 공급가 · 부가세 · 합계) · 차이/매칭(수량차이 · GR/IR 매칭상태) · 지급(지급기한 · 경과일수)
  • 수량차이는 송장수량 − 입고 양품수량으로, 음수면 부분청구(미청구 잔량 존재), 양수면 과다청구입니다. 경과일수로 지급기한 경과를 확인합니다.

요약현황

  • 매칭상태·거래처 조합으로 라인을 집계합니다. 컬럼: GR/IR 매칭상태 · 거래처코드 · 거래처명 · 라인개수 · 수량차이 합계
  • 매칭상태가 일치가 아닌(부분청구·과다청구) 건을 파악해, 원천 외주생산지시·실적·송장을 정정하면 매칭상태가 자동 재계산됩니다.

5.2. 외주지시별 입고/송장 현황

외주생산지시 기준으로 입고(GR)와 송장(IR)의 수량·금액을 합산해 진행률을 보여주는 보고서입니다. 지시 대비 입고·송장 진행, 미입고잔량·미청구잔량, 납기 경과를 외주생산지시 단위로 한 화면에서 확인합니다.

💡 예: 지시 100개 중 입고 80개·송장 70개 → 미입고 20개·미청구 10개 처럼, 외주생산지시별 진척도를 한눈에 파악합니다. 문제 항목은 [외주 GR/IR 불일치 조회]로 드릴다운해 원인을 확인합니다.

ℹ️ 미입고잔량(지시수량 − 입고수량) · 미청구잔량(양품수량 − 송장수량) · 납기경과일수로 납기 지연과 미청구를 추적합니다. 화면은 라인 단위 [상세현황]과 외주생산지시 단위 [요약현황] 두 탭입니다.

📝 아래 캡처의 데이터는 진행 상태(완결·미입고잔량·미청구잔량)를 보여주기 위한 예시이며, 가독성을 위해 주요 컬럼만 표시했습니다(전체 컬럼은 아래 목록 참조).

① 탭

  • 상세현황: 외주생산지시 항목 1건이 한 행. 요약현황: 외주생산지시 단위로 집계.

② 검색 영역

  • 필터·검색어·상세검색으로 조건을 좁혀 [조회]하고 [초기화]로 비웁니다.

③ 출력 · 다운로드

  • 조회 결과를 출력하거나 엑셀로 내려받습니다.

④ 조회 결과 (상세현황)

  • 전체 컬럼(좌→우): 기준정보(거래처코드 · 거래처명 · 품목코드 · 품목명 · 품목유형 · 규격 · 단위) · 외주생산지시(외주지시번호 · 외주지시일자 · 항목번호 · 납품기한 · 지시수량) · 입고(GR) 합산(입고수량 · 양품수량 · 불량수량 · 양품금액) · 송장(IR) 합산(송장수량 · 송장금액) · 잔량(미입고잔량 · 미청구잔량) · 납기(최종입고일자 · 최종송장일자 · 납기경과일수 · 납기지연수량 · 비고)
  • 미입고잔량 = 지시수량 − 입고수량, 미청구잔량 = 양품수량 − 송장수량. 잔량이 남은 항목은 공급사 납기 독촉·송장 청구 요청의 대상입니다.

요약현황

  • 외주생산지시 단위로 라인을 합산합니다. 컬럼: 거래처코드 · 거래처명 · 외주지시번호 · 지시품목 · 항목개수 · 지시수량 · 입고수량 · 송장수량 · 미입고잔량 · 미청구잔량
  • 지시수량 = 송장수량이고 미입고·미청구잔량이 0인 외주생산지시는 정산 완결 상태로, 잔량이 큰 지시는 추적 대상입니다.
