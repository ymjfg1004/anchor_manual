1. 경영/실행계획

1.1. 연간경영계획

개요

연간경영계획은 회기연도별로 회사의 연간 손익(매출액·매출원가·판매관리비·영업외손익·법인세 등)을 계획버전 단위로 수립하는 화면입니다. 연간영업계획(매출)·연간원가계획을 반영해 항목별 계획금액을 입력하고, 마감·결재상신을 거쳐 경영계획을 확정합니다.

💡 손익 항목은 9단계로 구성됩니다 — ①총매출액 → ②총매출원가 → ③매출총이익(1-2) → ④판매관리비 → ⑤영업이익(3-4) → ⑥영업외수익 → ⑦영업외비용 → ⑧법인세 등 → ⑨당기순이익(5+6-7-8). 계획버전은 여러 개 만들 수 있으나 ‘확정’은 계획별 1개만 가능합니다.

화면 진입

좌측 사이드바 [예산관리] ▸ [경영/실행계획] ▸ [연간경영계획]

화면 구성

상단 기준년도로 [조회]하면 좌측 ‘1. 계획버전’, 중앙 ‘2. 항목별 계획금액 입력’, 우측에 선택 항목의 상세 그리드가 표시됩니다.

  • ① 기준년도 — 조회 기준 회기연도를 선택하고 [조회]합니다. [초기화]로 조회조건을 리셋합니다.
  • ② 계획버전 — 해당 연도의 연간경영계획 버전 목록입니다. 각 카드에 계획번호(MP+연도+일련), 계획기간, 비고, 결재상태, 문서번호, 최종작업자·작업일시가 표시되며 ‘확정/미확정’ 상태를 가집니다. [계획버전 추가]·[결재상신]·[삭제] 버튼을 제공합니다.
  • ③ 항목별 계획금액 입력 — 선택한 계획버전의 손익 항목별 계획금액입니다. 1.총매출액 ~ 9.당기순이익의 9개 항목으로 구성되며, 매출액·매출원가는 사업부별로 펼쳐 볼 수 있습니다. 항목을 선택하면 우측에 상세가 표시됩니다. [엑셀업로드]로 일괄 입력할 수 있습니다.
  • ④ 상세 그리드 — 선택한 항목(예: 총매출액)의 사업부·제품별 상세입니다. 매출계획은 사업부/제품코드/제품명/규격/단위/판매계획수량 등을 표시합니다. 상단 [연간영업계획 반영]으로 영업계획 매출을 가져오고, ‘반영문서’로 연결된 연간영업계획 문서를 확인합니다. ‘월별 상세내역 보기’를 체크하면 1~12월 월별 금액으로 펼쳐집니다. [마감]/[마감취소]로 항목을 마감합니다.

계획버전 추가

[계획버전 추가]를 클릭하면 ‘계획버전 추가’ 팝업이 열립니다.

  • 계획년도 — 조회 기준연도가 기본값으로 표시되며 수정할 수 없습니다.
  • 기간 — 계획 대상 기간(예: 2026-01 ~ 2026-12)을 선택합니다.
  • 비고 — 계획에 대한 설명을 입력합니다.
  • [저장] 시 새 계획버전이 생성되고, [취소] 시 입력 내용은 저장되지 않습니다.

마감 · 결재상신 · 삭제

  • 마감 — 항목별로 [마감]합니다. 마감 후에는 수정할 수 없으며 [마감취소]로 해제합니다. (총매출액을 마감하면 사업부별 매출도 함께 마감)
  • 결재상신 — 전자결재를 사용하는 경우 [결재상신]으로 계획버전을 상신합니다. 결재상태·문서번호가 카드에 표시됩니다.
  • 삭제 — 마감·결재 내역이 없는 계획버전만 [삭제]할 수 있습니다.

1. 경영/실행계획

1.2. 월간실행계획

개요

월간실행계획은 기준년월별로 해당 월의 실행 손익(매출액·매출원가·매출총이익·판매관리비·영업이익)을 계획버전 단위로 수립하는 화면입니다. 연간경영계획을 월 단위로 구체화한 실행계획으로, 월간영업계획을 반영해 사업부·품목별 계획금액을 입력합니다.

💡 손익 항목은 5단계입니다 — ①총매출액 → ②총매출원가 → ③매출총이익(1-2) → ④판매관리비 → ⑤영업이익(3-4). 매출액·매출원가는 사업부별(메인사업부·공통사업부)로 분개됩니다. (연간경영계획이 당기순이익까지 9단계인 것과 달리, 실행계획은 영업이익까지 다룹니다.)

화면 진입

좌측 사이드바 [예산관리] ▸ [경영/실행계획] ▸ [월간실행계획]

화면 구성

상단 기준년월로 [조회]하면 좌측 ‘1. 계획버전’, 중앙 ‘2. 항목별 계획금액 입력’, 우측에 선택 항목의 사업부·품목별 상세가 표시됩니다.

  • ① 기준년월 — 조회 기준 연월(예: 2026-06)을 선택하고 [조회]합니다. [초기화]로 조회조건을 리셋합니다.
  • ② 1. 계획버전 — 해당 월의 월간실행계획 버전 목록입니다. 각 카드에 계획번호(MP+연월+M+일련, 예: MP202606M001), 계획기간(해당 월 1일~말일), 비고, 결재상태, 문서번호, 최종작업자·작업일시가 표시되며 ‘확정/미확정’ 상태를 가집니다. [계획버전 추가]·[결재상신]·[삭제] 버튼을 제공합니다.
  • ③ 2. 항목별 계획금액 입력 — 선택한 계획버전의 손익 항목별 계획금액입니다. 1.총매출액 ~ 5.영업이익의 5개 항목으로 구성되며, 매출액·매출원가는 사업부별로 펼쳐 볼 수 있습니다. [엑셀업로드]로 일괄 입력할 수 있습니다.
  • ④ 상세 그리드 — 선택한 항목(예: 총매출액)의 사업부·품목별 상세입니다. 순번/사업부/품목/규격/단위/판매계획수량/판매단가/매출액을 표시합니다. 상단 [월간영업계획 반영]으로 월간영업계획 수치를 가져오고, [마감]으로 항목을 마감합니다.

계획버전 추가

[계획버전 추가]를 클릭하면 ‘월간실행 계획버전 추가’ 팝업이 열립니다.

  • 계획월 — 조회 기준 연월이 기본값으로 표시됩니다.
  • 기간 — 계획 대상 기간(해당 월, 예: 2026-06-01 ~ 2026-06-30)을 선택합니다.
  • 비고 — 계획에 대한 설명을 입력합니다.
  • [저장] 시 새 계획버전이 생성되고, [취소] 시 입력 내용은 저장되지 않습니다.

마감 · 결재상신 · 삭제

  • 마감 — 항목별로 [마감]합니다. 마감 후에는 수정할 수 없으며 [마감취소]로 해제합니다.
  • 결재상신 — 전자결재를 사용하는 경우 [결재상신]으로 계획버전을 상신합니다.
  • 삭제 — 마감·결재 내역이 없는 계획버전만 [삭제]할 수 있습니다.

2.1. 연간 예산

회계연도(기준년도) 단위로 사업부·계정과목별 연간 예산을 수립·관리하는 화면입니다. 예산은 사업부별 원가(재료비·변동가공비·고정가공비)와 공통 판매관리비 계정과목으로 구성되며, 각 금액은 월(1~12월)별로 안분되어 관리됩니다. 화면은 [1. 계획버전] → [2. 항목별 예산]의 마스터-디테일 구조입니다.

연간경영계획의 매출원가·판관비 계획을 [연간경영계획반영]으로 그대로 가져와 예산을 수립할 수 있으며, 작성 완료 후 마감 → 확정 → 결재상신 순으로 예산을 확정합니다. 확정된 연간예산은 예산 모니터링(사전통제·사후관리)과 예산마감의 기준이 됩니다.

✅ 항목별 예산을 모두 [마감]해야 계획버전을 확정하거나 결재상신할 수 있습니다. 확정된 계획은 데이터가 잠겨 수정·삭제·마감취소가 불가합니다. 마감을 되돌리려면 [마감 취소], 확정을 되돌리려면 확정 취소를 먼저 해야 합니다.

💡 연간합계 금액을 입력하면 자동으로 12개월에 안분됩니다(소수점 절사, 차액은 마지막 월에 조정). 반대로 특정 월 금액을 수정하면 연간합계가 다시 계산됩니다.

🗂️ [연간경영계획반영]은 연간경영계획의 사업부별 재료비·변동가공비·고정가공비(월별)와 판매관리비 계정과목별 금액을 그대로 불러옵니다. 불러온 금액은 수정 불가로 처리됩니다. (반영한 문서는 ③ 항목별 예산 상단에 [반영문서]로 표시됩니다.)

① 조회조건

  • 기준년도: 조회할 회계연도를 선택합니다. [조회]를 클릭하면 해당 연도의 계획버전이 조회되고, [초기화]는 검색 조건을 되돌립니다.

② 1. 계획버전 (마스터)

기준년도별 연간예산 계획버전 목록입니다. 카드를 선택하면 우측 ③ 항목별 예산이 연동되어 표시됩니다. (화면 진입 시 최상단 버전이 자동 선택됩니다.)

  • 계획버전 추가: 새 예산 계획버전을 등록합니다. [연간예산 계획버전 추가] 팝업이 열립니다.
  • 결재상신: 작성·마감 완료한 버전을 결재 상신합니다. (마감되지 않은 항목이 있으면 결재상신이 불가합니다.)
  • 삭제: 선택한 계획버전을 삭제합니다. (미확정 상태이고 마감된 내역이 없는 버전만 삭제할 수 있습니다.)
  • 카드 정보: 계획번호(BUD+회기년도+Y+순번, 예: BUD2026Y001), 계획기간, 비고, 결재상태, 최종작업자·작업일시가 표시되며, 우측 상단에 [확정]/[미확정] 배지가 표시됩니다.

③ 2. 항목별 예산

선택한 계획버전의 사업부·계정과목별 월간 예산 그리드입니다. 사업부마다 재료비·변동가공비·고정가공비 3개 구분이 기본 생성되고, 하단에 공통 판매관리비 계정과목이 나열됩니다.

  • 연간경영계획반영: 연간경영계획의 금액을 불러옵니다. (선행 연간경영계획이 확정되어 있어야 사용할 수 있습니다.)
  • 마감 / 마감 취소: 항목별 예산을 마감하거나 마감을 취소합니다. 마감 후에는 금액 수정이 불가합니다.
  • 컬럼 — 사업부 / 구분(재료비·변동가공비·고정가공비) / 계정과목코드 / 계정과목 / 연간합계 / 1월~12월. 금액은 월별로 입력·안분됩니다.

⊙ 입력 예제

2.1.1. 계획버전 등록하기

[1. 계획버전] 영역의 [계획버전 추가] 버튼을 클릭하면 [연간예산 계획버전 추가] 팝업이 열립니다.

입력 항목

  • 계획년도: 예산을 수립할 회계연도를 선택합니다. (당 회기 연도가 기본값)
  • 기간: 선택한 연도의 1월 ~ 12월로 고정되어 표시됩니다.
  • 비고: 계획에 대한 설명을 입력합니다.

진행 순서: 계획년도 선택 → 비고 입력 → [추가]. 추가하면 새 계획버전이 [미확정] 상태로 생성됩니다.

2.1.2. 항목별 예산 입력하기

미확정 상태의 계획버전을 선택한 뒤 ③ 항목별 예산에 금액을 입력합니다. 입력 방법은 두 가지입니다.

  • 연간경영계획반영: [연간경영계획반영] 버튼으로 연간경영계획을 선택해 사업부별 원가·판관비 금액을 한 번에 불러옵니다. 불러온 금액은 수정할 수 없습니다.
  • 직접 입력: 사업부·계정과목별로 연간합계 또는 월별 금액을 직접 입력합니다. 연간합계를 입력하면 12개월로 자동 안분됩니다.

2.1.3. 마감 · 확정 · 결재상신

예산 입력을 마치면 마감 → 확정 → 결재상신 순으로 진행합니다.

  • 마감: ③ 항목별 예산의 [마감] 버튼으로 입력한 예산 항목을 마감합니다. (마감 후에는 금액 수정 불가)
  • 확정: 항목이 모두 마감되어야 계획버전을 확정할 수 있습니다. 확정 후에는 수정·삭제가 불가합니다.
  • 결재상신: 마감이 완료된 계획버전을 [결재상신]으로 결재 프로세스에 올립니다. 이미 확정되었거나 마감되지 않은 항목이 있으면 결재상신이 불가합니다.
▲ 맨 위

2.2. 월간 예산

2. 예산수립

2.2. 월간 예산

계획월(기준월) 단위로 사업부·계정과목별 월간 예산을 수립·관리하는 화면입니다. 연간 예산을 월 단위로 구체화한 실행 예산으로, 사업부별 원가(재료비·변동가공비·고정가공비)와 공통 판매관리비 계정과목으로 구성됩니다. 화면은 [1. 계획버전] → [2. 항목별 예산]의 마스터-디테일 구조입니다.

예산 입력을 마치면 마감 → 확정 → 결재상신 순으로 진행하며, 확정된 월간 예산은 예산 모니터링(사전통제·사후관리)과 예산마감의 기준이 됩니다.

✅ 항목별 예산을 [마감]해야 계획버전을 확정하거나 결재상신할 수 있습니다. 확정된 계획은 데이터가 잠겨 수정·삭제·마감취소가 불가하며, 한 계획월에는 확정 버전이 1개만 존재할 수 있습니다.

💡 계정과목별로 입력한 예산금액은 사업부별 합계 → 총 월간예산(합계)으로 자동 집계됩니다. 반대로 상단 [총 월간예산] 박스에서 합계·구분·사업부 라인을 선택하면 해당 기준의 금액이 우측 그리드에 표시됩니다.

🗂️ 계획번호는 BUD + 회기년도 + 월 + M + 순번 형식으로 자동 채번됩니다 (예: BUD202605M001).

① 조회조건

  • 기준월: 조회할 계획 연·월을 선택합니다. [조회]를 클릭하면 해당 월의 계획버전이 조회되고, [초기화]는 검색 조건을 되돌립니다.

② 1. 계획버전 (마스터)

기준월별 월간예산 계획버전 목록입니다. 카드를 선택하면 우측 ③·④ 영역에 해당 버전의 예산 내역이 연동되어 표시됩니다. (화면 진입 시 최상단 버전이 자동 선택됩니다.)

  • 계획버전 추가: 새 월간예산 계획버전을 등록합니다. [월간예산 계획버전 추가] 팝업이 열립니다.
  • 결재상신: 작성·마감 완료한 버전을 결재 상신합니다. (마감되지 않은 항목이 있으면 결재상신이 불가합니다.)
  • 삭제: 선택한 계획버전을 삭제합니다. (미확정 상태이고 마감된 내역이 없는 버전만 삭제할 수 있습니다.)
  • 카드 정보: 계획번호, 계획기간(해당 월 1일~말일), 비고, 결재상태, 최종작업자·작업일시가 표시되며, 우측 상단에 [확정]/[미확정] 배지가 표시됩니다.

③ 2. 항목별 예산

선택한 계획버전의 예산 집계 영역입니다. 좌측 [총 월간예산] 박스와 우측 [사업부별 예산합계] 그리드로 구성됩니다.

  • 총 월간예산(좌측 박스): 합계 금액과 구분별(재료비·변동가공비·고정가공비·판매관리비) 금액, 사업부별 금액이 트리로 표시됩니다. 라인을 선택하면 해당 기준의 상세가 ④에 표시됩니다.
  • 사업부별 예산합계(우측 그리드): 사업부 / 재료비·변동비·고정비·판관비 예산합계 / 예산합계 컬럼으로, 사업부별 원가·판관비 합계를 보여줍니다.
  • 엑셀업로드 / 마감: 예산을 엑셀로 일괄 업로드하거나, 입력한 항목별 예산을 마감합니다. (마감 후에는 금액 수정이 불가합니다.)

④ 예산상세내역

③에서 선택한 사업부·구분의 계정과목별 예산금액 목록입니다. 구분(재료비·변동가공비·고정가공비·판매관리비)별로 계정과목이 나열되며, 각 계정과목의 예산금액을 입력·확인합니다.

  • 컬럼 — 구분 / 계정과목코드 / 계정과목 / 예산금액 / 최종작업자 / 작업일시. 판매관리비 계정과목은 사용 중인 항목이 모두 나열됩니다.

⊙ 입력 예제

2.2.1. 계획버전 등록하기

[1. 계획버전] 영역의 [계획버전 추가] 버튼을 클릭하면 [월간예산 계획버전 추가] 팝업이 열립니다.

입력 항목

  • 기간: 선택한 계획월의 1일 ~ 말일로 고정되어 표시됩니다 (예: 2026-06-01 ~ 2026-06-30).
  • 비고: 계획에 대한 설명을 입력합니다.

  • 예산 입력: ④ 예산상세내역에서 계정과목별 예산금액을 직접 입력하거나, [엑셀업로드]로 예산을 일괄 등록합니다.

  • 확정: 항목이 모두 마감되어야 계획버전을 확정할 수 있습니다. 확정 후에는 수정·삭제가 불가합니다.
  • 결재상신: 마감이 완료된 계획버전을 [결재상신]으로 결재 프로세스에 올립니다. 이미 확정되었거나 마감되지 않은 항목이 있으면 결재상신이 불가합니다.

3.1. 예산모니터링(사전통제)

3. 예산집행

3.1. 예산모니터링(사전통제)

사전통제 대상 계정의 예산 집행 현황을 사업부·계정과목·월 단위로 실시간 모니터링하는 화면입니다. 집행금액이 예산에 도달하면 시스템이 추가 집행을 자동으로 차단(Block)합니다. 화면은 [1. 예산요약]과 [2. 예산집행현황]으로 구성됩니다.

집행 현황은 전월에 수립한 당월 [월간 예산]을 기준으로, 재무회계·구매에서 월 결산 후 집계된 실적·약정 금액을 반영해 산출됩니다.

✅ 집행금액 = 실적금액 + 약정금액 · 집행률 = 집행금액 ÷ 월 예산금액 · 잔여금액 = 월 예산금액 − 집행금액

⛔ 사전통제 항목은 집행률이 100%에 도달하면 자동으로 차단(Block)되어 추가 결재·지출이 불가합니다. 추가 집행이 필요하면 [예산증액신청 관리]에서 예산을 증액해야 합니다.

① 조회조건

  • 기준월: 조회할 연·월을 선택하고 [조회]를 클릭합니다. [초기화]는 검색 조건을 되돌립니다.

② 1. 예산요약

총 월간 예산과 구분별(재료비·변동가공비·고정가공비·판매관리비)·사업부별 예산합계가 트리로 표시되고, 우측 그리드에 사업부별 예산합계가 표시됩니다.

③ 2. 예산집행현황

계정과목별 예산 집행 현황 그리드입니다.

  • 컬럼 — 사업부 / 구분 / 계정코드 / 계정과목 / 월 예산금액 / 당월집행금액(실적금액·약정금액) / 집행률(%) / 잔여금액 / 상태 / 상태변경일자.
  • 상태가 주의·경고·차단이면 [상태] 값을 클릭해 [예산증액신청 관리] 화면으로 이동합니다.

⊙ 예산집행률 상태 구분

[2. 예산집행현황]의 [상태] 컬럼 머리글 옆 ⓘ 아이콘을 클릭하면 집행률 구간별 상태 기준이 표시됩니다.

  • 정상: 0% ~ 80% 미만 — 예산 범위 내에서 안정적으로 집행되고 있는 상태입니다.
  • 주의: 80% ~ 90% 미만 — 예산 소진 속도가 빠른 편이며, 월말까지 잔액 확인이 필요한 상태입니다.
  • 경고: 90% ~ 100% 미만 — 예산 소진이 임박해 추가 집행 시 승인 절차 강화가 권장되는 상태입니다.
  • 차단(Block): 100% 도달 — 사전통제 항목은 예산 전액 소진으로 추가 결재·지출이 불가합니다.

3. 예산집행

3.2. 예산증액신청 관리

사전통제 모니터링에서 차단(Block)·경고가 발생한 계정에 대해 예산 증액을 신청하고 결재하는 화면입니다. [예산모니터링(사전통제)]에서 [상태]를 클릭하면 해당 계정의 증액신청 라인이 자동 생성되어 이 화면으로 넘어옵니다.

증액신청이 결재 완료되면 해당 사업부·계정의 당월 예산이 증액되고, 집행률·상태가 자동으로 재계산됩니다.

📝 증액사유코드 — 물량급증 / 원가상승 / 협력사 이슈 / 시점차이 / 안전품질 / 기타 긴급 사유.

✅ 신청상태 — 작성중(수정·삭제 가능) → 결재중(편집 불가) → 승인(수정·삭제 불가). 반려된 건은 수정 후 재상신할 수 있습니다.

▲ 예시(목업) 데이터 — 실제 화면은 사전통제 모니터링에서 차단·경고 발생 시 해당 계정의 증액신청 라인이 자동 생성됩니다.

① 조회조건

  • 기준월: 조회할 연·월을 선택합니다.

② 기능 버튼

  • 수정: 선택한 증액신청 건의 [증액 신청서]를 작성·수정합니다. (품의 ID·신청자·대상기간·대상 CC·대상 계정·기존 월예산·잔여금액·집행률은 자동 표시, 추가요청 금액·사유·첨부·결재선은 신청자가 입력)
  • 결재상신: 작성한 증액신청을 결재 프로세스에 올립니다. 삭제 / 다운로드(엑셀)도 제공됩니다.

③ 그리드

  • 컬럼 — 사업부 / 코스트센터 / 구분 / 계정코드 / 계정과목 / 월 예산금액 / 당월집행금액(실적금액·약정금액) / 집행률(%) / 잔여금액 / 증액신청정보(증액신청일·신청부서·신청자·증액신청금액·증액사유·비고) / 신청상태 / 문서번호.

💡 위 목록은 이해를 돕기 위한 예시(목업) 데이터입니다. 실제로는 사전통제 모니터링에서 차단·경고가 발생하면 해당 계정의 증액신청 라인이 자동으로 생성됩니다.

▲ 맨 위

3.3. 예산모니터링(사후관리)

3. 예산집행

3.3. 예산모니터링(사후관리)

사후관리 대상 계정의 예산 집행 현황을 사업부·계정과목·월 단위로 모니터링하는 화면입니다. 사전통제와 달리 집행을 사전에 차단하지 않고, 월말 결산 후 예산 대비 집행 실적을 분석합니다. 집행률이 100%를 초과하면 [초과] 상태가 되어 초과 사유 보고가 필요합니다.

화면 구성은 [예산모니터링(사전통제)]와 동일하며([1. 예산요약] + [2. 예산집행현황]), 대상 계정만 사후관리 항목이라는 점이 다릅니다.

✅ 집행금액 = 실적금액 + 약정금액 · 집행률 = 집행금액 ÷ 월 예산금액 · 잔여금액 = 월 예산금액 − 집행금액

⚠️ 사후관리 항목은 집행을 차단하지 않습니다. 집행률 100% 초과 시 [초과] 상태가 되며, [상태]를 클릭하면 [예산초과집행 사유관리]로 이동해 초과 사유를 소명합니다.

① 조회조건

  • 기준월: 조회할 연·월을 선택합니다.

② 1. 예산요약

총 월간 예산과 구분별·사업부별 예산합계 트리, 우측 사업부별 예산합계 그리드로 구성됩니다.

③ 2. 예산집행현황

  • 컬럼 — 사업부 / 구분 / 계정코드 / 계정과목 / 월 예산금액 / 당월집행금액(실적금액·약정금액) / 집행률(%) / 잔여금액 / 상태 / 상태변경일자. 집행률 100% 초과 행은 [초과]로 표시됩니다.

⊙ 예산집행률 상태 구분

[2. 예산집행현황]의 [상태] 컬럼 머리글 옆 ⓘ 아이콘을 클릭하면 집행률 구간별 상태 기준이 표시됩니다.

  • 정상: 0% ~ 80% 미만 — 예산 범위 내에서 안정적으로 집행되고 있는 상태입니다.
  • 주의: 80% ~ 90% 미만 — 예산 소진 속도가 빠른 편이며, 월말까지 잔액 확인이 필요한 상태입니다.
  • 경고: 90% ~ 100% 미만 — 예산 소진이 임박해 추가 집행 시 승인 절차 강화가 권장되는 상태입니다.
  • 초과(Exceeded): 100% 초과 — 사후관리 항목은 예산을 초과하여 집행된 상태로, 초과 사유 보고가 필요합니다.

3.4. 예산초과집행 사유관리

사후관리 모니터링에서 집행률 100%를 초과한 계정의 초과 사유를 소명·관리하는 화면입니다. [예산모니터링(사후관리)]에서 [초과] 상태를 클릭하면 해당 계정의 소명 라인이 자동 생성되어 이 화면으로 넘어옵니다.

초과가 발생한 부서의 예산 담당자가 초과 사유코드·상세 사유·증빙·재발방지 조치를 입력하고 결재 상신합니다.

📝 초과사유코드 — 물량급증 / 원가상승 / 협력사 이슈 / 시점차이 / 안전품질 / 기타 긴급 사유.

▲ 예시(목업) 데이터 — 실제 화면은 사후관리 모니터링에서 집행률 100% 초과 발생 시 해당 계정의 소명 라인이 자동 생성됩니다.

① 조회조건

  • 기준월: 조회할 연·월을 선택합니다.

② 기능 버튼

  • 다운로드: 현재 목록을 엑셀로 내려받습니다. 결재상신: 작성한 초과 사유 소명을 결재 상신합니다.

③ 그리드

  • 컬럼 — 사업부 / 코스트센터 / 구분 / 계정코드 / 계정과목 / 월 예산금액 / 당월집행금액(실적금액·약정금액) / 집행률(%) / 초과금액 / 초과사유 정보(사유입력일자·입력부서·작성자·초과사유).
  • 초과사유 정보는 초과가 발생한 부서의 담당자가 직접 입력하며, 라인별로 저장 시 입력 일자가 자동 저장됩니다.

💡 위 목록은 이해를 돕기 위한 예시(목업) 데이터입니다. 실제로는 사후관리 모니터링에서 집행률 100% 초과가 발생하면 해당 계정의 소명 라인이 자동으로 생성됩니다.
