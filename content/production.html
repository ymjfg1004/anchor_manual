1.1. 공장관리

생산 활동이 이루어지는 공장을 등록하고 관리하는 화면입니다.

등록된 공장은 [생산관리] - [기준정보] - [창고관리], [생산관리] - [기준정보] - [작업장관리], [생산관리] - [기준정보] - [설비관리] 등 하위 기준정보의 소속 단위가 됩니다.

✅ 공장 코드는 등록 시 자동 부여되며, 직접 입력하거나 수정할 수 없습니다.

📅 공장캘린더는 사전에 [생산관리]-[기준정보]-[캘린더관리]에서 등록한 캘린더 중에서 선택합니다.

공장관리 메뉴 진입 화면

① 기능 버튼

  • 등록: 새로운 공장을 등록합니다. [공장 상세] 팝업이 열립니다.
  • 수정: 리스트에서 공장을 선택(체크박스 클릭)한 후 활성화됩니다. 선택한 공장의 [공장 상세] 팝업이 열려 정보를 수정할 수 있습니다.
  • 삭제: 리스트에서 선택한 공장을 삭제합니다. 하위 기준정보(작업장·창고·설비 등)가 공장에 연결되어 있으면 삭제되지 않을 수 있습니다.
  • 다운로드: 현재 리스트 내역을 엑셀 파일로 내려받습니다.
  • 업로드: 엑셀 파일을 업로드하여 공장을 일괄 등록할 수 있습니다.

② 검색 영역

  • 전체: 검색 기준 컬럼을 선택합니다. 기본값은 ‘전체’이며 공장코드/공장명 등 특정 컬럼을 지정할 수 있습니다.
  • 전체 검색: 입력한 키워드로 리스트를 필터링합니다.

③ 리스트 영역

  • 공장코드: 시스템이 자동 부여한 공장 고유 식별 코드 (예: PLT001).
  • 공장명: 사용자가 입력한 공장의 이름.
  • 주소: 공장의 우편번호·도로명 주소·상세주소가 결합되어 표시됩니다.
  • 캘린더: 공장에 적용된 운영 캘린더 (영업일·휴무일 기준). 생산일정·납기 계산에 사용됩니다.

⊙ 입력 예제

1.1.1. 새로운 공장 등록하기

리스트 화면에서 [등록] 버튼을 클릭하면 [공장 상세] 팝업이 열립니다.

공장 상세 - 등록 팝업

입력 항목

  • ① 공장코드: 자동 부여됩니다. 저장 시 시스템이 PLT001, PLT002 형식으로 채번하며 직접 입력할 수 없습니다.
  • ② 공장명 *: 등록할 공장의 이름을 입력합니다. (필수)
  • ③ 공장주소 *: [우편번호 검색] 돋보기 버튼을 눌러 주소를 검색한 후, 아래 [상세주소 입력]란에 동·호수 등 상세 주소를 추가 입력합니다. (필수)
  • ④ 공장캘린더 *: 드롭다운에서 사전에 등록된 공장 운영 캘린더를 선택합니다. (필수) ※ 사용할 캘린더가 없다면 먼저 [생산관리]-[기준정보]-[캘린더관리]에서 등록해야 합니다.
  • ⑤ 사용여부 *: 등록한 공장의 사용 여부를 설정합니다. 기본값은 [사용] 상태이며, 미사용으로 전환하면 다른 화면의 공장 선택지에서 노출되지 않습니다.

진행 순서: ② 공장명 입력 → ③ 공장주소 검색 + 상세 입력 → ④ 공장캘린더 선택 → [저장] 클릭

※ 필수 항목(*)을 모두 입력하지 않으면 [저장] 버튼이 비활성화되거나 저장 시 안내 메시지가 표시됩니다.

1.1.2. 등록된 공장 정보 수정하기

이미 등록된 공장의 이름·주소·캘린더 등을 변경하려면 리스트에서 해당 공장을 선택한 후 수정합니다.

공장 상세 - 수정 팝업 (PLT001 기본 공장)

진행 순서: 리스트에서 수정할 공장의 체크박스 선택 → [수정] 버튼 클릭 → [공장 상세] 팝업에서 변경할 값 입력 → [저장] 클릭

수정 팝업 동작 특징

  • ① 공장코드는 수정할 수 없습니다.
  • 기존에 저장된 값은 그대로 표시되며, 변경하고 싶은 항목만 갱신한 후 저장하면 됩니다.
  • 취소 시 안내 팝업이 한 번 더 표시되며, [확인]을 누르면 변경 내용 없이 닫힙니다.

1.2. 교대패턴관리

공장의 근무 시간대(교대 패턴)를 등록하고 관리하는 화면입니다.

등록된 교대 패턴은 [생산관리] - [기준정보] - [캘린더관리] 등에서 공장·작업장 운영 시간 계산의 기준으로 사용됩니다.

✅ 교대근무ID는 등록 시 자동 부여되며, 직접 입력하거나 수정할 수 없습니다.

🕒 교대 패턴 한 건은 [교대 패턴 마스터(상단 그리드)] + [교대근무 조 상세(하단 그리드)]로 구성됩니다. 상단에서 패턴을 선택하면 하단에 해당 패턴의 조별 근무·휴게 시간이 표시됩니다.

⚙️ 교대구분(1교대/2교대/3교대) 선택에 따라 등록·수정 팝업의 근무시간 입력 영역이 동적으로 바뀝니다. 1교대는 1개 조, 2교대는 주간·야간 2개 조(각 조 휴게시간 1·2 선택 가능), 3교대는 Day·Evening·Night 3개 조 입력 폼이 표시됩니다.

교대패턴관리 메뉴 진입 화면

① 기능 버튼

  • 등록: 새로운 교대 패턴을 등록합니다. [교대패턴 상세] 팝업이 열립니다.
  • 수정: 상단 그리드에서 패턴을 선택(체크박스 클릭)한 후 활성화됩니다. 선택한 패턴의 [교대패턴 상세] 팝업이 열립니다.
  • 삭제: 상단 그리드에서 선택한 패턴을 삭제합니다. 다른 기준정보에서 사용 중인 패턴은 삭제되지 않을 수 있습니다.

② 검색 영역

  • 검색기준: 검색 대상 컬럼을 선택합니다. 기본값은 ‘전체’.
  • 검색: 입력한 키워드로 리스트를 필터링합니다.

③ 교대 패턴 그리드 (상단)

  • 교대근무코드: 자동 부여된 교대 패턴 고유 코드 (예: SHT001).
  • 교대근무 명: 패턴의 이름 (예: ‘1교대 근무’).
  • 교대근무 설명: 패턴에 대한 부연 설명.

④ 교대근무 상세정보 그리드 (하단)

  • 교대근무 조: 패턴 내 각 조의 이름. 교대구분에 따라 상시조 / 주간조·야간조 / Day·Evening·Night 등으로 표시됩니다.
  • 근무시간: 해당 조의 근무 시작 ~ 종료 시각.
  • 휴게시간1: 근무 시간 안에 설정된 휴게 구간. 2교대 패턴의 경우 휴게시간2까지 추가로 설정할 수 있습니다.

상단 그리드에서 선택한 패턴에 매핑된 조별 근무 정보가 자동으로 표시됩니다.

⊙ 입력 예제

1.2.1. 새로운 교대 패턴 등록하기

리스트 화면에서 [등록] 버튼을 클릭하면 [교대패턴 상세] 팝업이 열립니다. 기본값은 ‘1교대’ 상태이며 1개 조의 근무·휴게 시간을 입력합니다.

교대패턴 상세 - 등록 팝업 (기본: 1교대)

공통 입력 항목

  • ① 교대근무ID: 자동 부여됩니다. 저장 시 시스템이 SHT001, SHT002 형식으로 채번하며 직접 입력할 수 없습니다.
  • ② 교대패턴명 *: 등록할 교대 패턴의 이름을 입력합니다. (필수) 예: ‘1교대 근무’, ‘주간 2교대’
  • ③ 교대패턴설명: 패턴에 대한 부연 설명을 자유롭게 입력합니다. 여러 줄 입력이 가능합니다.
  • ④ 교대구분: 하루 몇 교대 체계인지 선택합니다. 기본값은 ‘1교대’이며, 1교대 / 2교대 / 3교대 중에서 선택합니다. 선택값에 따라 아래 근무시간 영역(⑤·⑥)의 입력 항목이 자동으로 바뀝니다.
  • ⑤·⑥ 근무시간 / 휴게시간: 교대구분에 따라 다른 형태로 표시됩니다. 아래 1.2.2 ~ 1.2.4 참고.

※ 휴게시간은 근무시간 범위 안에 포함되어야 합니다.

1.2.2. 교대구분 선택

교대구분 드롭다운을 클릭하면 다음 3가지 옵션이 표시됩니다.

교대구분 드롭다운 - 1교대 / 2교대 / 3교대

  • 1교대: 하루 1개 조가 근무하는 패턴. 기본값. (예: 일반 사무직 9 to 6)
  • 2교대: 하루 2개 조(주간·야간)가 교대로 근무하는 패턴. 각 조에 휴게시간 1·2까지 설정 가능.
  • 3교대: 하루 3개 조(Day·Evening·Night)가 8시간씩 교대로 근무하는 패턴.

1.2.3. 2교대 패턴 입력

교대구분에서 ‘2교대’를 선택하면 근무시간 입력 영역이 주간조·야간조 두 행으로 확장됩니다. 각 조에는 휴게시간을 최대 2개까지 설정할 수 있습니다.

교대구분 = 2교대 선택 시 입력 영역

  • ① 교대구분: ‘2교대’ 선택 상태.
  • ② 주간조 근무시간: 주간 조의 시작 ~ 종료 시각. 예: 08:00 ~ 20:00
  • ③ 휴게시간1 (주간조): 주간조의 첫 번째 휴게 구간. 우측 체크박스가 활성화된 상태로 기본 표시됩니다.
  • ④ 휴게시간2 (주간조): 주간조의 두 번째 휴게 구간. 우측 체크박스를 켜야 시간이 적용됩니다. 필요 없으면 체크 해제.
  • ⑤ 야간조 근무시간: 야간 조의 시작 ~ 종료 시각. 예: 18:00 ~ 09:00 (다음 날까지 이어지는 경우 자동 처리)
  • ⑥ 휴게시간1 (야간조): 야간조의 첫 번째 휴게 구간. 예: 00:00 ~ 01:00
  • ⑦ 휴게시간2 (야간조): 야간조의 두 번째 휴게 구간. 체크박스로 활성/비활성 전환.

1.2.4. 3교대 패턴 입력

교대구분에서 ‘3교대’를 선택하면 근무시간 입력 영역이 Day·Evening·Night 세 행으로 확장됩니다. 각 조에는 휴게시간 1개씩만 설정할 수 있습니다.

교대구분 = 3교대 선택 시 입력 영역

  • ① 교대구분: ‘3교대’ 선택 상태.
  • ② Day조 근무시간: 주간 첫 번째 조. 예: 07:00 ~ 15:00
  • ③ Day조 휴게시간: Day조의 휴게 구간. 예: 12:00 ~ 13:00
  • ④ Evening조 근무시간: 저녁 조. 예: 15:00 ~ 23:00
  • ⑤ Evening조 휴게시간: Evening조의 휴게 구간. 예: 19:00 ~ 20:00
  • ⑥ Night조 근무시간: 야간 조 (다음 날 새벽까지). 예: 23:00 ~ 07:00
  • ⑦ Night조 휴게시간: Night조의 휴게 구간. 예: 03:00 ~ 04:00

※ 2교대와 달리 3교대 패턴에서는 각 조의 휴게시간이 1개로 고정됩니다. 더 세분화된 휴게 운영이 필요한 경우 1교대·2교대 패턴을 여러 개 등록해 작업장별로 매핑하는 방식을 검토하세요.

1.2.5. 등록된 교대 패턴 수정하기

수정 팝업 동작 특징

  • 교대구분을 다른 값으로 바꾸면 근무시간 입력 영역이 위 1.2.2 ~ 1.2.4와 같이 새 형태로 전환됩니다.

🔀 평일 클릭 시: 4가지 휴일 종류(공휴일/주휴일/직접입력/전사휴무) 중 하나를 선택해 휴일로 변경할 수 있습니다.

  • ② 휴일 구분: 휴일 종류를 라디오로 선택합니다. 옵션은 4가지.
  • • 공휴일: 신정·설날·추석 등 법정 공휴일. 빨간색 표시.

  • └ 각 옵션 오른쪽 [휴무일명 직접 입력] 칸에 휴무일 이름을 입력합니다. 입력한 이름은 연간 캘린더에서 마우스 오버 시 툴팁으로 표시됩니다.

일정 상세 (휴일 클릭) - 휴일 종류 5개 옵션 (+근무일)

화면 구성

  • ① 일자: 클릭한 휴일의 일자. (예: 2026-01-03 ~ 2026-01-03)
  • ② 휴일 구분: 현재 지정된 휴일 종류가 선택되어 표시됩니다. (예: ‘주휴일’ 선택, 휴무일명 ‘토요일’)
  • • 공휴일 / 주휴일 / 직접입력 / 전사휴무: 평일 클릭 시와 동일한 4가지 휴일 종류. 다른 옵션을 선택하면 해당 휴일의 종류·이름이 변경됩니다.
  • • 근무일: 휴일을 정상 근무일로 되돌립니다. 휴일 클릭 시에만 추가로 노출되는 옵션입니다.

  • ② 창고명 *: 등록할 창고의 이름을 입력합니다. (필수) 예: ‘기본창고’, ‘기본공장_원재료창고’
  • ③ 공장 *: 드롭다운에서 해당 창고가 소속될 공장을 선택합니다. (필수) ※ 공장이 미등록이면 옵션이 없으므로 [공장관리]에서 먼저 등록.
  • ④ 창고유형 *: 드롭다운에서 창고의 보관 용도를 선택합니다. (필수) 옵션은 아래 1.4.2 참고.
  • ⑤ 최대보관량: 창고에서 최대 보관 가능한 수량(또는 중량)을 입력합니다. placeholder 안내대로 ‘500EA’, ‘50KG’ 같은 형식으로 단위와 함께 입력합니다.

진행 순서: ② 창고명 입력 → ③ 공장 선택 → ④ 창고유형 선택 → ⑤ 최대보관량 입력(선택) → [저장] 클릭

※ 필수 항목(*)을 모두 입력하지 않으면 저장 시 안내 메시지가 표시됩니다.

창고유형 드롭다운 - 7개 옵션

  • 완제품 창고: 생산 완료된 완제품 보관.

1.5. 설비관리

생산 활동에 사용되는 설비를 등록하고 관리하는 화면입니다.

등록한 설비는 [생산관리] - [기준정보] - [작업장관리] 에서 작업장에 연결되어 가동시간·표준 셋업시간 등의 산정에 사용되며, 고정자산 정보와도 연동됩니다.

✅ 설비코드는 등록 시 우측 ‘자동’ 체크박스가 켜져 있으면 시스템이 자동 채번(FC00000001~)합니다. 직접 입력하려면 체크를 해제하고 최대 10자리까지 입력합니다.

🗂️ 설비 등록 팝업은 [기본정보 / 추가정보] 두 개의 탭으로 구성됩니다. 기본정보 탭은 고정자산·담당자 정보, 추가정보 탭은 설치일자·모델·제조사 등 물리 정보입니다.

⚠️ 작업장에 연결된 설비는 삭제할 수 없습니다. 삭제 가능한 설비를 지우면 연동된 고정자산도 자동으로 해제됩니다.

설비관리 메뉴 진입 화면

① 기능 버튼

  • 등록: 새로운 설비를 등록합니다. [설비 등록] 팝업이 열립니다.
  • 수정: 리스트에서 설비를 선택(체크박스 클릭)한 후 활성화됩니다. 선택한 설비의 [설비 등록] 팝업이 기존 값으로 채워져 열립니다.
  • 삭제: 리스트에서 선택한 설비를 삭제합니다. 작업장에 등록된 설비는 삭제되지 않고 안내 팝업이 표시됩니다.
  • 다운로드: 현재 리스트 내역을 엑셀 파일로 내려받습니다.
  • 업로드: 엑셀 파일을 업로드해 설비를 일괄 등록할 수 있습니다.

② 검색 영역

  • 검색 기준 드롭다운 + 키워드 검색: 설비코드·설비명 등 컬럼별로 필터링할 수 있습니다.

③ 리스트 영역

  • 설비코드 / 설비명: 설비의 고유 코드와 이름.
  • 소속공장 / 작업장: 해당 설비가 배치된 공장과 작업장. 작업장 화면에서 설비를 연결하면 자동으로 채워집니다.
  • 담당사원 / 담당부서: 설비 운영을 담당하는 사원과 부서.
  • 고정자산정보 (계정코드·계정과목·자산코드 등): 회계 모듈의 고정자산과 연결된 정보. 등록 시 [기본정보] 탭에서 매핑.

  • ② 설비명 *: 설비의 이름을 입력합니다. 텍스트+숫자 최대 50자.
  • ③ 사용여부 *: 토글. 기본값 ‘사용’. 미사용으로 전환하면 작업장 매핑·생산 실적 입력 등에서 선택지에 노출되지 않습니다.

  • ⑧ 경비구분: 드롭다운에서 선택. 기본값 ‘제조원가’.
  • ⑨ 담당사원 / 담당부서: 설비 운영 담당자를 검색 팝업으로 선택합니다.

1.6. 불량/반품코드관리

생산·구매·외주 과정에서 발생하는 불량과 반품 사유를 코드로 등록·관리하는 화면입니다.

🚫 시스템이 기본 제공하는 불량코드는 삭제되지 않고 ‘사용안함’으로 자동 전환됩니다. 사용자가 추가한 불량코드만 직접 삭제할 수 있고, 그 코드로 등록된 실적이 있으면 삭제 대신 ‘미사용 처리’로 안내됩니다.

① 기능 버튼

  • 등록: 새로운 불량코드를 등록합니다. [불량코드 등록] 팝업이 열립니다.

  • 삭제: 리스트에서 선택한 불량코드를 삭제합니다. 시스템 기본 코드 또는 실적이 있는 코드는 ‘사용안함’ 처리로 대체됩니다.
  • 다운로드: 현재 리스트 내역을 엑셀 파일로 내려받습니다.
  • 업로드: 엑셀 파일을 업로드해 불량코드를 일괄 등록할 수 있습니다.

② 검색 영역

  • 검색기준: 검색 대상 컬럼을 선택합니다. 기본값은 ‘전체’.
  • 전체 검색: 입력한 키워드로 리스트를 필터링합니다.

③ 리스트 영역

  • 불량코드: 시스템이 부여한 고유 코드 (예: DEF001).
  • 불량명: 불량 유형 이름 (예: ‘치수 불량’, ‘용접 불량’, ‘도장 불량’).
  • 설명: 해당 불량 유형의 정의/판정 기준.
  • 예시: 구체적인 불량 사례 (예: ‘길이 짧음, 홀 작음, 홀 안 맞음, 두께 오버, 평행도 불량, …’).
  • 생산불량: 생산 공정에서의 사용 구분 — 정상불량 / 비정상불량 / 사용안함 중 하나.
  • 구매불량: 구매(입고 검수)에서 이 코드를 사용할지 여부 (○ = 사용 / 빈칸 = 사용안함).
  • 외주불량: 외주 양품 확정에서 이 코드를 사용할지 여부 (○ = 사용 / 빈칸 = 사용안함).
  • 사용여부: 이 불량코드의 전반적 활성/비활성 상태.

  • ④ 예시: 구체적인 불량 사례를 콤마로 구분해 나열합니다. 예: ‘길이 짧음, 홀 작음, 두께 오버’
  • ⑤ 생산불량 사용여부: 생산 공정에서 이 불량코드를 어떻게 사용할지 라디오로 선택합니다.
  • • 정상불량: 생산 진행 중 흔히 발생하는 통상 불량. 일반 실적에 반영.
  • • 비정상불량: 예외 사유로 발생한 불량. 별도 분석 대상.
  • • 사용안함: 생산 공정에서는 이 코드를 사용하지 않음.
  • ⑥ 구매불량 사용여부: 구매(입고 검수)에서 이 불량코드를 사용할지 선택. 사용 / 사용안함.
  • ⑦ 외주불량 사용여부: 외주 양품 확정에서 이 불량코드를 사용할지 선택. 사용 / 사용안함.

진행 순서: ② 불량코드명 입력 → ③ 설명 / ④ 예시 입력(선택) → ⑤·⑥·⑦ 사용 여부 라디오 선택 → [저장] 클릭

※ 같은 불량코드를 [생산·구매·외주] 세 영역에서 동시에 사용할 수도 있고, 일부 영역에서만 ‘사용안함’으로 설정해 노출되지 않게 할 수도 있습니다.

1.5.2. 등록된 불량코드 수정하기

이미 등록된 불량코드의 이름·설명·예시·사용 여부를 변경하려면 리스트에서 해당 코드를 선택한 후 수정합니다.

불량코드 수정 팝업 (DEF001 치수 불량)

진행 순서: 리스트에서 수정할 불량코드의 체크박스 선택 → [수정] 버튼 클릭 → 변경할 값 입력 → [저장] 클릭

수정 팝업 동작 특징

  • 불량코드는 수정할 수 없습니다.
  • 기존에 저장된 값은 그대로 표시되며, 변경하고 싶은 항목만 갱신한 후 저장하면 됩니다.
  • ‘사용안함’으로 전환하면 다른 화면(생산 실적/구매 검수/외주 양품 확정 등)의 불량코드 선택지에서 노출되지 않습니다.

1.5.3. 불량코드 삭제 동작

불량코드를 삭제하려고 하면 시스템이 자동으로 다음과 같이 처리합니다.

  • 사용자가 직접 추가한 코드 + 실적이 없는 경우: 실제로 삭제됩니다.
  • 시스템 기본 제공 코드 (예: DEF001~DEF014): 삭제되지 않고 ‘사용안함’으로 자동 전환됩니다.
  • 실적이 등록된 코드: 삭제되지 않습니다. 안내 팝업 — “업무에 사용된 불량코드는 삭제할 수 없습니다. 미사용 처리 하시겠습니까?” — 에서 [확인] 시 ‘사용안함’으로 전환.

삭제 시 표시되는 결과 안내

  • ‘삭제 처리: x건 / 미사용 처리: x건’ 형태로 두 가지 처리 결과가 분리 표시됩니다.

1.7. 작업장관리

개요

작업장(Work Center)은 생산이 실제로 수행되는 가장 기본적인 조직 단위입니다 — 사람(작업자)·기계(설비) 또는 작업이 이뤄지는 장소를 정의합니다. 공정(라우팅)에 연결되어 ① 생산능력·일정 계획 ② 제조원가(가공비) 산정의 핵심 기준이 됩니다.

🏭 작업장은 ‘자원을 정의하는 곳’입니다. 특정 제품의 표준 작업시간은 [공정/작업]에서, 실제 작업시간은 [생산지시서]에서 기록합니다. 작업장에는 시간당 생산량(UPH)·효율·세팅시간·원가 귀속(코스트센터) 등 ‘기본값’만 둡니다.

핵심 개념 — 작업장유형 × 생산능력 집계구분

작업장은 두 축으로 분류됩니다. 이 두 값이 입력 폼의 하위 필드를 결정합니다.

① 작업장유형 (외주여부 + 외주구분으로 결정)

작업장유형 외주여부 / 외주구분 의미 집계구분 선택
자체작업 부 사내 인력·설비로 직접 생산 사람/기계/혼합 가능
사내외주 여 / 사내 사내에 입주한 외주(도급) — 자체작업과 동일하게 운영 사람/기계/혼합 가능
사외외주 여 / 사외 외부 업체에 위탁 — 외주거래처·외주창고로 관리 선택 없음 (외주)

② 생산능력 집계구분 (가용시간을 무엇으로 집계하는가)

집계구분 추가 입력 의미
사람 (LAB) 부서선택 + 표준노무세팅시간 + 근태율 작업자(인원) 기준 가용시간
기계 (MACH) 설비선택 + 표준설비세팅시간 + 가동율 설비(기계) 기준 가용시간
혼합 (MIX) 위 두 가지 모두 사람 + 설비 둘 다 사용

화면 진입

좌측 사이드바 [생산관리] ▸ [기준정보] ▸ [작업장관리]

목록 화면

작업장관리 목록 — 4개 작업장(자체작업 3 + 사외외주 1)

  • ① 기능 버튼 — [복사 등록] / [등록] / [수정] / [삭제] / [다운로드] / [업로드]
  • ② 목록 그리드 — 한 행이 작업장 1건. 작업장코드 / 작업장명 / 작업장유형 / 소속공장 / 기본 창고 / 코스트센터 / 작업장 생산달력 / 교대코드 / 생산능력 집계구분 / (집계구분별) 세팅시간·근태율·근무인원수·설비수·가동율 / 생산효율 / 표준·정격 UPH / 대기·이동시간 / 기본 스크랩

신규 등록 — 기본 입력 폼

상단 [등록] 클릭 → ‘작업장 상세’ 팝업이 열립니다.

작업장 상세 — 신규 빈 폼 (집계구분 미선택 상태)

  • ① 작업장 코드 — [자동] 체크 시 자동 채번. 해제하면 직접 입력.
  • ② 소속공장 / 코스트센터 — 코스트센터는 검색 팝업으로 선택. 선택 결과가 외주여부를 자동 결정합니다(아래 참조).
  • ③ 외주여부 — 여 / 부. 코스트센터 선택에 따라 자동 세팅되며, 사용자가 직접 바꿀 수도 있습니다.
  • ④ 생산능력 집계구분 — 사람 / 기계 / 혼합. 선택 전에는 하위 입력 영역이 나타나지 않습니다.
  • 하단 공통 — 교대코드 / 작업장 생산달력 / 생산효율(%) / 표준UPH / 정격UPH / 대기시간(m) / 이동시간(m) / 기본 스크랩(%)

코스트센터 선택 — 내부 vs 외주

코스트센터 검색(돋보기) → ‘코스트센터 조회’ 팝업. 유형 컬럼으로 직접/간접/판관/직접(외주)을 구분합니다.

코스트센터 조회 — 유형 컬럼(직접/간접/판관/직접(외주))

  • ① 유형 — 직접 / 간접 / 판관 / 직접(외주). 작업장에는 ‘직접’ 또는 ‘직접(외주)’ 코스트센터를 연결합니다.
  • 직접(외주) 코스트센터(예: COC012 도장외주)는 외주거래처가 연결되어 있어, 선택 시 작업장이 자동으로 외주 작업장으로 전환됩니다.

외주 코스트센터 자동 맵핑

외주 코스트센터를 선택하면 외주 관련 필드가 자동으로 채워집니다.

외주 CC(COC012 도장외주) 선택 → 외주여부 자동 ‘여’ + 외주거래처 자동 맵핑

  • ① 코스트센터 = 직접(외주) 유형 선택
  • ② 외주여부 자동 ‘여’ 체크 + 외주구분(사내/사외) 입력란 표시
  • ③ 외주거래처 자동 맵핑 — 코스트센터에 연결된 거래처(예: V-001 도장외주㈜)가 자동 입력됨

🔄 반대로, 외주가 아닌 코스트센터(직접/간접)를 선택하면 외주여부가 자동 ‘부’로 바뀌고 외주거래처·외주창고 입력란이 사라집니다.

입력 케이스 ① 사람 (자체작업·사내외주)

외주여부 ‘부’(자체작업) 또는 ‘여/사내’(사내외주)에서 생산능력 집계구분을 사람으로 선택하면 부서 기반 입력란이 나타납니다.

사람 케이스 (WKC002 조립작업장) — 부서선택 + 표준노무세팅시간 + 근태율

  • ① 생산능력 집계구분 = 사람
  • ② 부서선택 테이블 — [추가]로 부서 연결. 부서코드 / 부서명 / 인원수. 한 부서는 한 작업장에만 연결됩니다.
  • ③ 표준노무세팅시간(m) / 근태율(%) — 노무 가용시간·세팅시간 계산에 사용

[추가] 클릭 시 ‘부서 조회’ 팝업 — 해당 코스트센터 하위 부서 중 다른 작업장에 연결되지 않은 부서만 표시됩니다.

입력 케이스 ② 기계 (자체작업·사내외주)

생산능력 집계구분을 기계로 선택하면 설비 기반 입력란이 나타납니다.

기계 케이스 (WKC004 포장설비작업장) — 설비선택 + 표준설비세팅시간 + 가동율

  • ① 생산능력 집계구분 = 기계
  • ② 설비 테이블 — [추가]로 설비 연결. 설비코드 / 설비명 / 모델명 / 시리얼No.
  • ③ 표준설비세팅시간(m) / 가동율(%) — 설비 가용시간·세팅시간 계산에 사용

입력 케이스 ③ 혼합 (사람 + 기계)

생산능력 집계구분을 혼합으로 선택하면 설비 + 부서 입력란이 모두 나타납니다.

혼합 케이스 — 설비 테이블 + 부서선택 테이블 둘 다 + 표준설비/노무 세팅시간·가동율·근태율

  • ① 생산능력 집계구분 = 혼합
  • ② 설비 테이블 + 표준설비세팅시간 + 가동율
  • ③ 부서선택 테이블 + 표준노무세팅시간 + 근태율

입력 케이스 ④ 사외외주

외주여부 ‘여’ + 외주구분 ‘사외’인 경우. 생산능력 집계구분(사람/기계/혼합)은 선택하지 않으며, 대신 외주거래처·외주창고를 입력합니다.

사외외주 케이스 (WKC003 도장작업장) — 외주거래처 + 외주창고, 집계구분 없음

  • ① 외주여부 ‘여’ / 외주구분 ‘사외’ (외주 CC 선택 시 외주여부는 잠금)
  • ② 외주거래처 + 외주창고 — 외주창고는 필수입력. 입고/출고 전표가 이 외주창고로 자동 작성됩니다.

⚠️ 외주창고 미입력 시 저장 차단 — ‘외주작업장 등록 시 외주창고는 필수입력값입니다. 외주창고를 등록 후 다시 시도해주세요.’ a가 표시됩니다. 외주창고가 없다면 [창고관리]에서 먼저 외주창고를 등록하세요.

1.8. 생산품목관리

생산 관점에서 품목의 안전재고량·창고·리드타임·Lot크기·조달유형 등을 일괄 설정·변경하는 화면입니다.

⚠️ 이 화면에서는 품목을 새로 등록할 수 없습니다. 품목 자체는 [기초정보]-[정보관리]-[품목정보]에서 등록해야 하며, 등록된 품목의 생산 관련 속성을 이 화면에서 일괄로 채워 넣습니다.

✅ 리스트의 행을 1개 이상 체크해야 [일괄적용] 버튼이 활성화됩니다. 체크 없으면 버튼이 비활성 상태(회색).

생산품목관리 메뉴 진입 화면

① 기능 버튼

  • 일괄적용: 리스트에서 체크한 품목들의 생산 정보 5개 필드(안전재고량/공장·창고/리드타임/Lot크기/조달유형)를 한 번에 같은 값으로 일괄 설정합니다.
  • 다운로드: 현재 리스트를 엑셀 파일로 내려받습니다. 외부에서 수정한 후 업로드로 일괄 반영할 수 있습니다.
  • 업로드: 엑셀 파일을 업로드해 다수 품목의 생산 정보를 한 번에 변경합니다.

이 화면에는 [등록]·[수정]·[삭제] 버튼이 없습니다. 품목 자체에 대한 등록/수정/삭제는 [기초정보] - [정보관리] - [품목정보] 메뉴에서 진행합니다.

② 검색 영역

  • 검색기준 + 키워드: 품목코드·품목명 등으로 리스트 필터링.

③ 리스트 영역

  • 품목코드 / 품목명 / 별칭 / 품목유형 / 규격 / 단위: 기초정보 화면에서 등록된 값. 이 화면에서는 조회만 가능.
  • 안전재고량: 품목별 최소 보관 기준. MRP·발주 계산의 임계치로 사용.
  • 공장/창고: 기본 보관 위치. 등록된 창고 중에서 매핑.
  • 리드타임(일): 발주 또는 생산 지시부터 입고까지 걸리는 표준 일수.
  • Lot크기: 1회 생산/발주 단위 수량.
  • 조달유형: ‘내부 제조’ 또는 외부 구매 등 조달 방식 구분.

1.8.1. 다수 품목의 생산 정보 일괄 변경하기

진행 순서: 리스트에서 변경할 품목들의 체크박스 선택 → 상단 [일괄적용] 클릭 → 팝업에서 변경할 필드의 체크박스 ON + 값 입력 → [확인] 클릭

일괄적용 팝업 - 5개 생산 정보 필드

입력 항목

  • ① 안전재고량: 좌측 체크박스 ON 후 숫자 입력. 체크된 모든 품목의 안전재고량이 같은 값으로 변경됩니다.
  • ② 공장/창고: 좌측 체크박스 ON 후 돋보기로 창고 검색·선택. (예: 기본 공장의 원재료 창고)
  • ③ 리드타임(일): 좌측 체크박스 ON 후 일수 입력.
  • ④ Lot크기: 좌측 체크박스 ON 후 수량 입력.
  • ⑤ 조달유형: 좌측 체크박스 ON 후 드롭다운에서 조달 방식 선택. 기본값은 ‘내부 제조’.

※ 각 필드 좌측 체크박스가 켜진 항목만 일괄 변경됩니다. 체크 해제된 필드는 기존 값을 유지합니다.

1.8.2. 다운로드 / 업로드로 대량 변경

  • 엑셀 파일에서 안전재고량·창고·리드타임·Lot크기·조달유형 컬럼을 수정
  • [업로드] 클릭 → 수정한 엑셀 파일 선택 → 변경 사항이 일괄 반영됨

※ 엑셀 양식의 열 순서·헤더는 다운로드한 그대로 유지해야 업로드 시 정상 처리됩니다.

1.10. 작업관리

1.10.2. 작업에 불량코드 매핑하기

진행 순서: 좌측 리스트에서 작업 행 클릭(선택) → 우측 [등록] 클릭 → [불량 코드 등록] 팝업에서 매핑할 코드 체크 → [확인] 클릭

  • 작업ID는 수정할 수 없습니다.
  • 작업명만 변경한 후 [확인] 클릭으로 저장합니다.
  • 불량코드 매핑은 수정 팝업이 아니라 좌측 리스트에서 작업 선택 후 우측 영역에서 별도로 관리합니다.

1.10.4. 엑셀 양식으로 일괄 등록하기

대량의 작업을 한 번에 등록하면서 불량코드 매핑까지 같이 처리할 때 사용합니다.

  • ‘작업관리 엑셀 일괄 업로드 양식’ 사용 (최대 5,000건)
  • 작업ID(선택, 영문/숫자 20자) / *작업명(필수, 한글/영문/숫자 100자) / 불량코드
  • 불량코드 컬럼: 콤마(,)로 구분하여 여러 개 입력 가능. 예: DEF001,DEF002,DEF004
  • 미입력 시: 회사에 등록된 전체 불량코드를 매핑한 것으로 처리됩니다.

※ 양식을 변형하지 말고 그대로 작성. 파란색으로 표시된 작업명만 필수, 작업ID는 미입력 시 자동 채번.

1.11. 공정순서(라우팅)

개요

제품을 생산할 때 어떤 공정을 어떤 순서로 거치는지 정의하는 라우팅(Routing)을 등록·관리하는 화면입니다. 하나의 라우팅은 공정순서(라우팅) 하나에 여러 공정(Routing Operation)이 순서대로 묶이고, 각 공정은 다시 작업(Work Operation)을 포함합니다.

🧱 선행 작업: 품목 · 공장 · 작업장 · 활동(Activity)이 먼저 등록되어 있어야 합니다. 라우팅은 등록된 작업장·활동을 참조하여 작업 단위를 정의합니다.

화면 진입

좌측 사이드바 [생산관리] ▸ [기준정보] ▸ [공정순서(라우팅)] 메뉴를 클릭합니다.

목록 화면

화면은 좌상단 ‘공정순서(라우팅)’ / 우상단 ‘공정’ / 하단 ‘작업 상세정보’ 세 영역으로 구성됩니다.

공정(라우팅)관리 목록 화면

  • ① 기능 버튼 — [등록] / [복사해서 등록] / [수정] / [삭제] / [다운로드]. 좌측 그리드에서 공정순서(라우팅)을 선택한 뒤 사용합니다.
  • ② 공정순서(라우팅) — 라우팅 단위. 한 건은 코드 · 품목 · 규격 · 단위 · 공장 · 상태 · 버전 · 사용여부를 가집니다.
  • ③ 작업 상세정보 — 우측에서 선택한 공정에 등록된 작업의 작업명 · 작업장 · 표준세팅시간 · 활동ID · 표준공수 · 표준기계/건수 · 스크랩율(%)을 표시합니다.
  • ④ 공정 — 좌측 공정순서(라우팅)에 속한 공정들의 목록입니다. 공정을 선택하면 하단(③)에 그 공정의 작업이 표시됩니다.

📌 표시 데이터 예시 — 공정순서(라우팅) RTG-A01 / 품목 [FG-A01] 캔버스 에코백 / 공장 [PLT001] 기본 공장. 공정 4개: 가공(재단) → 조립(봉제) → 도장(외주) → 포장(Packaging). 선택된 공정의 작업 1개: [DL04001] 가공노무작업, 표준공수 10분.

등록 절차

라우팅 등록은 다음 순서로 진행합니다.

  1. 공정순서(라우팅)을 먼저 만들고 (라우팅 헤더)
  2. 그 안에 공정들을 순서대로 추가한 뒤
  3. 각 공정에 작업을 등록

1단계: 공정순서(라우팅) 등록

상단 [등록] 버튼을 클릭하면 공정순서(라우팅) 등록 팝업이 열립니다.

공정그룹 등록 팝업

  • ① 공정순서(라우팅)명* — 라우팅 코드를 직접 입력 (예: RTG-A01)
  • ② 품목* — 돋보기 클릭 → 품목 조회 팝업에서 대상 완제품/반제품 선택
  • ③ 공장* — 라우팅이 적용될 공장 선택

필수 항목을 채우고 [저장] 클릭하면 공정순서(라우팅)이 생성되고, 다음 단계(공정 추가)로 진행할 수 있습니다.

2단계: 공정 추가

목록에서 방금 만든 공정순서(라우팅)을 체크박스로 선택한 뒤 [수정] 버튼을 클릭하면 공정/작업 상세 팝업이 열립니다.

공정/작업 상세 — 공정그룹 상세정보 표시

  • ① 상단 액션 — [공정등록] / [작업등록] / [수정] / [삭제]. 좌측 트리에서 선택한 노드 종류에 따라 활성/비활성됩니다.
  • ② 트리 — 공정순서(라우팅)(루트) ▸ 공정 ▸ 작업의 3단 계층. 화살표를 클릭하면 펼쳐집니다.
  • ③ 우측 상세 — 현재 트리에서 선택한 노드(공정순서(라우팅)/공정/작업)의 상세정보가 표시됩니다.

루트(공정순서(라우팅))를 선택한 상태에서 [공정등록] 클릭 → 다음 팝업이 열립니다.

공정 등록 팝업

  • ① 공정* — 돋보기 클릭 → 기준 공정 조회 팝업에서 등록된 공정(예: [RTG0003] 가공 (재단))을 선택
  • ② 특이사항 — 해당 공정에서 수행할 구체 내용을 자유 입력 (예: ‘캔버스 원단을 본체 패턴대로 재단’)

[저장] 클릭하면 트리에 공정이 추가됩니다. 순서대로 여러 공정을 반복 등록합니다.

공정 선택 시 우측에 공정 상세정보(특이사항)가 표시됨

3단계: 작업 추가

트리에서 작업을 추가할 공정 노드를 선택 한 뒤 [작업등록] 클릭하면 작업 등록 팝업이 열립니다.

작업 등록 팝업

  • ① 작업명* / 작업순번* — 작업명은 돋보기로 기준 작업 선택, 작업순번은 자동 부여(수정 가능)
  • ② 작업장* / 생산능력집계구분 — 작업장은 돋보기로 선택, 생산능력집계구분은 자동 표시(예: [LAB] 사람)
  • ③ 활동ID* — 돋보기 → 활동 조회 팝업에서 표준 활동 선택 (예: [DL04001] 가공노무작업)
  • ④ 작업내용/설명 — 작업의 구체 내용을 자유 입력

[저장] 클릭 시 트리의 해당 공정 아래에 작업 노드가 추가됩니다. 표준공수(분), 표준기계, 표준건수, 스크랩율(%) 등 세부 수치는 작업 등록 후 [수정]으로 보완합니다.

작업 선택 시 우측에 작업 상세정보(작업명·작업장·활동ID·표준공수 등)가 표시됨

트리 우클릭으로 하위 레벨 바로 추가

공정/작업 상세 팝업의 좌측 트리에서 노드를 우클릭(마우스 오른쪽 버튼) 하면, 상단 [공정등록]/[작업등록] 버튼을 거치지 않고 그 자리에서 바로 한 단계 아래 레벨을 추가할 수 있습니다. 우클릭한 노드의 레벨에 따라 메뉴의 활성 항목이 달라집니다.

💡 우클릭 메뉴는 상단 액션 버튼과 같은 기능입니다 — 클릭한 위치에 바로 메뉴가 떠 더 빠르게 추가할 수 있습니다. 선택한 노드의 한 단계 아래만 추가되며, 나머지 추가 항목은 비활성됩니다.

  • 제품(공정순서(라우팅)) 루트 노드 우클릭 → [+ 공정 등록] 으로 하위 공정을 추가 ([+ 작업 등록] 은 비활성)
  • 공정 노드 우클릭 → [+ 작업 등록] 으로 하위 작업을 추가 ([+ 공정 등록] 은 비활성)
  • 메뉴의 [+ 수정] / [- 삭제] 로 선택한 노드를 그 자리에서 바로 수정·삭제할 수도 있습니다.

① 루트(공정순서(라우팅)) 노드 우클릭 → ② [+ 공정 등록] 으로 하위 공정 추가 (작업 등록은 비활성)

① 공정([RTG0005] 도장) 노드 우클릭 → ② [+ 작업 등록] 으로 하위 작업 추가 (공정 등록은 비활성)

수정 · 삭제

  • 수정 — 트리에서 공정순서(라우팅)/공정/작업 노드를 선택한 후 [수정] 버튼 클릭. 우측에 표시되던 상세정보가 입력 가능한 폼으로 전환됩니다.
  • 삭제 — 트리에서 노드 선택 후 [삭제]. 공정순서(라우팅)을 삭제하면 하위 공정·작업이 모두 함께 삭제되므로 주의합니다.

기타 기능

  • 사용여부 토글 — 목록 그리드의 사용여부 컬럼 토글로 라우팅 활성/비활성 전환. 비활성 라우팅은 생산지시·MRP 등 후속 화면의 선택 대상에서 제외됩니다.
  • 복사해서 등록 — 기존 라우팅을 선택 후 클릭하면 같은 내용으로 새 공정순서(라우팅)을 만듭니다. 유사한 제품의 라우팅을 빠르게 복제할 때 유용합니다.
  • 다운로드 — 현재 조회된 라우팅 그리드를 엑셀로 내려받습니다.
  • 버전 / 상태 — 버전은 라우팅이 변경될 때마다 올라가는 식별자, 상태는 결재/배포 단계(예: R = Released = 배포)를 의미합니다.

1.12. E-BOM관리

개요

E-BOM(Engineering BOM, 설계 BOM)은 제품을 설계 관점에서 ‘무엇으로 구성되는가’를 정의하는 자재명세서입니다. 완제품·반제품이 어떤 부품·자재로 이뤄지는지 다단계 구조로 표현하며, 연구소·설계팀이 등록·관리합니다.

🔗 E-BOM과 M-BOM은 동일한 데이터 구조를 가집니다. E-BOM(설계)에서 제품 구조를 확정하면, 이를 참조해 [1.13. M-BOM관리])에서 공장·공정 정보를 입힌 제조용 M-BOM을 생성합니다. (의사결정: E-BOM → M-BOM 이관)

화면 진입

좌측 사이드바 [생산관리] ▸ [기준정보] ▸ [E-BOM관리]

목록 화면 — 기본 정보(헤더) + 구성 부품

E-BOM관리 — 상단 기본 정보(헤더) + 하단 구성 부품(다단계 라인)

  • ① 기능 버튼 — [등록] / [수정] / [삭제] / [복사] / [다운로드] / [업로드]
  • ② 기본 정보(헤더) — 제품코드 / 제품명 / 규격 / 단위 / Revision(설계 개정 A·B·…) / E-BOM 명칭 / 설계 변경 번호 / 비고. 한 제품 + Revision이 BOM 1건입니다.
  • ③ 구성 부품(라인) — 상단에서 선택한 BOM의 부품 목록. 구성부품 코드 / 구성부품명 / 상위품목코드·상위품목명(다단계 계층) / 순번 / 모품 1EA당 소요량 / 규격 / 단위 / 설계 스크랩율(%)

🌳 다단계(Multi-level) BOM — 구성부품이 또 다른 반제품이면 그 반제품이 다시 자신의 하위 부품을 갖습니다. 위 예시: FG-A01(완제품) → SFG-A01(봉제완료 본체, 반제품) → RM-A01 캔버스원단 + RM-A02 면손잡이끈 / + RM-A03 실크프린트잉크(완제품 직접 투입). 상위품목코드로 부모-자식 관계를 표현합니다.

BOM 헤더 등록

상단 [등록] → ‘E-BOM 기본정보 등록’ 팝업.

E-BOM 기본정보 등록 — 제품 검색 + Revision/설계변경번호/E-BOM명칭

  • ① 제품 검색 — 상단 돋보기로 BOM을 만들 제품(완제품/반제품)을 선택
  • ② Revision — 설계 개정 차수(A, B, …). 제품코드 + Revision이 BOM의 Key. 설계 변경 시 새 Revision으로 이력을 보존합니다.
  • ③ 설계 변경 번호 — 자동 채번(001→002…). 설계변경(ECO) 추적용
  • ④ E-BOM 명칭 / 비고 — 식별용 이름과 메모

제품 조회 팝업

품목 조회 — 품목유형 탭(전체/상품/원재료/제품/반제품…)으로 BOM 대상 제품 선택

  • 품목유형 탭으로 필터링. E-BOM은 보통 제품(FG)·반제품(SFG)에 대해 만듭니다. ‘전용품목 보기’ 체크로 범위를 좁힐 수 있습니다.

E-BOM 상세 — 다단계 트리 편집

목록에서 BOM 행을 더블클릭 → ‘E-BOM 상세’ 화면. 좌측 트리로 다단계 구조를 보고, 노드를 선택해 우측에서 상세를 확인·편집합니다.

E-BOM 상세 — 좌측 다단계 트리 + 우측 구성부품 정보

  • ① 편집 버튼 — [구성부품등록] / [수정] / [중간삭제] / [삭제]. 트리에서 부모 노드를 선택하고 [구성부품등록]하면 그 하위에 부품이 추가됩니다.
  • ② 다단계 BOM 트리 — 완제품 → 반제품 → 원자재 계층을 펼쳐서 확인
  • ③ 구성부품 정보 — 선택한 노드의 순번 / 구성부품 / 모품 1EA당 소요량 / 단위 / 설계 스크랩율

구성부품 등록

[구성부품등록] → ‘E-BOM 구성부품 상세’ 팝업. 선택한 부모 노드 하위에 부품을 추가합니다.

E-BOM 구성부품 상세 — 순번(자동)/구성부품(검색)/소요량/단위/설계 스크랩율

  • ① 순번 — 자동 채번(L01-10, L02-02 등 계층 반영)
  • ② 구성부품 — 검색으로 부품(자재·반제품) 선택
  • ③ 모품 1EA당 소요량 / 단위(자동) / 설계 스크랩율(%) — 모품 1개 생산에 필요한 수량 + 설계 단계 예상 로스율

주요 필드 설명

필드 설명
Revision 설계 개정 차수(A·B…). 제품코드 + Revision = BOM Key. 변경 이력 보존
설계 변경 번호 ECO(설계변경) 추적 번호. 자동 채번
상위품목코드 다단계 계층에서 이 부품의 부모(반제품) 코드
모품 1EA당 소요량 부모 1개 생산 시 필요한 이 부품 수량
설계 스크랩율(%) 설계 단계에서 예상하는 폐기·로스 비율. MRP 소요량 계산에 반영

등록 절차 요약

  1. [등록] → 제품 검색·선택 → Revision / E-BOM 명칭 입력 → [저장] (헤더 생성)
  2. 목록에서 해당 BOM 더블클릭 → ‘E-BOM 상세’ 트리 화면
  3. 트리에서 부모 노드(완제품/반제품) 선택 → [구성부품등록]
  4. 구성부품 검색·선택 + 소요량 + 설계 스크랩율 입력 → [저장]
  5. 다단계 구조면 하위 반제품 노드를 선택해 동일하게 부품 추가

복사 등록 — 기존 BOM 복제

구성이 완료된 BOM 한 건을 골라 다른 품목으로 통째로 복제하는 기능입니다. 대상 품목에 원본의 구성부품이 1차로 그대로 들어오고, 이를 기반으로 추가·수정·삭제해 새 BOM을 빠르게 완성합니다.

📋 활용 — 유사한 제품의 BOM을 처음부터 만들지 않고 기존 BOM을 복제한 뒤 차이 나는 자재만 교체합니다. 비슷한 구조의 제품군에서 등록 시간을 크게 줄입니다.

동작 흐름

① 원본 BOM 체크 → [복사] → 품목 조회에서 복제 대상 품목 선택 (예: FG-B01 원목 미니 책꽂이)

② ‘E-BOM 복사’ 모달 — 대상 품목과 원본 Revision이 채워진 상태에서 E-BOM 명칭 입력

③ 저장 후 — 원본(FG-A01)의 구성부품이 대상 품목(FG-B01)으로 그대로 복제됨

  1. 목록에서 원본 BOM 체크 → [복사]
  2. 품목 조회 팝업에서 복제 대상 품목 선택 → [확인]
  3. ‘E-BOM 복사’ 모달에 원본 Revision이 가져와짐 → E-BOM 명칭 입력 → [저장]
  4. 저장 즉시 원본의 구성부품 전체가 대상 품목으로 복제됨
  5. 복제된 BOM을 더블클릭 → 트리에서 구성부품 추가·수정·중간삭제·삭제로 대상 품목에 맞게 조정

1.13. M-BOM관리

개요

M-BOM(Manufacturing BOM, 제조 BOM)은 E-BOM(설계 구조)을 실제 제조 관점으로 구체화한 자재명세서입니다. ‘어느 공장에서, 어떤 공정에 어떤 자재를 투입하는가’를 담아 MRP·생산지시·원가계산에 직접 쓰입니다.

🔗 M-BOM은 E-BOM과 동일한 다단계 구조를 가지되, 공장·참조E-BOM·상태·투입 공정작업·공정 스크랩율이 추가됩니다. 보통 [1.12. E-BOM관리])에서 설계 BOM을 확정한 뒤 이를 참조해 공장별 M-BOM을 만듭니다.

공장 없음 (설계는 공장 무관) 공장별 관리 ✓
참조 E-BOM — 참조한 E-BOM 코드 ✓
스크랩율 설계 스크랩율 공정 스크랩율 ✓
라인 추가 정보 — 투입 공정작업 / 상태(P·R·E) ✓

  • ② 공장 — 이 M-BOM이 적용될 제조 공장. 공장별 가용자재·설비·스크랩율이 다르므로 공장 단위로 관리

M-BOM 상세 — 다단계 트리

목록에서 BOM 행을 더블클릭 → ‘M-BOM 상세’. E-BOM과 동일하게 좌측 다단계 트리 + 우측 정보, [구성부품등록/수정/중간삭제/삭제] 버튼으로 편집합니다.

M-BOM 상세 — 다단계 트리(2단계 반제품) + 우측 BOM 기본정보(참조E-BOM/공장)

  • ① 다단계 BOM 트리 — 완제품 → 반제품(여러 단계) → 원자재. 제조 실제 구조 반영(예: 봉제완료 본체 + 실크프린트 완료품 두 반제품)
  • ② BOM 기본 정보 — 참조 E-BOM / 제품코드·명 / 공장 / Revision / M-BOM 명칭 / 상태. 구성부품 노드를 선택하면 순번·투입공정작업·소요량·공정 스크랩율이 표시됩니다.

1.14. 공정별 BOM관리

📒 공정별 BOM관리는 M-BOM의 구성부품을 각 공정·작업에 어떤 부품이 투입되는지 연결(할당)하는 화면입니다. M-BOM이 ‘무엇이 얼마나 필요한가’, 공정(라우팅)이 ‘어떤 순서로 만드는가’를 정의한다면, 공정별 BOM은 그 둘을 이어 ‘어느 공정·작업에서 그 부품을 쓰는가’를 확정합니다.

1) 개요 — 공정별 BOM관리란

M-BOM에 등록된 제품 구성부품을, 해당 제품을 만드는 공정(라우팅)의 개별 공정·작업 단위로 배치합니다. 예를 들어 ‘실크 프린트 잉크’는 도장 공정의 실크 프린트 작업에, ‘포장지’는 포장 공정의 완제품 포장 작업에 연결하는 식입니다.

💡 왜 필요한가 — 생산지시·생산실적에서 공정별 자재 투입/출고와 재공(WIP) 원가 집계가 이 연결을 기준으로 이뤄집니다. 부품이 어느 공정에서 소비되는지 정해져 있어야 공정별 투입수량·원가를 정확히 계산할 수 있습니다.

핵심 개념

  • 품목 · 공장 · 공정순서(라우팅) · BOM Rev. 단위로 ‘공정별 자재 연결’ 한 건을 만든다.
  • 그 안에서 M-BOM 구성부품을 공정(라우팅)의 각 공정·작업에 연결한다.
  • 제품을 구성하는 부품은 빠짐없이 모두 어느 한 작업에 연결되어야 한다(아래 정책 참조).

2) 화면 진입 / 선행 조건

  • 메뉴 경로 : [생산관리] › [기준정보] › [공정별 BOM관리]
  • 선행 등록 : 생산품목(제품·반제품), 공정(라우팅), M-BOM이 먼저 등록되어 있어야 한다. 공정별 BOM은 이 셋을 연결하는 단계다.

3) 목록 화면

공정별 BOM관리 목록 — ① 기능 버튼 ② 등록된 공정별 자재 연결 목록 ③ 상태·대표·사용여부

주요 버튼

  • 조회 / 상세검색 — 품목·공장 등 조건으로 목록 조회
  • 등록 / 수정 / 삭제 — 연결 건 신규·편집·삭제 (행 더블클릭 또는 [수정]으로 상세 진입)
  • 다운로드 / 결재상신 — 목록 엑셀 다운로드, 작성된 연결의 전자결재 상신

주요 컬럼

  • 품목 · 규격 · 단위 — 연결 대상 제품/반제품
  • 공정순서(라우팅) · 공장 · BOM Rev. — 어떤 공정(라우팅)·공장·M-BOM 리비전에 대한 연결인지
  • 문서번호 · 결재상태 · 상태 — 채번/전자결재 상태/연결 진행 상태
  • 대표공정 · 사용여부 — 대표 연결 지정 여부, 사용/미사용

4) 등록 절차

  1. [등록] → ‘공정별 자재 연결 기본정보’ 팝업에서 품목·공장·공정순서(라우팅)·BOM Rev. 입력
  2. 저장하면 상세 화면이 열리고, 공정(라우팅)의 공정·작업이 표시됨
  3. 각 작업의 투입 부품(BOM) 칸에서 검색(돋보기)을 눌러 ‘구성부품 선택’ 팝업으로 부품을 연결
  4. 모든 부품을 빠짐없이 연결한 뒤 저장 → 필요 시 [결재상신]

4-1) 기본정보 입력

공정별 자재 연결 ‘기본정보’ 팝업 — 4개 필수값으로 연결 대상 1건을 정의

필드 필수 설명
품목 필수 공정별 BOM을 연결할 제품·반제품
공장 필수 해당 제품을 생산하는 공장
공정순서(라우팅) 필수 적용할 공정(라우팅) 그룹 — 공정·작업 구조를 가져옴

4-3) 구성부품 선택 + 연결 정책 ★

투입 부품(BOM) 칸의 검색(돋보기) 버튼을 누르면 ‘구성부품 선택’ 팝업이 열립니다. 좌측에는 해당 M-BOM의 전체 구성부품 트리가, 우측에는 현재 공정·작업과 ‘연결 자재’가 표시됩니다. 트리에서 부품을 체크하면 그 작업의 투입 부품으로 등록됩니다.

구성부품 선택 팝업 — ① 전체 구성부품 트리 ② Assay 선택 시 하위 개별부품 비활성 ③ 연결 자재로 등록 ④ 확인

🔒 부품 연결 정책 — 구성부품 선택 시 반드시 적용되는 규칙

  • ① 모든 부품을 빠짐없이 연결 : 제품을 구성하는 BOM 부품은 전부 어느 한 공정·작업에 연결되어야 하며, 빠진 부품이 있으면 안 됩니다.
  • ② 한 부품은 한 작업에만(재사용 불가) : 이미 다른 작업에 연결된 부품은 트리에서 비활성(disabled) 처리되어 다른 작업에 중복 연결할 수 없습니다.
  • ③ Assay(하위를 가진 반제품·모듈) 선택 시 하위 비활성 : 상위 Assay를 선택하면 그 하위 개별부품은 선택 불가가 되고, 투입 부품에는 상위 Assay만 등록됩니다.
  • ④ 개별부품 먼저 선택 시 상위 Assay 비활성 : 반대로 하위 개별부품을 먼저 선택하면 그 상위 Assay·모듈이 모두 비활성됩니다. → 한 묶음은 ‘Assay 통째로’ 또는 ‘개별부품 각각’ 중 한 방식으로만 연결됩니다.

위 화면 예시 : 좌측은 [FG-A01_A] 캔버스에코백 M-BOM의 전체 구성부품 트리입니다(①). [SFG-A01] 봉제완료 본체(반제품=Assay)가 선택되어 그 하위 [RM-A01]·[RM-A02]는 비활성 처리됐고(②), 선택한 [RM-A03] 실크 프린트 잉크가 우측 ‘연결 자재’의 투입 부품(BOM)으로 등록됐습니다(③). [확인](④)을 누르면 해당 공정·작업에 연결이 저장됩니다.

⚠️ 주의사항 (매우 중요) — 사외외주 작업장의 BOM 연결

라우팅(공정·작업) 중 사외외주(사외 외주가공) 작업장에 부품을 연결할 때는, 일반 원자재가 아니라 외주제작품(외주 결과물로 입고되는 품목)을 투입 부품(BOM)으로 선택해야 합니다.

  • 외주제작품이란 — 외주가공을 거쳐 결과물로 입고되는 품목(대개 반제품)입니다. 사외외주 작업의 투입 부품(BOM)으로는 반드시 이 외주제작품을 선택합니다.
  • 사급자재 자동 인식 — 외주제작품을 선택하면, 시스템이 해당 품목의 BOM 트리 1레벨 아래(직하위) 구성품들을 사급자재(외주처에 지급하는 자재)로 자동 인식합니다.
  • 연결 방식 — 따라서 사외외주 작업에서는 하위 원자재를 하나씩 연결하지 않고, 외주제작품 1건만 연결하면 그 직하위 부품이 사급 관계로 설정됩니다.
  • 확인 필수 — 외주제작품(및 그 직하위 사급 구성)을 잘못 지정하면 외주 사급 출고·입고와 원가 집계가 어긋나므로 반드시 확인합니다.

  • 상태 — 연결 작업의 진행 상태(예: 확정 / 연결완료). 작성 후 [결재상신]으로 전자결재를 올립니다.

2.1. 연간생산계획

한 해 동안 공장에서 생산할 완제품의 연간·월별 생산 계획을 수립하고 관리하는 화면입니다. 연간 단위로 품목별 판매·재고·생산 수량을 계획하면, 이후 [생산관리]-[생산계획]-[월간생산계획]·[주간생산계획]에서 이를 기준으로 세부 계획을 전개합니다.

[연간영업계획]을 반영하면 선택한 영업계획의 내용을 가져와 월별 [판매계획수량] 입력의 기준으로 활용할 수 있습니다.

✅ 생산계획번호(예: PP2026083)는 [확인]을 눌러 최종 저장될 때 시스템이 자동으로 부여하며, 직접 입력하거나 수정할 수 없습니다.

💡 [연간영업계획]을 반영하려면 사전에 영업계획이 등록되어 있어야 합니다. 영업계획 없이도 생산계획을 직접 수립할 수 있습니다.

① 기능 버튼

  • 등록: 새로운 연간생산계획을 등록합니다. [연간생산계획 기본정보] 팝업이 열립니다.
  • 수정: 리스트(기본 정보)에서 계획을 선택한 후 클릭하면 [연간생산계획 상세] 팝업이 열려 내용을 수정할 수 있습니다.
  • 삭제: 선택한 연간생산계획을 삭제합니다.
  • 다운로드: 현재 조회된 기본 정보·상세정보를 엑셀 파일로 내려받습니다.
  • 결재상신: 선택한 계획을 결재 상신합니다. (결재 기능을 사용하는 경우에만 표시됩니다.)

② 검색 영역

  • 계획연도: 조회할 계획연도를 선택합니다. 기본값은 [전체]입니다.
  • 상세검색: 클릭하면 생산계획번호, 공장 검색 조건이 펼쳐집니다.
  • 조회 / 초기화: 입력한 조건으로 리스트를 조회하거나, 검색 조건을 초기화합니다.

③ 기본 정보

등록된 연간생산계획의 머리 정보 목록입니다. 행을 선택하면 아래 ④ 상세정보와 ⑤ 월별 생산 계획에 해당 계획의 내용이 표시됩니다.

  • 생산계획번호: 시스템이 자동 부여한 계획 고유번호입니다 (예: PP2026083).
  • 계획연도: 계획 대상 연도.
  • 공장: 계획이 적용되는 공장입니다 (예: [PLT001] 기본 공장).
  • 계획시작일 / 계획종료일: 계획 적용 기간.
  • 참조: 반영한 연간영업계획 문서입니다 (예: 영업계획(PS2026001)). 링크를 클릭하면 참조한 문서를 확인할 수 있습니다.
  • 확정여부: 계획의 확정 상태를 표시합니다 (예: 확정). 확정 상태에 따라 일부 기능이 제한될 수 있습니다.
  • 작성자: 계획을 등록한 사원이 이름(사번) 형태로 표시됩니다 (예: 고성민(26051301)).
  • 부서: 작성자의 소속 부서입니다 (예: 생산총괄).
  • 문서번호 / 결재상태: 결재 기능 사용 시 부여되는 결재 문서번호와 결재 상태.
  • 비고: 메모.

④ 상세정보

③에서 선택한 계획의 품목별 수량 요약입니다. 그리드 맨 아래 [합계] 행에 품목 전체 합계가 표시됩니다.

  • 품목 / 규격 / 단위: 생산 대상 완제품 정보.
  • 판매계획수량: 해당 품목의 연간 판매 계획 수량.
  • 기초재고수량 / 기말재고수량: 연초 보유 재고와 연말 목표 재고.
  • 생산계획수량: 월별 생산 계획의 1~12월 [생산계획수량]을 합산한 연간 생산 계획 수량입니다 (예: 80,614).
  • 비고: 메모.

⑤ 월별 생산 계획

④에서 선택한 품목의 1~12월 월별 내역입니다. 그리드 맨 아래 [합계] 행에 12개월 합계가 표시됩니다.

  • 월: 계획연도의 각 월입니다. 첫 행에는 연도가 함께 표시됩니다 (예: 2026년 1월).
  • 판매계획수량: 월별 판매 계획 수량.
  • 기초재고 / 기말재고: 월별 재고 수량.
  • 스크랩 반영 전 생산계획수량: 스크랩을 고려하기 전의 필요 생산 수량으로, 판매계획수량 + 기말재고 − 기초재고로 산출됩니다.
  • 스크랩율(%): 해당 월에 적용되는 스크랩율.
  • 생산계획수량: 스크랩을 감안해 목표 수량을 확보하도록 [스크랩 반영 전 생산계획수량]을 (1 − 스크랩율)로 나눈 뒤 올림한 값입니다. 예) 스크랩 반영 전 10,000개, 스크랩율 1%이면 10,000 ÷ (1 − 0.01) ≈ 10,101 → 올림하여 10,102개로 산출됩니다.

2. 생산계획

2.2. 월간생산계획

한 달(월) 단위로 공장에서 생산할 완제품·반제품의 월별 생산 계획을 수립하고 관리하는 화면입니다. 연간생산계획을 더 짧은 월 단위로 구체화한 계획으로, 이후 [생산관리]-[생산계획]-[주간생산계획]·[부하분석(MPS)]에서 이를 기준으로 세부 계획을 전개합니다.

계획 수립 시 참조 방식([자체]/[영업계획]/[생산요청])을 선택할 수 있으며, [영업계획] 또는 [생산요청]을 반영하면 해당 문서의 내용을 가져와 [판매계획수량] 입력의 기준으로 활용할 수 있습니다.

✅ 생산계획번호(예: PP202605004)는 [확인]을 눌러 최종 저장될 때 시스템이 자동으로 부여하며, 직접 입력하거나 수정할 수 없습니다.

💡 [영업계획]·[생산요청]을 반영하려면 사전에 해당 문서가 등록되어 있어야 합니다. [자체]를 선택하면 참조 없이 생산계획을 직접 수립합니다.

🗂️ 월간생산계획은 [생산계획버전]으로 관리되어, 조건이 다른 여러 버전을 비교·조정할 수 있습니다.

① 기능 버튼

  • 등록: 새로운 월간생산계획을 등록합니다. [월간 생산계획 기본정보] 팝업이 열립니다.
  • 수정: 리스트(기본 정보)에서 계획을 선택한 후 클릭하면 [월간생산계획 상세] 팝업이 열려 내용을 확인·수정할 수 있습니다.
  • 삭제: 선택한 월간생산계획을 삭제합니다.
  • 다운로드: 현재 조회된 기본 정보·상세정보를 엑셀 파일로 내려받습니다.
  • 결재상신: 선택한 계획을 결재 상신합니다. (결재 기능을 사용하는 경우에만 표시됩니다.)

② 검색 영역

  • 계획월: 조회할 계획월의 범위(시작월 ~ 종료월)를 선택합니다.
  • 상세검색: 클릭하면 생산계획번호, 공장 검색 조건이 펼쳐집니다.
  • 조회 / 초기화: 입력한 조건으로 리스트를 조회하거나, 검색 조건을 초기화합니다.

③ 기본 정보

등록된 월간생산계획의 머리 정보 목록입니다. 행을 선택하면 아래 ④ 상세정보와 ⑤ 월별 생산 계획에 해당 계획의 내용이 표시됩니다.

  • 생산계획번호: 시스템이 자동 부여한 계획 고유번호입니다 (예: PP202605004).
  • 계획월: 계획 대상 월 (예: 2026-05).
  • 공장: 계획이 적용되는 공장입니다 (예: [PLT001] 기본 공장).
  • 반영 참조: 반영한 참조 문서입니다 (예: 영업계획(PS202605001)). 링크를 클릭하면 참조한 문서를 확인할 수 있습니다.
  • 확정여부: 계획의 확정 상태를 표시합니다 (예: 확정).
  • 작성자: 계획을 등록한 사원이 이름(사번) 형태로 표시됩니다 (예: 구자영(결재)(26052301) — 결재자에게는 (결재) 표기가 덧붙습니다).
  • 부서: 작성자의 소속 부서입니다 (예: 생산).
  • 문서번호 / 결재상태: 결재 기능 사용 시 부여되는 결재 문서번호와 결재 상태입니다. 결재 기능을 사용하지 않으면 공란으로 표시됩니다.
  • 비고: 메모.

④ 상세정보

③에서 선택한 계획의 품목별 수량 요약입니다. 선택한 공장에서 생산하는 완제품·반제품 품목이 자동으로 표시됩니다. 그리드 맨 아래 [합계] 행에 품목 전체 합계가 표시됩니다.

  • 품목 / 규격 / 단위: 생산 대상 품목 정보 (예: [FG-A01] 캔버스 에코백 / 300×400mm…, [SFG-A01] 봉제완료 본체 / 캔버스 14oz…).
  • 판매계획수량: 해당 품목의 월 판매 계획 수량입니다. [영업계획]이나 [생산요청]을 반영한 경우 자동으로 채워지며, [자체]로 수립한 경우 직접 입력합니다.
  • 기초재고수량 / 기말재고수량: 월초 보유 재고와 월말 목표 재고.
  • 생산계획수량: 판매 계획과 재고, 스크랩율을 반영해 산출된 생산 계획 수량.

⑤ 월별 생산 계획

④에서 선택한 품목의 월별 내역입니다. 월간생산계획은 한 달을 대상으로 하므로 해당 계획월 한 행이 표시됩니다. 그리드 맨 아래 [합계] 행에 합계가 표시됩니다.

  • 월: 계획 대상 월입니다. 목록에서는 2026년 05월, 상세 팝업에서는 5월 형태로 표시됩니다.
  • 판매계획수량: 월 판매 계획 수량.
  • 기초재고 / 기말재고: 월별 재고 수량.
  • 스크랩 반영 전 생산계획수량: 스크랩을 고려하기 전의 필요 생산 수량으로, 판매계획수량 + 기말재고 − 기초재고로 산출됩니다.
  • 스크랩율(%): 해당 월에 적용되는 스크랩율.
  • 생산계획수량: 스크랩을 감안해 목표 수량을 확보하도록 [스크랩 반영 전 생산계획수량]을 (1 − 스크랩율)로 나눈 뒤 올림한 값입니다. 예) 스크랩율이 1%이면 10,000 ÷ (1 − 0.01) ≈ 10,101 → 올림하여 10,102개로 산출됩니다. (위 예시처럼 스크랩율이 0%이면 [스크랩 반영 전 생산계획수량]과 같습니다.)

2.3. 주간생산계획

한 주(주 단위)에 공장에서 생산할 완제품·반제품의 요일별 생산 계획을 수립·관리하는 화면입니다. 월간생산계획을 일자별로 배분해 주차·요일 단위로 구체화한 계획입니다. 주간생산계획에서 부하분석을 실행·확정하면 그 확정된 계획을 MPS(기준생산계획, Master Production Schedule)라고 하며, 이후 [생산관리]-[생산실행]-[생산지시서]의 기준이 됩니다.

계획 수립 후 부하분석 실행 → 부하분석 확정(= MPS 확정) → MRP 실행의 흐름으로 자재 소요 계획(MRP)까지 연결할 수 있습니다.

✅ 생산계획번호(예: PP202619W005 — 가운데 19가 주차를 나타냅니다)는 저장 시 시스템이 자동으로 부여하며, 직접 입력하거나 수정할 수 없습니다.

💡 월간생산계획을 반영하면 월 목표 수량이 계획 주의 일자별로 자동 배분됩니다. 월간생산계획 없이 [자체]로 직접 수립할 수도 있습니다.

🗂️ 주차는 연중 절대주차로 표시됩니다 (예: 19주차 = 2026-05-04 ~ 05-10).

② 검색 영역

  • MPS실행일자: 조회할 부하분석(MPS) 실행일자의 범위(시작일 ~ 종료일)를 선택합니다. 기본값은 당월입니다.
  • 상세검색: 클릭하면 MPS실행번호·작업장·제품 등 추가 검색 조건이 펼쳐집니다. [작업장]·[제품]은 조회 팝업에서 선택합니다.
  • 조회 / 초기화: 입력한 조건으로 조회하거나, 검색 조건을 초기화합니다.

③ MPS 실행 정보

부하분석을 실행한 내역 목록입니다. 행을 선택하면 아래 ④·⑤ 영역에 해당 실행 결과의 부하 분석 내용이 표시됩니다.

  • MPS실행일자 / MPS실행번호: 부하분석을 실행한 일자와 실행번호 (예: 2026-05-27 / MPS202619W005).
  • 주간생산계획번호: 부하분석의 기준이 된 주간생산계획 번호 (예: PP202619W005).
  • 계획월 / 주차 / 계획시작일 / 계획종료일: 해당 주간생산계획의 대상 월·주차·기간 (예: 2026-05, 19주차, 2026-05-04 ~ 2026-05-10).
  • 공장: 계획이 적용되는 공장 (예: [PLT001] 기본 공장).
  • 상태: 부하분석 실행 결과의 상태입니다 (예: 확정). 주간생산계획에 반영해 확정되기 전에는 실행완료 등으로 표시됩니다(설계 기준).

④ 분석 탭

③에서 선택한 부하분석 결과를 두 가지 관점으로 조회합니다.

  • 작업장별 과부족: 일자·작업장별 필요시간과 가용시간을 비교해 과부족을 보여줍니다. (⑤)
  • 제품별 공정/작업 매핑 & 작업장별 제품별 필요시간: 제품별 공정·작업 매핑 정보와, 작업장별·제품별 필요시간 계산 내역을 보여줍니다. (아래 별도 캡처)

⑤ 작업장별 과부족

작업장별 과부족 시간 계산(필요시간 vs. 가용시간 비교) 결과입니다.

  • 일자: 분석 대상 일자 (예: 2026-05-04).
  • 작업장: 분석 대상 작업장 (예: [WKC001] 가공작업장(재단), [WKC002] 조립작업장(봉제)).
  • 필요시간(분): 해당 일자에 그 작업장에서 생산하는 데 필요한 시간입니다 (예: [WKC001] 가공작업장 5,000).
  • 가용시간(분): 해당 작업장이 그 일자에 투입 가능한 시간입니다 (예: [WKC001] 1,920).
  • 과부족 시간(분): 가용시간 − 필요시간입니다. 값이 음수이면 빨간색으로 표시되며 능력이 부족하다는 의미입니다 (예: 1,920 − 5,000 = -3,080).
  • 과부족 상태: 능력 충족 여부를 표시합니다. 가용시간이 필요시간 이상이면 🟢 여유, 미만이면 🔴 부족으로 표시됩니다. (일치 상태도 있습니다 — 설계 기준.)

제품별 공정/작업 매핑 & 작업장별 제품별 필요시간 탭

  • ① 제품별 공정/작업 매핑 정보: 제품이 어떤 공정·작업을 거쳐 어느 작업장에서 생산되는지를 보여줍니다 (일자·제품·공정그룹·공정명·작업명·작업장).
  • ② 작업장별 제품별 필요시간 계산: 작업장별·제품별 필요시간 계산 내역입니다 (일자·작업장·제품·표준노무시간(분)·생산계획수량·필요시간(분)). 필요시간(분) = 생산계획수량 × 표준노무시간(분)으로 계산됩니다 (예: 100,000 × 2 = 200,000). 이렇게 합산된 작업장·일자별 필요시간이 ⑤ 작업장별 과부족의 [필요시간]이 됩니다.

2.4.1. 부하분석 조회·조정하기

① [생산관리]-[생산계획]-[주간생산계획]에서 계획을 선택해 [부하분석 실행] → ② 본 [부하분석] 화면에서 MPS실행일자로 조회 → ③ MPS 실행 정보에서 대상 건을 선택해 작업장별 과부족을 확인합니다.

2.4.2. 부하분석 → 주간생산계획 반영 → MRP 흐름

부하분석은 주간생산계획·MRP와 다음과 같은 흐름으로 연결됩니다.

  • 부하분석 실행: 주간생산계획에서 실행하면 원본 데이터는 유지되고, 부하분석 결과가 생성됩니다.
  • 조정 후 반영: 부하분석 데이터를 조정한 뒤 [주간생산계획으로 반영하기]를 하면, 주간생산계획의 새 버전이 확정 상태로 생성됩니다. ([새버전 생성]으로 부하분석 자체의 버전을 올릴 수도 있습니다.) 단, 같은 주차·같은 공장에 이미 확정 상태의 부하분석 건이 있으면 새로 생성할 수 없습니다. (설계 기준)
  • MRP 실행: 부하분석이 확정되어야 주간생산계획에서 [MRP 실행]을 할 수 있습니다.

⚠️ MRP 확정 시 구매요청(PR)이 자동 생성됩니다. MRP를 확정 취소하려면 연결된 PR이 작성중 상태여야 합니다. 부하분석을 확정 취소하려면 연결된 MRP가 확정 상태가 아니어야 하며(MRP 확정 시 부하분석 확정취소 불가), 확정 취소 시 연결된 MRP 내역이 함께 삭제됩니다. (설계 기준)

2.5. 생산요청서

생산요청서는 영업에서 수주한 내역 또는 직접 입력한 내용을 바탕으로, 어떤 품목을 언제까지 얼마나 생산할지를 생산 부서에 요청하는 문서입니다. 작성된 생산요청서는 [생산계획]-[월간생산계획]에서 참조되어 생산 일정 수립의 기초가 됩니다.

메뉴 경로: [생산관리]-[생산계획]-[생산요청서]

✅ 생산요청서는 두 가지 방법으로 작성할 수 있습니다. ① 수주서로 등록 — 영업 수주서를 불러와 작성 / ② 직접 등록 — 품목을 직접 선택해 작성.

① 검색 조건

  • 생산요청번호·공장·작성일자·상태로 생산요청서를 조회합니다. 작성일자 기본값은 당월 1일 ~ 당일입니다. [조회] 클릭 시 결과가 기본 정보·요청 상세정보 영역에 표시됩니다.

② 기능 버튼

  • 수주서로 등록: 수주서를 불러와 생산요청서를 작성합니다. (→ 입력 예제 1)
  • 등록: 품목을 직접 선택해 생산요청서를 작성합니다. (→ 입력 예제 2)
  • 수정 / 삭제: 선택한 생산요청서를 수정하거나 삭제합니다.
  • 다운로드: 조회된 기본정보·상세정보를 엑셀 파일로 내려받습니다.
  • 결재상신: 선택한 생산요청서를 결재 상신합니다. (결재 기능을 사용하는 경우에만 표시됩니다.)

③ 기본 정보

  • 조회된 생산요청서 목록입니다. 행을 선택하면 ④ 요청 상세정보에 해당 생산요청서의 품목 내역이 표시됩니다.
  • 참조: 수주서 링크를 클릭하면 이 생산요청서가 참조한 원본 수주서를 확인할 수 있습니다. (→ 참조 수주서 확인)
  • 상태: 생산요청서의 진행 상태를 표시합니다. (작성 직후에는 ‘작성중’으로 표시됩니다.)
  • 작성자 · 부서: 생산요청서를 작성한 사용자와 소속 부서가 자동 표시됩니다.
  • 문서번호 · 결재상태: 결재 기능 사용 시에만 표시되는 컬럼으로, 상신 전에는 공란이며 상신 후 문서번호·결재 상태가 표시됩니다.

④ 요청 상세정보

  • ③에서 선택한 생산요청서의 품목별 생산요청수량 · 생산요청기한이 표시됩니다.

⊙ 입력 예제 1 — 수주서로 등록

영업에서 등록한 수주서를 불러와 생산요청서를 작성하는 방법입니다.

진행 순서: ① [수주서로 등록] → ② 수주일자·공장 조회 → ③ 수주서 선택 → ④ 생산요청수량·기한 입력 → ⑤ [확인]

1) 수주서 조회 · 선택

[수주서로 등록] 버튼을 클릭하면 수주서 선택 팝업이 열립니다. 수주일자(예: 2026-05-01 ~ 2026-05-31)와 공장을 지정하고 [조회]하면 수주서 조회 팝업이 나타나 조건에 맞는 수주서 목록을 보여줍니다. 대상 수주서를 선택하고 [확인]합니다.

ℹ️ 공장을 선택하지 않고 조회하면 “공장 선택 후 조회하세요.” 안내가 표시됩니다.

2) 생산요청수량 · 기한 입력

수주서를 선택하면 수주정보와, 선택한 공장에서 생산하는 품목의 상세품목정보가 표시됩니다.

  • ① 검색 조건: 수주일자 · 공장. (수주서 조회 시 사용한 조건)
  • ② 수주정보: 선택한 수주서의 정보(수주번호·수주일자·거래처·납기일자·공장)가 표시됩니다.
  • ③ 상세품목정보: 수주서 품목 중 선택한 공장에 해당하는 품목만 표시됩니다. 품목·규격·단위·수주수량은 자동 표시(읽기 전용)이며, 생산요청수량은 수주수량 범위 내에서, 생산요청기한은 직접 입력합니다. (수주수량 초과 시 안내가 표시되고, 0으로 두면 해당 품목은 제외됩니다.)
  • ④ 확인: 입력 내용을 저장하고 생산요청서가 등록됩니다. (예: 캔버스 에코백 200 / 아로마 향초 500, 기한 2026-06-09)

✅ 이미 생산요청이 등록된 수주 품목은 기존 생산요청번호·기생산요청수량이 함께 표시되어, 남은 수량만 추가로 요청할 수 있습니다.

3) 참조 수주서 확인

조회 화면 ③ 기본 정보의 참조 컬럼에서 수주서 링크를 클릭하면 이 생산요청서가 참조한 원본 수주서를 확인할 수 있습니다.

  • ① 수주정보: 참조한 수주서의 기본 정보입니다.
  • ② 상세정보: 수주서의 전체 품목이 표시되며, 이 생산요청서에 포함된 품목만 생산요청수량·생산요청기한이 채워집니다. 다른 공장 품목 등 생산요청 대상이 아닌 품목은 생산요청수량이 ‘---’로 표시됩니다.

⊙ 입력 예제 2 — 직접 등록

수주서 없이 품목을 직접 선택해 생산요청서를 작성하는 방법입니다.

진행 순서: ① [등록] → ② 품목 선택 → ③ 생산요청수량·기한 입력 → ④ [확인]

[등록] 버튼을 클릭하면 생산요청 상세 팝업이 열립니다.

  • ① 기본정보: 생산요청번호(저장 시 자동 채번)·공장·작성자·부서가 표시됩니다. 공장은 필수 항목이며, 작성자·부서는 로그인 사용자 정보로 자동 입력됩니다.
  • ② 요청 상세정보: [등록] 버튼으로 품목 조회 창을 열어 생산할 품목을 선택하면 목록에 추가됩니다. 품목·규격·단위는 자동 표시되며, 생산요청수량·생산요청기한을 직접 입력합니다. 잘못 추가한 품목은 체크 후 [삭제]로 제거합니다. 입력을 마치고 [확인]하면 생산요청서가 등록됩니다.

2.6. MRP

MRP(자재소요량계획, Material Requirements Planning)는 확정된 주간생산계획(MPS)을 기준으로, 생산에 필요한 원·부자재를 언제 얼마나 조달해야 하는지 계산하는 화면입니다. 부품별·일자별로 필요수량과 가용수량을 산출해 부족분(신규 구매요청 필요수량)을 도출하며, 이 부족분이 구매요청으로 이어집니다.

메뉴 경로: [생산관리]-[생산계획]-[MRP]

💡 MRP 실행(계산)은 이 화면이 아니라 [생산관리]-[생산계획]-[주간생산계획]에서 [MRP 실행] 버튼으로 수행합니다. 이 MRP 화면은 실행된 결과(실행내역)를 조회·확인하는 화면입니다. (→ 맨 아래 ‘MRP 실행 방법’ 참고)

  • 부품 · 규격 · 단위: 소요가 발생한 원·부자재 정보입니다.
  • 일자별 필요수량: 해당 일자에 필요한 수량입니다.
  • 일자별 가용재고: 해당 일자에 사용 가능한 재고 수량입니다.
  • 합계: 부품별 일자 필요수량·가용재고의 합계 행입니다.

부품별 실행결과 — 필요수량·가용수량 계산 근거

부품별 탭에서는 필요수량과 가용수량이 어떤 항목으로 구성되는지 세부 내역까지 보여줍니다.

  • 필요수량 = 생산계획수량 기반 총 소요수량 + 안전재고 + LOT으로 인한 추가필요수량 → ‘필요수량 합계’
  • 가용수량 = 현재고량 + 구매요청 미전환수량 + 구매오더 미입고 수량 + 창고이동 요청수량 → ‘가용수량 합계’
  • 신규 구매요청 필요수량 = 필요수량 합계 − 가용수량 합계. 즉 현재 확보 가능한 수량으로 부족한 부분이며, 이 수량이 신규 구매요청 대상이 됩니다.

✅ 부품별 결과는 각 부품에 대해 일자별 행으로 펼쳐지며, 위 계산식에 따라 일자별 부족분(신규 구매요청 필요수량)을 한눈에 확인할 수 있습니다.

예외사항 확인

실행내역 그리드의 예외사항 ‘N건’ 링크를 클릭하면 MRP 예외사항 팝업이 열립니다.

  • 일자 · 품목 · 규격 · 단위: 예외가 발생한 항목 정보입니다.
  • 필요수량 · 부족수량: 해당 일자의 필요수량과 부족수량입니다.
  • 예외코드 · 메시지: 예외 유형과 안내 메시지입니다. 예) NEED_DATE_PAST — “부품 준비일(생산일자 전일)이 이미 경과. 주간생산계획 조정 및 MPS 재확정이 필요합니다.”

ℹ️ 예외사항이 있으면 조달 일정이 이미 지났다는 의미이므로, 주간생산계획(MPS)을 조정하고 다시 확정·MRP 실행하는 것이 좋습니다.

  • [MRP 실행]으로 생성된 결과가 이 MRP 화면의 ‘MRP 실행내역’에 표시됩니다.

3.1. 생산지시서

🏭 생산지시서는 확정된 생산계획(계획오더)이나 수주를 실제 생산을 위한 ‘생산지시’로 만들어, 어떤 제품을 · 언제 · 얼마나 · 어느 공정/작업장에서 생산할지 지시하는 문서입니다. 자재이동·생산실적·원가집계 등 생산실행의 모든 출발점이 됩니다.

1) 개요 — 생산지시서란

주간생산계획에서 확정된 계획을 그대로 실행하거나(직접 입력), 계획 단계의 계획오더(MPS)를 불러와 생산지시로 전환합니다. 생산지시서가 발행되면 그 제품의 BOM · 공정순서(라우팅) · 작업장 · 표준공수가 함께 확정되어, 이후 자재이동요청 · 생산실적 · 원가집계가 모두 이 지시서를 기준으로 처리됩니다.

💡 왜 필요한가 — 생산지시서가 있어야 ① 어떤 자재를 공정창고로 보낼지(자재이동요청), ② 어떤 공정에서 얼마를 만들지(생산실적), ③ 제품별 재공(WIP)·원가가 얼마인지를 추적할 수 있습니다. 생산지시 한 건 = 완제품/반제품 1종을 한 번 생산하는 단위입니다.

핵심 개념

  • 생산지시 헤더 — 무엇을·언제·얼마나: 품목 · 라우팅 · 총생산목표수량 · 시작/완료일 · 발행일자 · 상태. 생산지시번호(PIR…)로 식별됩니다.
  • 생산지시 상세(공정) — 어디서·어떻게: 라우팅에 정의된 공정·작업·작업장·근무조 단위로 전개되며, 공정별 생산지시수량과 공정 시작/종료 일시를 가집니다.
  • 직접 / MPS 참조: 계획 없이 바로 입력(직접)하거나, 주간생산계획에서 만든 계획(MPS실행번호)을 불러와 전환(MPS 참조)합니다.
  • 상태: 생산지시는 발행 → 진행 → 완료 → 정산 단계를 거치며, 단계에 따라 후속 작업(자재투입·실적·원가)이 진행됩니다.

2) 화면 진입

좌측 사이드바 [생산관리] ▸ [생산실행] ▸ [생산지시서] 메뉴를 클릭합니다.

3) 목록 화면

화면은 상단 조회 조건, 가운데 기본정보(생산지시서 목록), 하단 생산지시 상세정보(선택한 지시서의 공정별 작업) 로 구성됩니다. 목록의 행을 선택하면 하단에 그 지시서의 공정이 표시됩니다.

생산지시서 목록 — 생산계획일자 기간으로 조회한 결과 (예: 2026-05)

  • ① 조회 조건 — 생산계획일자(기간) · 공장 으로 조회합니다. [조회] / [초기화].
  • ② 툴바 — [마감] [다운로드] [출력] [등록] [수정] [삭제] [결재상신]. [등록]으로 새 생산지시를 만들고, [출력]으로 생산지시서를 인쇄합니다.
  • ③ 기본정보(생산지시 목록) — 생산지시번호 · 공장 · 품목 · 규격 · 단위 · 라우팅 · 총생산목표수량 · 시작/완료일 · 발행일자 · MPS실행번호 · 상태 · 작성자 등. 행을 선택하면 하단 상세가 갱신됩니다.
  • ④ 생산지시 상세정보 — 선택한 지시서를 라우팅 공정 단위로 전개한 작업 목록(공정 · 작업 · 작업장 · 근무조 · 수량 · 공정 시작/종료).

📋 표시 데이터 예시 — 2026-05 기간 조회 시 PIR2026050015~021(캔버스 에코백 FG-A01, 봉제완료 본체 반제품 등) 7건이 모두 ‘진행중’ 상태로 표시됩니다.

4) 상세정보 — 공정별 작업 읽기

선택한 생산지시서의 공정 상세 — 라우팅 공정 순서대로 전개

선택한 생산지시서가 라우팅에 정의된 공정 순서대로 펼쳐집니다. 각 공정의 작업장·근무조·생산지시수량·생산실적수량과 공정 시작/종료 일시를 확인합니다.

  • ① 공정 · 작업 · 작업장 — 라우팅(공정순서)에 정의된 공정/작업과 수행 작업장. (예: 도장(외주) → 포장)
  • ② 근무조 · 수량 — 근무조(교대)와 공정별 생산지시수량 / 생산실적수량. 실적은 생산 실적 입력 전이면 0.
  • ③ 공정시작 — 공정 시작 예정 일자 · 시 · 분.
  • ④ 공정종료 — 공정 종료 예정 일자 · 시 · 분.

5) 생산지시 등록

툴바 [등록] 을 누르면 생산지시서 상세 팝업이 열립니다. 헤더(기본정보)와 공정(상세정보)을 입력해 새 생산지시를 만듭니다.

생산지시 등록 팝업 ‘생산지시서 상세’ — 빈 양식 (별표(*)는 필수 항목)

  • ① 작성자 · 부서 — 지시를 생성하는 담당자 / 부서.
  • ② 구분 — [직접] / [MPS 참조] 중 선택(필수). [직접] 선택 시 ‘생산 지시 품목 선택’ 팝업이 열려 공장·품목을 고르고, [MPS 참조] 선택 시 ‘주간생산계획(MPS) 선택’ 팝업이 열려 계획(MPS실행번호)을 골라 불러옵니다. 기존 건을 수정할 때는 구분 영역이 숨겨집니다.
  • ③ 기본정보 — [추가](‘직접’일 때만 표시)로 행을 만들어 품목 · 라우팅 · 총생산목표수량 · 시작일 · 완료일 · 발행일자 를 입력합니다. 품목·라우팅을 고르면 단위·공장 등이 자동 채워지고, 생산지시번호는 저장 시 자동 채번됩니다. 발행일자는 기본값이 오늘 날짜이며 직접 수정할 수 있습니다. 공정별 생산지시수량은 총생산목표수량과 동일하게 자동 적용(읽기전용)됩니다.
  • ④ 생산지시 상세정보 — 선택한 라우팅의 공정이 자동 전개됩니다. 공정별 생산지시수량과 공정 시작/종료(일자·시·분)를 입력합니다.
  • ⑤ [확인] 으로 저장합니다(취소는 [취소]).

ℹ️ 직접 vs MPS 참조 — 반복 생산이나 긴급 건은 [직접]으로 바로 입력하고, 주간생산계획으로 수립한 계획은 [MPS 참조]로 불러와 계획–실적을 연결합니다.

🔎 선택 팝업 — [직접]은 ‘생산 지시 품목 선택’ 팝업(공장·품목·규격·단위·라우팅 확인 후 선택), [MPS 참조]는 ‘주간생산계획(MPS) 선택’ 팝업(MPS실행일자·공장·품목·생산기간으로 조회 → 라우팅 단위로 선택)에서 대상을 고릅니다. MPS 참조로 고르면 참조한 MPS실행번호가 기본정보에 함께 표시됩니다. (MPS 조회 기간은 1개월 이내로 지정)

📅 발행일자 (2026-06 추가) — 생산지시 등록 시 기본값은 오늘 날짜이며 직접 수정할 수 있습니다. 발행일자는 목록과 등록 팝업의 기본정보에 컬럼으로 표시됩니다.

6) 생산지시 상태 흐름

생산지시는 생성 후 발행 · 진행 · 완료 · 정산 단계를 거칩니다. 목록의 ‘상태’ 컬럼에서 현재 단계를 확인합니다(예시 데이터는 모두 ‘진행중’).

코드 단계 설명 · 전환 시점
생성 (CR) 작성 생산지시서를 만들고 저장한 단계. 아직 작업장 배포 전.
배포 (RL) 발행 작업장에 배포되어 실행 가능. 이때 BOM도 함께 배포되어 자재투입·외주발주가 가능.
진행중 (PG) 진행 발행 후 시작일이 도래하고 생산실적이 입력되면 자동 전환.

3.2. 자재이동요청

📦 자재이동요청은 생산에 필요한 원·부자재를 각 보관 창고에서 해당 생산지시서 공장의 ‘공정창고’로 이동시키는 작업입니다. (공정창고는 공장마다 기본으로 하나씩 존재) 생산지시서 단위로 ‘어떤 자재를 공정창고로 보낼지’를 요청하면, 입출고요청서에 ‘이동요청’으로 쌓이고 → [이동실행]에서 실제 재고가 옮겨집니다.

1) 개요 — 자재이동요청이란

생산을 시작하려면 BOM상의 원·부자재가 그 제품을 만드는 공장의 공정창고에 있어야 합니다. 자재이동요청은 원자재 창고 등에 보관된 자재를, 생산지시서가 지정한 공장의 공정창고로 옮기도록 요청하는 화면입니다.

💡 왜 필요한가 — 자재가 공정창고로 이동되어 있어야 생산실적 집계와 재공(WIP) 원가가 정확히 잡힙니다. 생산지시서별로 필요한 자재 수량이 자동 표시되어, 그대로 출고(이동)를 요청합니다.

핵심 개념

  • 출고요청(자재이동요청) — 원·부자재 창고 → 공정창고 로 자재를 보내는 요청. 입고(공장·창고)는 생산지시서 공장의 공정창고로 자동 고정됩니다.
  • 반납요청 — 공정창고 → 원자재 창고 로 되돌리는 요청. 공정창고의 과불출·미사용 자재를 반납합니다. 출고(공장·창고)가 공정창고로 자동 고정됩니다.
  • 두 요청 모두 입출고요청서에 ‘이동요청’으로 쌓이며, [이동실행]에서 실제 재고가 이동합니다.
  • 분할 요청 가능 — 한 번에 전량을 요청하지 않고 잔여수량 범위에서 여러 번 나눠 요청할 수 있습니다.

  • ① 조회 조건 — 생산 지시서 발행일(기간) · 생산지시서번호 로 조회
  • ② 다운로드 / 출력 — 조회 결과를 엑셀 다운로드 / 출력
  • ③ 기본 정보 — 자재 이동이 필요한 생산지시서 목록(생산지시번호·발행일·작성자·부서·비고). 행을 선택하면 하단에 자재 목록이 표시됩니다.
  • ④ 자재이동요청 상세정보 — 선택한 생산지시서에 투입될 자재별 수량(총 지시수량 / 기 출고요청수량 / 잔여수량 / 반납수량)

3.4. 생산실적

🏭 생산실적은 생산지시서에 따라 실제 생산한 결과(양품·불량 수량, 작업 시간)를 입력·확정하는 화면입니다. 실적을 입력하면 Backflush로 BOM 자재가 자동 출고(재고 차감)되고, 완성 수량이 완제품/반제품 재고로 입고되며, 제조원가 전표가 발생합니다.

1) 개요 — 생산실적이란

생산지시서별로 실제 생산 결과를 공정·작업 단위로 입력합니다. 작업의 시작/종료 시각, 양품수량·불량수량, 실제 노무·설비 시간을 기록하면, 시스템이 해당 공정 BOM의 자재를 자동 불출(Backflush)하고 완성 수량을 재고로 입고합니다. 입력된 실적은 생산원가 집계와 재고 이동의 근거가 됩니다.

💡 왜 필요한가 — 생산실적이 있어야 ① 실제 투입 자재·시간이 확정되어 제조원가가 계산되고, ② 완성품이 재고로 입고되어 판매가 가능하며, ③ 생산지시 대비 실적 차이를 분석할 수 있습니다. 회계·재고 처리의 구체 로직은 아래 3.5 페이지에서 다룹니다.

핵심 개념

  • 공정실적 확정 — 공정/작업 단위로 실적을 입력하고 확정합니다. 모든 공정이 완료되면 생산이 끝납니다.
  • Backflush(자동 자재 불출) — 실적(완성 수량)을 등록하는 순간, 해당 공정에 매핑된 BOM 자재 중 Backflush 대상 자재를 양품수량 × 소요량만큼 출고창고에서 자동 차감합니다.
  • 양품 / 불량 — 양품수량과 불량수량(불량코드별)을 입력합니다. 불량은 정상불량/비정상불량으로 구분되어 원가 처리가 달라집니다.
  • 진행상태 — 실적은 초안 → 확정 단계로 관리되며, [생산실적 확정/취소]로 전환합니다.

3.5. 생산실적 관련 전표처리 로직

🧾 이 페이지는 생산실적 입력·확정 시 발생하는 회계 전표(분개)와 재고 이동을 정리합니다. 상세 분개 레퍼런스는 4.2. 제조원가 회계처리 를 따릅니다.

1) 한눈에 — 생산실적 입력이 일으키는 일

생산실적(공정 작업실적)을 확정하면 두 가지가 동시에 일어납니다 — ① 재고 이동(자재 출고 + 완성품 입고), ② 회계 전표(재료비·가공비 재공품(WIP) 인식, 완성품 입고대기 대체).

⏱️ 실시간 vs 월말 — 아래 전표(T1~T3)는 생산실적입력 시점에 실시간 발생합니다. 가공비 실제배부·배부차이·생산지시서별 정산·매출원가차이는 월말 제조원가 마감(4.2. 제조원가 회계처리)에서 처리됩니다.

2) 재고 처리 — Backflush 출고와 완성품 입고

Backflush — 생산실적(완성 수량)을 등록하는 순간, 해당 공정에 매핑된 BOM 자재 중 Backflush=Y 자재를 (양품수량 × 단위소요량)만큼 출고창고에서 자동 차감합니다. 동시에 원가·재무회계의 재고 장부가 갱신됩니다.

  • 원재료/부재료 출고(재고 ↓) — Backflush로 자동 불출. 출고창고는 공정/작업 BOM의 출고저장위치(issue_sloc).
  • 재공품(WIP) 증가 — 출고된 재료비 + 표준배부 가공비가 재공품으로 집계됩니다.
  • 완성품 입고(최종 공정) — 마지막 공정이 완료되면 완성 수량이 완성품입고대기(제품-완성품미입고)로 입고되고, 완제품 창고이동 시 정식 완제품 재고로 전환됩니다.
  • 비정상불량 — 재공품에서 차감되어 타계정(손실)으로 대체됩니다.

⚠️ Backflush 재고 부족 — 시스템 재고 < 차감 수량이면 “Deficit of XX in SLOC” 오류로 전표가 생성되지 않습니다. 입고·이동 전표 누락, 저장위치(SLOC) 오지정, Lot 불일치 등이 원인 → 3.2. 자재이동요청 등으로 재고를 보충한 뒤 재시도합니다.

4.1. 생산투입수량확정

개요

생산투입수량확정은 월 재고실사에서 확인된 원재료·부재료·반제품의 차이수량 중 ‘정상차이수량’만큼을, 해당 자재가 투입된 제품·반제품의 생산비율로 추가 투입수량으로 안분(배부)한 뒤 확정(마감)하는 화면입니다. 확정된 정상차이 투입분은 재료비로 인식되어 제품·반제품의 제조원가에 가산됩니다.

⚠️ 선행조건: 모든 창고의 재고실사가 마감(실사 확정)되어야 조회·배부가 가능합니다. 실사가 마감되지 않은 상태로 조회하면 ‘재고실사 마감필요’ 안내가 표시됩니다.

화면 진입

좌측 사이드바 [생산관리] ▸ [생산마감] ▸ [생산투입수량확정]. 상단 공장·기준월을 선택해 [조회]합니다(기준월 예: 2026-05).

화면 구성

화면은 ‘1. 대상 품목 실사 차이 요약’(마스터)과 ‘2. 제품/반제품 별 배부 상세 및 사용자 조정’(디테일)의 상하 마스터-디테일로 구성됩니다.

  • 1. 대상 품목 실사 차이 요약 — 실사번호 · 공장 · 창고 · 품목코드 · 품목명 · 품목유형(원재료/부재료/반제품) · 규격 · 단위 · 장부수량 · 실사수량 · 차이수량 · 정상차이수량 · 비정상차이수량 · 비고 · 배부상태. 버튼: [투입수량 확정(마감)] · [생산비율 자동안분처리] · [다운로드], 체크박스 ‘정상차이수량 품목만 보기’.
  • 2. 제품/반제품 별 배부 상세 및 사용자 조정 — 공장 · 품목코드 · 품목명 · 품목유형 · 규격 · 단위 · 구분(완제품/재공품) · 표준투입수량 · 투입비율(%) · 추가투입수량 배부 · 최종 투입수량 · 비고 · 최종작업자 · 작업일시. 하단에 추가투입수량 합계·미투입수량이 표시됩니다.

선행조건 — 재고실사 마감

조회 시 모든 창고의 재고실사 마감 여부를 검증합니다. 대기·결재진행·반려 등 미마감 창고가 있으면 배부가 차단됩니다.

  • 미마감 상태로 조회하면 ‘창고 재고실사가 아직 마감되지 않았습니다. 먼저 실사를 확정한 후 차이 배부를 진행해 주세요.’ 안내가 표시됩니다. 재고실사를 확정한 뒤 다시 조회합니다.

처리 절차

  • 차이수량 확인 — 차이수량 = 장부수량 − 실사수량. 실사수량이 부족해 차이수량이 음수인 품목 중 ‘정상차이수량’이 있는 건만 제품·반제품 안분 대상입니다.
  • 정상 / 비정상 구분 — 정상차이수량은 제조원가에 반영되는 차이, 비정상차이수량(예: ‘생산투입기록 없음’)은 원가 반영에서 제외됩니다.
  • 생산비율 자동안분처리 — [생산비율 자동안분처리]를 누르면 정상차이수량을 해당 자재가 투입된 당월 제품·반제품의 생산비율(투입비율)대로 자동 안분해 추가투입수량 배부를 채웁니다. 또는 ②에서 추가투입수량 배부를 직접 키인할 수 있습니다(정상차이수량이 있는 행만 입력 가능). 예) 표준투입수량 5,000 · 투입비율 30% 행에 추가투입수량 50 → 최종 투입수량 5,050.
  • 배부상태 — 정상차이수량이 없는 라인은 상태 없음, 정상차이수량이 있는데 100% 안분되지 않으면 ‘미배부’, 모두 안분되면 ‘배부완료’입니다.
  • 투입수량 확정(마감) — 모든 라인이 배부완료(또는 정상차이 없음) 상태일 때 [투입수량 확정(마감)]으로 확정합니다(‘…의 생산투입수량을 확정하시겠습니까?’). 확정 후에도 확정취소가 가능하나, 공장별 원가마감·전체마감 상태이면 확정취소할 수 없습니다.

회계처리 (전표)

확정된 정상차이 투입분은 재료비로 인식되어 제조원가에 가산됩니다. 제조원가 회계처리(4.2)의 【9】 생산투입수량확정 단계로, 재료비 인식(T1)과 같은 흐름을 정상차이 수량만큼만 인식합니다(9a 추가투입분 원재료 출고 / 9b 재공품 안분(미완성분) / 9c 완성품 원가 가산(입고완료분)).

  • 9a 원재료 출고 — (차) 원재료비(50100)·부재료비(50200) / (대) 원재료(15300)·부재료(16200).
  • 9b·9c 재공품·완성품 대체 — (차) 재공품(16900) / (대) 원재료비(50100)·부재료비(50200), 반제품 투입 시 (대) 반제품(17300).
  • 표준원가형은 동일 구조를 표준단가로 인식합니다. 차변/대변 분개 상세는 [4.2. 제조원가 회계처리]를 참조하세요.

연계

  • 선행은 재고실사 마감, 후속은 제조원가 마감 및 결산의 재고마감 단계입니다. 확정된 정상차이 투입분은 제품·반제품의 실제 제조원가와 원가조정 내역에 반영됩니다.

5.5. 생산지시서별 재공재고 현황

개요

생산지시서별 재공재고 현황은 생산지시서별로 월말 시점의 재공재고(WIP)를 재료비·변동가공비·고정가공비 비목별로 나눠 표준 대비 실제로 산출해 보여주는 조회 전용 보고서입니다. 공정·작업 단위로 기초 재공에서 당기 작업분을 더하고 완성품으로 전환된 분을 빼서 차월로 이월되는 재공재고를 확인하며, 표준과 실제 금액의 차이도 함께 봅니다.

💡 재공재고수량(양품) = 작업별 양품수량 − 완성(전환)수량. WIP금액(표준) = 표준소요량(또는 표준시간) × 표준단가 WIP금액(실제) = 실제투입수량(또는 실제시간) × 실제단가 표준-실제 차이금액 = WIP금액(표준) − WIP금액(실제) 기초WIP(이월) + 당기작업분 − 완성품전환 = 차월이월.

화면 진입

좌측 사이드바 [생산관리] ▸ [보고서] ▸ [생산지시서별 재공재고 현황]. 상단 기준월·공장을 선택해 [조회]합니다. 조건을 비우려면 [초기화], [상세 검색]으로 생산지시서 등 조건을 추가할 수 있으며, [다운로드]·[출력]로 내보냅니다.

화면 구성

화면은 상단 ‘생산지시서 목록’(마스터)과 하단 ‘공정·작업별 재공재고 산출[표준 대비 실적]’(디테일)의 마스터-디테일로 구성됩니다. 마스터에서 생산지시서를 선택하면 하단에 그 지시서의 재공재고가 표시되고, 하단은 재료비 / 변동가공비 / 고정가공비 탭으로 나뉩니다.

  • 생산지시서 목록(마스터) — 생산지시서번호 · 제품코드 · 제품명 · 규격 · 단위 · 생산지시수량 · 생산지시서 발행일 · 계획시작일 · 계획종료일 · 작성자 · 부서 · 비고.

  • 공정·작업별 재공재고(디테일) — 공통 좌측: 공정명 · 작업명 · 작업장 · 작업순번과 A.기초WIP(이월)[기초수량·기초단가·기초금액], B.당기작업분[양품 · 정상불량 · 비정상불량 · 합계], C.완성품전환[전환수량 · 총평균단가 · 전환금액(실제)], D.차월이월[이월수 · 이월단가 · 이월금액(실제)]. 비목별 표준/실제 컬럼은 탭에 따라 달라집니다.
  • 재료비 탭 — 자재코드 · 자재명 · 표준소요량 · 표준재료비단가 · WIP금액(표준) · 실제투입수량 · 실제재료비단가 · WIP금액(실제) · 표준-실제 차이금액. (예: 캔버스 원단 표준 2,500,000 vs 실제 2,627,273 → 차이 −127,273.)
  • 변동가공비 탭 — 활동코드 · 활동명 · 계정과목 · 표준노무시간(분) · 표준설비시간(분) · 표준활동단가 · WIP금액(표준) · 실제노무시간(분) · 실제설비시간(분) · 실제활동단가 · WIP금액(실제) · 표준-실제 차이금액. 작업 진행은 준비(S)·가공(P)·완료(F) 구분으로 집계됩니다.
  • 고정가공비 탭 — 코스트센터 · 고정비 계정과목 · 표준배부율 · 배부적수값 · WIP금액(표준) · 실제배부율 · WIP금액(실제) · 표준-실제 차이금액.

재공재고(WIP) 산출

  • 재공재고수량은 작업별 양품수량에서 완성(전환)수량을 뺀 미완성 수량입니다(최종 작업까지 완료된 양품은 완성품으로 전환).
  • WIP금액(표준)은 재공수량 기준 표준소요량·표준시간에 표준단가를 곱한 값, WIP금액(실제)은 실제투입·실제시간에 실제단가(총평균단가 기준)를 곱한 값이며, 둘의 차이가 표준-실제 차이금액입니다.
  • 월마감 시 완성분은 전환금액으로 제품·반제품에 대체되어 해당 생산지시서의 재공은 0이 되는 것이 원칙이며, 미완성분만 차월로 이월됩니다. 표준-실제 차이는 원가차이로 정산됩니다.
