1.1. 사업부 (Profit Center)

개요

원가 산정의 단위가 되는 사업부(Profit Center)를 등록·관리하는 화면입니다. 사업부는 회사를 수익 책임 단위로 나눈 구분이며, 그 아래에 코스트센터를 묶어 원가를 집계합니다.

🧱 계층 — 사업부 ▸ 코스트센터. 사업부 등록 시 ‘연결부서’를 지정하면, 이후 그 사업부 아래에 코스트센터를 만들 때 사용할 수 있는 부서가 ‘연결부서의 하위 부서’로 제한됩니다. 즉 사업부의 책임 부서 트리 안에서만 코스트센터-부서 1:1 매핑이 이루어집니다.

화면 진입

좌측 사이드바 [원가관리] ▸ [기준정보관리(BM)] ▸ [사업부 (Profit Center)]

목록 화면

사업부 목록 — 사업부 코드 / 사업부명 / 연결부서코드 / 연결부서명 / 설명 / 사용여부

  • ① 기능 버튼 — [등록] / [수정] / [삭제] / [다운로드] / [업로드]. 수정·삭제는 그리드에서 체크박스로 선택 후 사용합니다.
  • ② 그리드 — 한 행이 사업부 1건. 사업부 코드 / 사업부명 / 연결부서코드 / 연결부서명 / 설명 / 사용여부. 연결부서 컬럼은 사업부를 책임지는 부서이며, 이 부서의 하위 부서들이 해당 사업부 아래 코스트센터의 매핑 후보가 됩니다.

📌 표시 데이터 예시 — PFC001 메인사업부 / 연결부서 00005 생산총괄. ‘생산총괄’의 하위 부서들이 PFC001 사업부 아래 코스트센터에 매핑할 수 있는 부서 풀이 됩니다.

사업부 등록

상단 [등록] 버튼을 클릭하면 사업부 상세 팝업이 열립니다.

사업부 상세(등록) 팝업

  • ① 사업부 코드 — ‘자동부여’로 채워지며 저장 시 시스템이 채번 (예: PFC001)
  • ② 사업부명* — 사업부의 표시명. 후속 화면(코스트센터 등록 등)에서 이 이름으로 선택됩니다.
  • ③ 연결부서* — 돋보기 클릭 → 부서 조회 팝업에서 이 사업부의 책임 부서(상위 부서)를 1개 선택합니다. 선택한 부서의 하위 부서들만 이후 이 사업부 아래 코스트센터를 만들 때 ‘부서’로 선택할 수 있습니다 (코스트센터 ↔ 부서는 1:1).
  • ④ 사업부 설명 — 자유 텍스트 메모 (책임 영역, 핵심 제품군 등)
  • ⑤ 사용여부* — 토글. OFF면 신규 코스트센터 등록 화면의 사업부 선택 대상에서 제외됩니다.

필수 항목을 채우고 [저장] 클릭하면 목록 그리드에 추가됩니다.

사업부 수정

목록에서 사업부를 체크박스로 선택한 뒤 [수정] 버튼을 클릭하면 동일 팝업이 데이터가 채워진 상태로 열립니다 (사업부 코드는 readonly).

사업부 수정 — PFC001 메인사업부 데이터가 채워진 상태

  • 연결부서를 바꾸면 이 사업부 아래에서 ‘앞으로 새로 만들 코스트센터’가 선택할 수 있는 부서 풀(연결부서의 하위 부서)이 달라집니다. 이미 등록된 코스트센터의 부서 매핑은 자동으로 바뀌지 않으니, 부서 트리가 바뀐 경우 각 코스트센터에 들어가 매핑을 점검하세요.

코스트센터와의 연결

사업부를 등록하면 [원가관리] ▸ [기준정보관리(BM)] ▸ [코스트센터 (Cost Center)] 화면에서 그 사업부 아래에 코스트센터를 추가할 수 있습니다. 좌측 트리에서 사업부 노드를 선택한 상태로 [코스트센터 추가] 버튼을 누르면 해당 사업부 하위로 등록됩니다.

코스트센터 화면의 좌측 트리 — PFC001 메인사업부 ▸ COC007 생산총괄 ▸ COC008~COC013 하위 코스트센터들

  • ① 사업부가 트리의 ‘루트’ 역할을 하고, 그 아래로 코스트센터들이 계층을 이룹니다.
  • ② 하나의 사업부 안에 다수의 코스트센터를 둘 수 있고, 코스트센터끼리도 부모-자식 계층을 가질 수 있습니다. 각 코스트센터에는 부서를 1:1로 매핑하며, 선택 가능한 부서는 부모 사업부의 연결부서 아래에 있는 부서로 한정됩니다.

🌳 핵심 관계
• 사업부 ↔ 연결부서 = 1:1 (사업부의 책임 부서, 상위 부서)
• 사업부 ↔ 코스트센터 = 1:N (한 사업부에 다수 코스트센터)
• 코스트센터 ↔ 부서 = 1:1, 단 ‘사업부 연결부서의 하위 부서’ 풀 안에서만 선택 가능
→ 원가/실적의 부서별 집계는 코스트센터의 부서 매핑을 기준으로 산정됩니다.

삭제 / 사용여부 / 다운로드 / 업로드

  • 삭제 — 사업부 아래에 등록된 코스트센터가 하나라도 있으면 삭제가 막힙니다. 하위 코스트센터를 모두 정리한 뒤에 사업부를 삭제할 수 있습니다.
  • 사용여부 토글 — 행 우측의 토글. OFF로 바꾸면 신규 코스트센터 등록 시 선택 대상에서 제외 (기존 등록된 코스트센터·전표에는 영향 없음)
  • 다운로드 — 현재 사업부 목록을 엑셀로 내려받기
  • 업로드 — 엑셀 양식에 맞춰 여러 사업부를 일괄 등록

1.2. 코스트센터 (Cost Center)

개요

실제 비용이 집계되는 단위인 코스트센터(Cost Center)를 사업부 아래 트리 형태로 등록·관리하는 화면입니다. 각 코스트센터는 부서 1개와 1:1로 매핑되며, 이 매핑을 기준으로 원가가 부서별로 집계됩니다.

🧱 계층 — 사업부 ▸ 코스트센터. 코스트센터는 부모 사업부의 ‘연결부서’ 아래에 있는 부서들 중에서 1개를 선택해 매핑합니다. 상위가 되는 부서가 있으면 그 아래에 또 자식 코스트센터를 둘 수 있어 트리 깊이도 자유롭게 가져갈 수 있습니다.

화면 진입

좌측 사이드바 [원가관리] ▸ [기준정보관리(BM)] ▸ [코스트센터 (Cost Center)]

화면 구성

화면은 좌측의 ‘사업부 ▸ 코스트센터’ 트리와, 우측의 ‘코스트센터 상세’ 폼으로 나뉘는 2분할 레이아웃입니다. 트리에서 노드를 클릭하면 우측에 그 노드의 상세가 표시되고, 사업부 노드를 선택한 상태로 [코스트센터 추가] 버튼을 누르면 그 사업부 아래에 새 코스트센터가 만들어집니다.

코스트센터 화면 — 좌측 트리(사업부 ▸ 코스트센터) / 우측 상세 폼

  • ① 기능 버튼 — [코스트센터 추가] / [삭제] / [다운로드] / [업로드] / [조회]
  • ② 좌측 트리 — [PFC001] 메인사업부 ▸ [COC007] 생산총괄 ▸ [COC008]~[COC013] 식으로 사업부 아래에 코스트센터가 계층으로 표시됩니다.

코스트센터 유형

코스트센터는 ‘유형’에 따라 직접 / 간접 / 판관 세 가지로 나뉘고, 유형이 ‘직접’일 때는 다시 ‘직접 CC 유형’으로 내부 / 외주로 세분됩니다.

  • 직접(Direct) — 제품 생산에 직접 투입되는 부서·라인. 가공/조립/도장처럼 작업이 일어나는 현장의 코스트센터.
  • 간접(Indirect) — 제조원가에는 들어가지만 직접 작업하지는 않는 부서. 품질관리/생산기획/설비보전/창고관리 등 지원 부서.
  • 판관(SG&A) — 제조와 관계없는 판매·관리 부서. 영업/관리/회계 등.

직접 코스트센터는 한 번 더 갈라집니다:

  • 직접·내부 — 자사 인력·설비로 직접 작업. 부서 매핑은 ‘연계조직’으로 회사 조직 1개 선택.
  • 직접·외주 — 외부 거래처에 위탁해 작업. 부서 대신 ‘외주거래처’를 1:1로 매핑.

🔗 규칙 — ‘직접·외주’ CC는 외주 발주를 받는 거래처와 1:1로만 매핑되어야 합니다. 한 외주 거래처에 여러 외주 코스트센터를 매핑하거나, 한 외주 코스트센터에 여러 거래처를 매핑하는 것은 불가합니다. 외주 공정/거래가 여러 개라면 각각 별도의 외주 코스트센터를 만드세요.

코스트센터 등록

좌측 트리에서 ‘부모’가 될 사업부(또는 상위 코스트센터)를 선택한 뒤 [코스트센터 추가] 버튼을 클릭하면 우측이 빈 등록 폼으로 바뀝니다.

코스트센터 등록 빈 폼 — 기본값: 유형=직접, 직접 CC 유형=내부, 사용여부=ON

  • ① [코스트센터 추가] 버튼 — 트리에서 부모 노드를 선택한 상태로 클릭해야 합니다.
  • ② 코스트센터 코드 — ‘자동’ 토글이 ON이면 저장 시 시스템이 채번 (예: COC014). 끄면 직접 입력 가능.
  • ②’ 코스트센터명* — 표시명 (예: 공정품질팀, 가공, 도장외주)
  • ③ 코스트센터 설명 — 자유 텍스트 메모 (책임 영역, 특이사항 등)
  • ④ 유형* — 직접 / 간접 / 판관 중 하나
  • ⑤ 직접 CC 유형* — 유형이 ‘직접’일 때만 활성. 내부 / 외주 중 하나
  • ⑥ 사용여부* — 토글. OFF면 신규 전표·배부 화면 선택 대상에서 제외
  • ⑦ 연계조직 — 부모 사업부의 ‘연결부서’ 아래에 있는 부서 중에서 1개 선택 (내부 직접 CC와 간접/판관 CC)

외주 선택 시 — 외주거래처 영역으로 전환

‘직접 CC 유형’을 외주로 바꾸면, 하단 ‘연계조직’ 영역이 ‘외주거래처 선택’으로 자동 전환됩니다.

등록 폼 — 직접 CC 유형 ‘외주’ 선택 시 하단이 ‘외주거래처 선택’ 영역으로 바뀜

  • ① 직접 CC 유형 = 외주

  • ① 조회조건 — 검색기준(전체 / 1차 원가계정 코드 / 1차 원가계정명)을 선택하고 검색어를 입력해 [조회]합니다. [초기화]는 조건을 비웁니다.
  • ② 다운로드 — 조회된 그리드를 엑셀 파일로 내려받습니다.
  • ③ 목록 그리드 — 1차 원가계정 코드 · 1차 원가계정명 · 1차 구분 · 배부용 원가 계정 구분 · 설명 · 사용여부.

목록 그리드 항목

  • 1차 원가계정 코드 · 1차 원가계정명 — 회계 계정과목과 동일합니다(예: 50300 급여, 51100 복리후생비).
  • 1차 구분 — 계정의 원가 성격 분류입니다(예: 노무비(직원근로), 노무비(일용), 경비 등).
  • 배부용 원가 계정 구분 — 이 1차 계정에 연계된 배부용(2차) 원가계정입니다. 2차 원가계정은 변동비(예: 변동 가공비 배부 계정)와 고정비(예: 고정 가공비 배부 계정)를 구분해 설정할 수 있으며, 노무 활동 배부 계정 등도 연계됩니다. 셀의 돋보기 버튼을 클릭하면 2차 원가계정 조회 팝업이 열려 연계할 배부용 원가계정을 지정할 수 있습니다.
  • 설명 — 원가요소에 대한 설명을 입력합니다.
  • 사용여부 — 해당 원가계정의 사용/미사용을 토글로 제어합니다.

✅ 배부용(2차) 원가계정의 변동비·고정비 구분은 원가 배부 시 기준정보로 활용됩니다. 변동비와 고정비를 서로 다른 배부 기준·로직으로 배부할 수 있어, 제조원가 계산의 정확도를 높입니다.

1.7. 배부용원가계정 (2차계정)

개요

배부용원가계정(2차계정)은 직접원가계정(1차계정)의 원가를 배부하기 위한 배부용 계정입니다. 원가 흐름은 1차원가 → 2차원가(배부용) → 배부적수로 연결되며, 각 2차계정은 변동비/고정비로 구분하고, 배부에 사용할 수 있는 배부적수를 지정합니다. 등록한 2차원가계정은 제조원가·판관비 배부방법설정에서 배부 계정으로 사용됩니다.

💡 원가 연결 구조는 1차원가 ▸ 2차원가(배부용) ▸ 배부적수입니다. 2차원가 구분(변동비/고정비)과 연계 배부적수가 원가 배부의 기준정보가 됩니다.

화면 진입

좌측 사이드바 [원가관리] ▸ [기준정보관리(BM)] ▸ [배부용원가계정 (2차계정)]

화면 구성

좌측 ‘배부용원가계정 내역’(Master)과 우측 ‘2차원가별 선택가능 배부적수 설정’(Detail)으로 나뉘는 2분할 레이아웃입니다. Master에서 2차계정을 선택하면 Detail에 해당 계정에 연계된 배부적수가 표시됩니다.

  • ① 조회조건 — 검색기준(전체 / 2차 원가계정 코드 / 2차 원가계정명) + 검색어 + [조회]/[초기화].
  • ② 배부용원가계정 내역 (Master) — 2차 원가계정 코드 · 2차 원가계정명 · 원가요소 설명 · 2차원가 구분(변동비/고정비) · 사용여부. [등록]/[수정]/[삭제]/[다운로드] 버튼이 있습니다. 사용여부는 해당 2차계정의 사용/미사용 상태로, 미사용 시 배부에 활용되지 않습니다.
  • ③ 2차원가별 선택가능 배부적수 설정 (Detail) — Master에서 선택한 2차계정에 연계된 배부적수 목록(배부적수 코드 · 배부적수명 · 배부적수 설명 · 배부적수단위 · 기본가중치)입니다. [추가]/[삭제] 버튼으로 배부적수를 연계·해제합니다.

2차원가계정 등록 · 수정

[등록] 클릭 시 배부용원가계정(2차계정) 등록 팝업이 열립니다. Master 행을 선택하고 [수정]하면 같은 팝업이 수정 상태로 열립니다.

  • 2차 원가계정코드 — ‘자동’ 체크 시 저장할 때 자동 부여됩니다.
  • 2차 원가계정명 (필수) — 배부용 계정 명칭을 입력합니다. (예: 노무 활동 배부 계정, 고정 가공비 배부 계정)
  • 원가요소 설명 — 계정에 대한 설명을 입력합니다.
  • 2차원가 구분 (필수) — 고정비 / 변동비 중 선택합니다(예: 노무 활동 배부 계정·변동 가공비 배부 계정 → 변동비, 고정 가공비 배부 계정 → 고정비). 이 구분은 원가 배부 시 변동비와 고정비를 서로 다른 로직으로 배부하는 기준이 됩니다.
  • [저장] 시 팝업이 닫히고 목록이 갱신됩니다. [취소]는 입력을 버리고 닫습니다.

ℹ️ 2차원가계정 정보를 수정하면, 연결된 1차 원가계정 구분 및 배부 관련 설정도 함께 변경됩니다.

선택가능 배부적수 설정 (추가)

Master에서 2차계정을 선택한 뒤 Detail 영역의 [추가]를 클릭하면 배부적수 조회 팝업이 열립니다.

  • 배부적수 조회 팝업은 배부적수 코드·배부적수명으로 구성됩니다. 코드 또는 명칭으로 [조회]·[초기화]하고, 연계할 배부적수를 체크해 다중 선택한 뒤 [확인]하면 선택한 배부적수가 ‘선택가능 배부적수’(Detail)에 추가됩니다. [취소]하면 추가 없이 닫힙니다.
  • 잘못 추가한 배부적수는 Detail에서 체크 후 [삭제]로 연계를 해제합니다.

삭제

삭제할 2차계정을 체크하고 [삭제]하면 확인 후 삭제됩니다. 단, 원가배부방법설정 등에 이미 사용 중인 2차계정은 삭제할 수 없습니다.

1. 기준정보관리(BM)

1.8. 제조원가 배부방법설정

개요

제조원가 배부방법설정은 제조 과정에서 발생한 간접원가를 코스트센터·제품으로 배부하는 방법을 배부대상월 단위로 정의하는 화면입니다. 간접 코스트센터 간 배부(코스트센터간 배부방법)와 직접 코스트센터에서 제품으로의 배부를 설정하며, 여기서 정의한 배부방법이 제조원가 마감·결산 시 원가 배부 계산에 사용됩니다.

💡 배부 흐름은 간접CC → (간접/직접)CC → 제품 으로 이어집니다. 배부대상월을 선택해 월별로 관리하며, [전월데이터복사]로 전월 설정을 가져오고 설정을 마치면 [마감]으로 확정합니다.

화면 진입

좌측 사이드바 [원가관리] ▸ [기준정보관리(BM)] ▸ [제조원가 배부방법설정]

화면 구성

상단에서 배부대상월을 선택해 [조회]하면, 좌측 ‘배부 구성 트리’와 우측 콘텐츠가 표시됩니다.

  • 배부대상월 · 기능 버튼 — 배부방법을 적용·관리할 월을 선택해 [조회]/[초기화]합니다. [전월데이터복사]는 전월 배부방법을 복사하고, [마감]은 해당 월 배부방법을 확정합니다.
  • 좌측 트리 — ① 코스트센터간 배부방법 설정(‘미설정 간접코스트센터 목록’ / ‘추가배부’), ② 직접코스트센터에서 제품으로 배부, 그리고 ‘원가 배부관련 필요설정’(코스트센터 등록 · 배부적수 등록 · 직접원가계정(1차) 설정 · 배부용원가계정(2차) 설정 바로가기)로 구성됩니다.
  • 미설정 간접코스트센터 목록 — 해당 월에 배부방법이 등록되지 않은 간접 코스트센터(코스트센터명·코드·설명)입니다(예: 생산총괄 COC007·품질관리 COC008·창고관리 COC009). 여기에 표시된 간접CC는 [추가배부]로 배부방법을 등록해야 합니다.

1. 코스트센터간 배부방법 설정

간접 코스트센터에 집계된 비용을 다른 코스트센터로 배부하는 방법입니다. [추가배부]로 등록하면 좌측 트리에 배부방법이 추가되고, 선택하면 아래 4개 영역이 표시됩니다.

  • 1. 배부처리명 — 배부방법의 이름입니다(예: ‘생산총괄 → 하위 간접CC 인원수 배부’). [수정]으로 이름을 변경합니다.
  • 2. 배부관계 설정 — 보내는 코스트센터(FROM)와 받는 코스트센터(TO)를 지정합니다. 보내는 CC는 간접CC 1개이며, 받는 CC는 간접·직접 코스트센터 모두 여러 개 지정할 수 있습니다(돋보기로 조회·추가, 행 단위 [삭제]). 예: 생산총괄(COC007) → 품질관리(COC008)·창고관리(COC009).
  • 3. 원가계정별 배부기준 설정 — 어떤 원가계정을 어떤 배부적수로 배부할지 지정합니다(원가계정과목·원가계정코드·배부적수선택 컬럼, 행 [삭제]). ‘모든 원가에 일괄적용’ 행이 기본 제공되며(예: 배부적수 ALB005 인원수), 특정 원가계정만 별도 배부적수를 적용할 수도 있습니다. 코스트센터간 배부에서는 변동비·고정비 구분 없이 모든 원가계정에 배부적수를 지정할 수 있습니다(단, 재료비 제외).
  • 4. 배부비율 직접설정(사용자 정의비율) — 배부적수를 ‘사용자정의비율’로 지정한 경우, 받는 코스트센터(TO)별 배부비율(배부적수단위·배부비율 컬럼)을 직접 입력하고 [저장]합니다.

2. 직접코스트센터에서 제품으로 배부

직접 코스트센터에 집계된 원가를 제품으로 배부하는 방법입니다. 좌측 트리에서 ‘2. 직접코스트센터에서 제품으로 배부’를 선택하면 아래 3개 영역이 표시됩니다.

  • 1. 직접코스트센터 목록 — 회사의 직접 코스트센터(코스트센터명·코드·설명·배부설정여부)입니다(예: 가공 COC010·조립 COC011·도장외주 COC012·포장 COC013). 행을 선택하면 아래 2·3 영역이 해당 코스트센터 기준으로 표시됩니다.
  • 2. 계정과목별 배부기준 설정 — ‘변동비 계정과목’(활동으로 자동 배부, 이 화면에서 배부적수 선택 안 함)과 ‘모든 고정비 일괄적용’(배부적수로 배부, 예: ALB003 작업시간) 두 배부기준 행으로 구성됩니다(체크·원가계정과목·배부적수선택 컬럼, 행 [삭제]). 즉 변동비는 활동으로, 고정비는 배부적수로 배부합니다.
  • 3. 배부비율 직접설정(사용자 정의비율) — 배부적수를 사용자정의비율로 지정한 경우, 직접 코스트센터에 귀속된 제품별 배부비율(제품코드·제품명·배부비율 컬럼 + 합계)을 직접 입력하고 [저장]합니다.

ℹ️ 배부방법은 배부대상월 단위로 관리됩니다. 매월 [전월데이터복사]로 전월 설정을 복사한 뒤 변경분만 수정하고, 설정을 마치면 [마감]으로 확정하면 됩니다.

1. 기준정보관리(BM)

1.9. 판관비 배부방법설정

📊 판관비 배부방법설정은 판매관리비(판관비)를 ‘배부대상월’ 단위로 어떤 기준(배부적수)에 따라 원가대상(제품·사업부·거래처)에 배부할지 설정하는 화면입니다. 판관 코스트센터별 · 원가특성별 · 계정과목별로 배부기준을 지정합니다.

1) 개요 — 판관비 배부란

판관비(판매관리비)를 매출액·매출수량 등 합리적 기준으로 제품/사업부/거래처에 나눠 배부합니다. 배부대상월 단위로 설정하고, 설정이 끝나면 마감합니다.

💡 배부율 = 배부대상금액 ÷ 배부적수 합계. 각 대상의 배부적수 값 × 배부율 = 그 대상이 배부받은 금액.

핵심 개념

  • 판관 코스트센터 — 판관비가 모이는 코스트센터(영업·관리 등). CC별로 배부기준을 설정합니다.
  • 원가특성 — 원가를 어떤 단위로 분석할지(제품 / 사업부 / 거래처). 오픈 기준 3개 고정(회사별 커스터마이징 가능). 원가특성별로 배부기준을 따로 설정합니다.

2.1. 연간원가계획

개요

연간원가계획은 연도·계획버전별로 제품의 매출원가(재료비·변동가공비·고정가공비)를 계획하는 화면입니다. 연간영업계획(매출)을 반영하고 실적금액을 가져와 제품별 계획원가와 원가율을 산출하며, 세 원가 항목을 각각 마감한 뒤 계획버전을 확정·결재상신합니다. 연간원가계획은 경영계획(매출→생산→구매→원가)의 원가 부분으로, 손익계획(매출−매출원가)의 기초가 됩니다.

💡 매출원가 = 재료비 + 변동가공비 + 고정가공비. 세 항목을 각각 계획·마감해야 계획버전을 확정할 수 있습니다.

화면 진입

좌측 사이드바 [원가관리] ▸ [원가계획] ▸ [연간원가계획]

화면 구성

상단에서 기준연도를 선택해 [조회]하면, 좌측 ‘1. 계획버전’과 우측 ‘2. 제품별 계획원가상세’ 및 원가 항목 탭(재료비/변동가공비/고정가공비)이 표시됩니다.

  • 기준연도 · 회사 — 조회 기준연도와 회사를 선택해 [조회]합니다.
  • 1. 계획버전 — 연도별 연간원가계획 버전 목록입니다(계획번호 CP+연도+일련, 계획기간, 비고, 결재상태, 최종작업). 상태는 ‘미확정’ 또는 ‘확정’으로 표시됩니다. [계획버전 추가]로 새 버전을 만들고, [결재상신]·[삭제]를 할 수 있습니다. 확정 버전은 계획별 1개만 존재합니다.
  • 2. 제품별 계획원가상세 — 제품별로 ①재료비·②변동가공비·③고정가공비와 매출원가 합계, 연간매출계획 금액, 원가율(매출원가÷매출계획)을 표시합니다. [연간영업계획 반영]으로 영업계획의 매출을 가져옵니다. [삭제]로 제품 행을 제거합니다.
  • 재료비 / 변동가공비 / 고정가공비 탭 — 매출원가 3개 항목별로 제품별 상세를 입력·관리합니다. 각 탭에 [마감]·[실적반영하기]·[일괄적용]과 ‘월별 상세내역 보기’가 있습니다.

원가 항목별 계획 입력 (재료비·변동가공비·고정가공비)

각 탭에서 제품별 실적금액을 가져와 계획원가율·계획원가를 산출합니다. 그리드 헤더의 번호는 계산식을 나타냅니다.

  • 실적금액(①매출액·②재료비) — 실적조회기간 기준 실적입니다. [실적반영하기]로 가져옵니다.
  • ③원가율(%) = ② ÷ ① — 실적 기준 원가율입니다.
  • ④증감(%) — 계획 시 적용할 증감율을 입력합니다.
  • ⑤계획원가율(%) = ③ × ④ — 증감을 반영한 계획 원가율입니다.
  • ⑥연간매출계획 — 영업계획에서 가져온 연간 매출입니다.
  • 계획원가 = ⑥ × ⑤ — 연간매출계획에 계획원가율을 곱한 계획원가입니다.
  • [일괄적용]으로 여러 제품·항목에 값을 한 번에 적용하고, ‘월별 상세내역 보기’를 체크하면 1~12월 월별 계획원가(안분)를 확인·입력할 수 있습니다.

  • 확정 — 세 원가 항목이 모두 마감되어야 계획버전을 확정할 수 있습니다. 확정 후에는 수정할 수 없고(확정취소 가능), 확정 버전은 계획별 1개만 존재합니다.

개요

원자재 표준단가관리는 차기 표준원가 계산에 사용할 원재료·부재료의 표준단가를 산정기간(차수)별로 등록·마감하는 화면입니다. 매월 단가 산정기간(차수)을 만들고, 해당 차수의 원재료·부재료 품목별 표준단가를 입력·반영한 뒤 마감하면, 그 단가가 표준원가 계산과 품목 기준정보(품목별 표준단가조회)에 반영됩니다.

💡 산정기간(차수)은 원자재 표준단가관리 · 표준가공비 계획 및 배부 · 표준활동단가관리 · 표준고정비 배부금액관리 4개 메뉴에 일괄로 생성되어, 같은 차수 기준으로 표준원가를 산정합니다.

  • 1. 단가 산정기간 — 월별 단가 차수 목록입니다. 차수 카드에는 적용기간(예: 2026-05 ~ 2026-05)·등록일자와 상태(작성중 / 마감)가 표시됩니다. [단가차수 추가]로 새 차수를 만들고, [삭제]로 차수를 제거합니다.

3.2. 표준가공비 계획 및 배부

개요

표준가공비 계획 및 배부는 산정기간(차수)별로 제조 코스트센터의 가공비(배부용 원가계정) 계획금액을 산정하고, 간접 코스트센터의 비용을 직접 코스트센터로 배부하는 화면입니다. 실적금액에 증감율을 반영해 계획금액을 만들고 배부적수 기준으로 배부를 실행하면, 그 결과가 표준활동단가·표준고정비·제품별 표준가공비 계산의 기초가 됩니다.

💡 계획금액 = 실적금액 × (1 + 증감율). 배부실행 시 표준활동단가, 고정비 계정금액, 제품별 표준가공비가 함께 업데이트됩니다.

화면은 ‘1. 금액 산정기간(차수)’, ‘2. 차수별 금액상세’의 코스트센터 목록과 계정과목 상세 그리드로 구성됩니다. 차수와 코스트센터를 선택하면 해당 코스트센터의 계정과목별 금액이 우측에 표시됩니다.

  • 1. 금액 산정기간 — 원자재 표준단가관리와 동일한 단가 차수(예: 2026-06)를 공유합니다. 상태는 작성중 / 마감으로 표시됩니다.
  • 코스트센터 목록 — 제조 관련 코스트센터입니다. 유형이 간접(예: 생산총괄·품질관리·창고관리)과 직접(예: 가공·조립·도장외주·포장)으로 구분되며, 간접 코스트센터 비용을 직접 코스트센터로 배부합니다. [등록]·[삭제]로 대상을 관리합니다.
  • 계정과목 상세 — 선택한 코스트센터의 배부용 원가계정(2차계정)별로 실적금액(월) · 증감(%) · 계획금액 · 배부적수 · 최종작업자 · 작업일시를 표시합니다.

계획금액 산정

계정과목별 실적을 가져와 증감율을 반영해 계획금액을 만들고, 각 계정의 배부적수를 지정합니다.

  • 실적금액 가져오기 — [실적금액 가져오기]로 해당 월의 계정과목별 실적금액(월)을 불러옵니다.
  • 증감(%) 입력 — 계획에 반영할 증감율을 입력하면 계획금액 = 실적금액 × (1 + 증감율)로 산출됩니다.
  • 배부적수 — 각 계정과목에 적용할 배부적수(배부 기준)를 지정합니다. ‘미설정’ 상태는 제조원가 배부방법설정/배부적수에서 기준을 지정해야 함을 의미합니다.
  • 이전차수 불러오기 / 업로드 — [이전차수 불러오기]로 직전 차수 값을 복사하거나, [업로드]로 엑셀 양식의 금액을 일괄 등록할 수 있습니다.

배부 실행 · 마감

  • 마감 — [마감]으로 차수를 마감합니다. 마감 후에는 금액을 수정할 수 없습니다(마감취소 가능).

개요

  • 2. 보내는 코스트센터 계정과목별 세부내역 — 선택한 코스트센터를 계정과목(급여·복리후생비·전력비·감가상각비 등) 단위로 분해해 자체발생/배부대상/배부한금액을 보여줍니다.
  • 3. 받는 코스트센터 계정과목별 받은 금액과 비율 — 받는 코스트센터가 어떤 배부적수(예: ALB005 인원수) 기준으로 얼마를, 어떤 비율로 받았는지 보여줍니다.

  • 1. 보내는 직접코스트센터 배부내역 — 직접 코스트센터(가공·조립·도장외주·포장 등)의 자체발생금액과 배부받은금액 합계가 제품으로 배부됩니다.
  • 2. 보내는 코스트센터 계정과목별 세부내역 — 직접 코스트센터를 계정과목 단위로 분해한 내역입니다.
  • 3. 제품별 받은 금액과 비율 — 제품코드·제품·규격·단위별로 어떤 배부적수(예: ALB003 작업시간) 기준으로 가공비를 배부받았는지 보여줍니다. 이 금액이 제품별 표준가공비의 기초가 됩니다.

3.4. 표준활동단가 관리

개요

💡 표준활동단가 = 활동단가(실적) × (1 + 증감율). 제품 표준가공비 = 표준활동단가 × 표준활동량(공정 투입시간·수량).

3.5. 표준고정비 배부금액 관리

개요

표준고정비 배부금액 관리는 직접 코스트센터에 집계된 고정비(감가상각비·지급임차료·급여 등) 계정금액을 산정기간(차수)별로 관리하고, 각 고정비 계정을 배부적수 기준으로 제품에 배부할 금액을 확정하는 화면입니다. 표준가공비 배부 결과로 직접 코스트센터에 모인 고정비가 여기서 제품 배부의 기초금액이 됩니다.

💡 배부율 = 계획금액 ÷ 배부적수 계획수치 합계. 제품별 고정비 = 제품의 배부적수 값 × 배부율.

화면 진입

좌측 사이드바 [원가관리] ▸ [표준원가] ▸ [표준고정비 배부금액 관리]

  • 코스트센터 목록 — 고정비를 배부할 직접 코스트센터(가공·조립·도장외주·포장 등)입니다.

직접 코스트센터를 선택하면 해당 코스트센터에 집계된 고정비 계정과 계획금액이 표시됩니다.

  • 실적금액 가져오기 — [실적금액 가져오기]로 직접 코스트센터로 배부·집계된 고정비 계정금액을 불러옵니다.

  • 배부적수 — 각 고정비 계정을 제품에 배부할 기준(예: ALB003 작업시간)을 지정합니다. 배부율 = 계획금액 ÷ 배부적수 계획수치 합계로 산출되어 제품별 고정 가공비가 계산됩니다.
  • 이전차수 불러오기 / 업로드 / 등록 — 직전 차수 복사, 엑셀 일괄 등록, 행 추가가 가능합니다.

3.6. 제품/반제품 표준원가관리

‘반제품’과 ‘제품’ 탭으로 나뉘며, 각 탭에서 품목별 표준재료비·표준가공비(변동)·표준가공비(고정)·표준원가를 확인합니다.

  • 반제품 탭 — 반제품(SFG) 품목의 표준원가입니다. 컬럼: 공장 · 제품코드 · 제품 · 규격 · 단위 · 표준재료비 · 표준가공비(변동) · 표준가공비(고정) · 표준원가 · 비고 · 최종작업자 · 작업일시.

  • 제품 탭 — 완제품(FG) 품목의 표준원가입니다(예: 캔버스 에코백 1,458 = 300 + 139 + 1,019). 구성은 반제품 탭과 동일하며, 반제품이 투입된 완제품은 반제품 표준원가가 재료비로 반영됩니다.

  • 합계 — 그리드 하단에 표준재료비·표준가공비(변동/고정)·표준원가의 합계가 고정 표시됩니다.

표준원가 구성 · 마감

표준가공비(변동·고정)는 표준가공비 계획 및 배부에서 배부를 실행하면 제품·반제품 모두 자동으로 반영됩니다. 따라서 이 화면에서는 재료비를 불러와 합산하고, 반제품 → 제품 순으로 원가마감(확정)합니다.

🔄 핵심 흐름: ① 표준가공비 배부실행 → 제품·반제품의 변동·고정 가공비 자동 반영 ② [표준재료비 불러오기] ③ 반제품 원가마감(확정) ④ 반제품 표준원가가 제품 재료비에 자동 반영 ⑤ 제품 원가마감.

  • 표준가공비(변동·고정) 자동 반영 — 표준가공비 계획 및 배부에서 표준가공비 배부실행을 하면 제품·반제품의 표준가공비(변동)·표준가공비(고정)가 자동으로 업데이트됩니다. ([표준가공비(변동)/(고정) 불러오기]는 필요 시 수동으로 다시 반영할 때 사용합니다.)
  • 표준재료비 불러오기 — 가공비가 자동 반영된 상태에서 [표준재료비 불러오기]로 원자재 표준단가관리·BOM 기준의 표준재료비를 가져옵니다.
  • 반제품 먼저 확정 — 반제품 탭에서 재료비까지 채운 뒤 [원가마감]하면 반제품의 표준원가가 확정됩니다(재료비 + 자동 반영된 변동·고정 가공비).
  • 제품 재료비 자동 계산 — 반제품이 확정되면, 그 반제품이 투입된 제품의 재료비에 반제품 표준원가가 자동으로 반영(계산)됩니다. 이어서 제품을 [원가마감]해 제품 표준원가를 확정합니다.
  • 원가마감 · 보조기능 — 원가마감으로 확정된 표준원가는 품목별 표준단가조회 등 기준정보에 반영됩니다. [전월표준원가 복사]로 전월 값을 복사하거나 [실제원가 반영하기]로 실제원가를 참조할 수 있습니다.

1단계. 실물확정

제조원가 계산의 기초가 되는 실물 거래(구매·외주·생산·재고)를 먼저 마감합니다.

  • 구매마감 — 구매요청서 마감, 발주(구매오더) 마감, 구매입고(GR) 마감, 송장(IR) 마감, 구매 정산 마감.
  • 외주마감 — 외주지시서 마감, 외주실적(GR) 마감, 외주송장(IR) 마감, 외주정산 마감.
  • 생산마감 — 생산지시서 마감, 생산실적 마감.
  • 재고마감 — 입출고 요청서 마감, 입고/출고/이동/조정 마감, 재고실사 마감, 생산투입수량확정, PPV(구매가격차이) 원가조정 반영, 원부자재 및 상품 재고자산 금액확정(재고평가).

2단계. 제조비용 집계 및 배부진행

재무전표를 마감해 1차 원가계정 실적을 집계하고, 간접 코스트센터 비용을 직접 코스트센터·제품으로 배부합니다.

  • 제조원가 배부방법설정 마감 — 직접원가계정-배부용원가계정 맵핑 점검, 코스트센터간 배부방법설정 검증, 직접코스트센터에서 제품으로 배부 검증, 해당월 배부설정 마감.
  • 재무전표 마감 및 1차원가계정 실적 집계 — 급여입력 마감, 재무전표 마감.
  • 가공비 배부실행 — 1차원가계정 금액 집계 → 간접CC→간접CC 배부 → 간접CC→직접CC 배부 → 직접CC→제품 배부 순으로 배부합니다.

3단계. 제조원가 마감 및 표준/실제 원가 차이분석

생산지시서별로 실제 재료비·가공비(노무비·간접비)·외주비를 계산해 제조원가를 확정하고, 표준 대비 실제 원가차이를 산출한 뒤 재고자산 금액을 확정합니다.

  • 생산지시서 마감 및 재료비 Roll-up — 생산지시서별 가공비 계산, 생산지시서별 재료비 계산, 원가마감. (제조원가 = 배부된 가공비(노무비·간접비) + 재료비 + 외주비, 제조단가 = 제조원가 ÷ 당월 생산량.)
  • 재고자산 마감 — 공장별 원가마감, 제품/반제품 단가 확정, 재고자산 금액 확정. 표준/실제 원가차이는 매출원가와 기말재고로 배분됩니다.

4단계. 판관비 배부 및 수익성 마감

판관비를 원가특성별로 배부하고 원가특성별 손익보고서를 확정합니다.

  • 판관비 배부방법설정 마감 — 판관비 원가특성별 배부방법설정 검증, 판관비 배부방법.
  • 판관 Cost Center 실적 마감 및 원가특성별 배부 — 판관비 계정별 재무전표 금액을 코스트센터별로 집계, 원가특성별 판관비 배부.
  • 수익성분석 — 원가특성별 손익보고서 산출.

마감 처리 · 마감취소

  • 마감처리 — 각 섹션의 [마감처리]를 누르면 ‘2026년 5월을 마감합니다. 마감 후 등록,수정,삭제가 불가합니다.’(원가대상년월이 동적으로 표기됨) 확인 후 마감됩니다. 마감되면 처리여부가 ‘완료’로 바뀌고 최종작업자·작업일시가 기록됩니다.

개요

제조원가 회계처리는 두 가지 방식을 지원합니다.

  • 혼합형 (Hybrid) — 원재료는 이동평균단가, 완제품은 표준원가로 입고. SAP V+S 방식.

코스트센터 간 배부내역

‘코스트센터 간 배부내역’ 탭은 간접 코스트센터 → 직접 코스트센터로 실제 배부된 내역을 보여줍니다. 상단 행을 선택하면 하위 그리드가 연동되어 드릴다운됩니다(합계 라인 선택 시 전체 내역).

  • 2. 보내는 코스트센터 계정과목별 세부내역 — 선택한 코스트센터를 원가계정과목(급여·복리후생비·전력비·감가상각비·지급임차료 등) 단위로 분해한 실제 배부 내역입니다.
  • 3. 받는 코스트센터 계정과목별 받은 금액과 비율 — 받는 코스트센터가 어떤 배부적수(예: ALB005 인원수) 기준으로 얼마를, 어떤 비율로 받았는지 보여줍니다.

직접CC에서 제품 배부내역

‘직접CC에서 제품 배부내역’ 탭은 직접 코스트센터 → 제품으로 배부된 실적 가공비를 보여줍니다.

  • 1. 보내는 직접코스트센터 배부내역 — 직접 코스트센터(가공·조립·도장외주·포장 등)의 자체발생금액과 배부받은금액 합계가 제품으로 배부됩니다.
  • 2. 보내는 코스트센터 계정과목별 세부내역 — 직접 코스트센터를 원가계정과목 단위로 분해한 내역입니다.
  • 3. 제품별 받은 금액과 비율 — 제품 · 제품코드 · 원가계정과목 · 배부적수(예: ALB003 작업시간) · 배부율 컬럼으로, 제품이 어떤 배부적수 기준으로 가공비를 배부받았는지 보여줍니다. 비율(배부율)은 전체 합계 대비 개별 금액을 소수점 4자리로 계산한 뒤 3자리로 반올림해 표기하며, 원가계정의 고정비/변동비 구분에 따라 표기가 달라집니다.

  • ⑦ 수동 원가 조정 — 위 자동 조정으로 해소되지 않는 잔여 차이를 사용자가 품목·금액으로 직접 입력해 재고 단가를 보정합니다. 발행경로·분개는 케이스별이며 노션 회계처리에 별도 정의가 없습니다.

개요

제품원가 보고서는 선택한 기간의 제품별 표준원가와 실제원가(단가·금액)를 비교하는 조회 전용 보고서입니다. 제품단가를 구성하는 재료비·변동가공비·고정가공비별로 표준 대비 실제 단가를 함께 보여주어, 어느 원가요소에서 차이가 났는지 한눈에 파악합니다. 화면 조회와 엑셀 다운로드만 제공합니다.

💡 단가차이 = 실제제품단가 − 표준제품단가, 단가차이율 = 단가차이 ÷ 표준제품단가. 금액차이 = 실제제품금액 − 표준제품금액(= 양품수량 × 단가). 제품단가 = 재료단가 + 변동단가 + 고정단가(표준·실제 각각).

🚦 차이 상태(신호등): 단가차이 ±3% 이하 정상 / 3~5% 주의 / 5% 초과 경고. 금액차이 ±100만원 이하 정상 / 100~300만원 주의 / 300만원 초과 경고. 임계값은 회사별로 정의합니다.

개요

원가차이 보고서는 제품별 재료비·변동가공비·고정가공비의 표준 대비 실제 차이를 원가요소별로 분해해 차이 원인(수량차이/단가차이)을 파악하는 조회 전용 보고서입니다. 완성품과 재공품을 함께 보며, 상단 ‘원가차이 요약’(제품별)과 하단 상세 탭(재료비 / 변동가공비 / 고정가공비)으로 구성됩니다.

💡 차이금액 = 실제원가 합계 − 표준원가 합계, 차이율(표준기준) = 차이금액 ÷ 표준원가 합계. 재료비차이 = 수량차이금액[(실제−표준수량)×표준단가] + 단가차이금액[(실제−표준단가)×실제수량]. 변동가공비차이 = (시간)수량차이 + 단가차이. 고정가공비차이 = 배부적수차이[(실제−예상적수)×예상배부율] + 배부율차이[(실제−예상배부율)×실제적수].

🚦 차이 상태(신호등) 기준: 제품원가 차이 ±3%/3~5%/5%, 재료비 차이 ±3%/3~5%/5%, 가공비 차이 ±2%/2~4%/4% (정상/주의/경고, 회사별 기준). 차이금액·차이율은 ▲불리(실제>표준, 원가 상승)/▼유리(실제<표준, 원가 절감)로 방향을 함께 표기하며, 실제 단가가 아직 반영되지 않은 항목은 차이율이 크게(경고) 표시될 수 있습니다.

상단 요약 그리드는 제품별로 표준 대비 실제 차이를 원가요소별 차이 합계와 함께 보여줍니다(행: 기간 × 공장 × 제품 × 구분).

6.3. 당기 생산원가 보고서

개요

당기 생산원가 보고서는 당기에 생산된 원가(당기 생산 제품 + 기말 재공품 WIP)를 표준·실제로 확정하고, 기말 시점의 재공품 현황(어느 제품의 WIP가 많은지)을 파악하는 조회 전용 보고서입니다. 상단 ‘당기 생산 재고자산 요약’(3구분)과 하단 상세 탭(당기 생산 상세 / 당기 생산 제품재고 상세 / 당기 순증가 WIP 상세)으로 구성됩니다.

💡 당기 생산 합계 = 당기 생산 제품재고 금액(제품+반제품) + 기말 재공(WIP) 금액. 차이 = 실제금액 − 표준금액(▲불리: 실제>표준, 원가 상승 / ▼유리: 실제<표준). 당기 순증가 WIP수량/금액 = 기말 WIP − 기초 WIP. WIP 비중(%) = WIP 금액 ÷ 당기 재고합계.

📒 제조원가명세서 관점: 당기제품제조원가 = 당기총제조비용(재료비+노무비+경비) + 기초재공품 − 기말재공품 − 타계정대체액. 본 보고서는 그 결과(제품재고분·재공분)를 표준/실제로 보여줍니다.

7.2. 원가특성별 EBITDA 요약

개요

원가특성별 EBITDA 요약은 제품·조직·거래처별로 매출액부터 EBITDA까지의 손익 흐름을 한 줄로 요약해 보여주는 수익성분석 화면입니다. 매출에서 매출원가·판관비를 차감해 영업이익을 구하고, 현금흐름 관점의 감가상각비를 더해 EBITDA를 산출합니다.

💡 ③매출총이익 = ①매출액 − ②매출원가. ⑤영업이익 = ③매출총이익 − ④판관비. EBITDA = ⑤영업이익 + ⑥감가상각비(제조) + ⑦감가상각비(판관).

화면 진입

  • 컬럼 — 순번 · 공장 · 품목 · 규격 · 단위 · ①매출액 · ②매출원가 · ③매출총이익(①-②) · ④판관비 · ⑤영업이익(③-④) · ⑥감가상각비(제조) · ⑦감가상각비(판관) · EBITDA(⑤+⑥+⑦).
  • ①매출액 = 판매단가 × 판매수량(영업 매출실적), ②매출원가 = 제품원가 × 판매수량(제품별 실제원가 5.3), ④판관비는 매출 비중으로 배부된 원가특성별 배부내역(7.1)에서 집계됩니다. ⑥감가상각비(제조)는 제조원가 계산 시 제품 배부분, ⑦감가상각비(판관)는 판관비 배부분입니다. 탭을 바꾸면 동일 손익을 조직(Profit Center)·거래처(고객) 단위로 집계해 보여줍니다.

📝 예시) FG-A01: ①매출액 120,000,000 − ②매출원가 81,240,000 = ③매출총이익 38,760,000. − ④판관비 30,800,000 = ⑤영업이익 7,960,000. + ⑥제조감가 760,080 + ⑦판관감가 1,500,000 = EBITDA 10,220,080.

연계

  • 항목별(특히 판관비 계정별) 상세 손익은 원가특성별 EBITDA 상세(7.3)에서 확인합니다. 마감 기준은 제조원가 마감 및 결산(4.1)입니다.

7.3. 원가특성별 EBITDA 상세

개요

원가특성별 EBITDA 상세는 제품·조직·거래처별 손익을 항목 단위(매출액·매출원가·매출총이익·판관비·영업이익·감가상각비·EBITDA)로 펼쳐 보여주는 손익계산서형 화면입니다. 특히 판관비를 계정과목별로 분해해, 어느 항목에서 손익이 결정되는지 상세하게 확인합니다. EBITDA 요약(7.2)을 항목 단위로 풀어 본 상세 버전입니다.

💡 매출총이익 = 매출액 − 매출원가. 영업이익 = 매출총이익 − 판관비. EBITDA = 영업이익 + 감가상각비(제조) + 감가상각비(판관).

화면 진입

좌측 사이드바 [원가관리] ▸ [수익성분석] ▸ [원가특성별 EBITDA 상세]. 상단 조회월을 선택해 [조회]합니다.

화면 구성

화면은 좌측 ‘1. 원가특성’ 선택 트리와 우측 ‘2. 원가 특성별 손익 조회’ 그리드로 구성됩니다. 좌측에서 보고 싶은 손익 대상을 체크하면, 우측에 항목(행) × 대상(열) 형태의 손익이 표시됩니다.

  • 1. 원가특성(좌측 트리) — 전체 손익 ▸ 제품별 손익 / 조직별 손익 / 거래처별 손익으로 나뉘며, 각 하위에 개별 제품·조직(Profit Center)·거래처가 체크박스로 나열됩니다. 체크한 대상이 우측 그리드의 열로 추가됩니다.
  • 2. 원가 특성별 손익 조회(우측) — 행은 손익 항목, 열은 ‘합계’와 선택한 각 대상입니다. 항목: 1.매출액 · 2.매출원가 · 3.매출총이익(1-2) · 4.판관비(계정과목별로 직원급여·복리후생비·여비교통비·기업업무추진비·통신비·지급임차료·보험료 등으로 분해) · 5.영업이익 · 6.감가상각비(제조) · 7.감가상각비(판관) · EBITDA.
  • 판관비 하위에 계정과목별 금액이 펼쳐져, 판관비가 어떤 비용으로 구성됐는지 대상별로 비교할 수 있습니다.

연계

  • 매출원가는 제품별 실제원가(5.3), 판관비는 원가특성별 배부내역(7.1)에서 집계되며, 요약 지표는 원가특성별 EBITDA 요약(7.2)에서 한 줄로 확인합니다. 마감 기준은 제조원가 마감 및 결산(4.1)입니다.
